### 3.2 60分钟写入过程 (第二步, 级联合成生效!)

```
_query_tf_from_db("AAPL", "60分钟", cutoff_date, 120)
SQL: SELECT ... FROM kline WHERE ... timeframe='60分钟'
     AND ts <= '2026-07-03T14:45:00+08:00'
     ORDER BY ts DESC LIMIT 120

返回: 119 条 dict (时间升序, 最后完整bar ts=2026-07-03T14:00:00+08:00)

数据预览 (最后4条):
| ts=2026-07-03T10:30+08:00 | O=183.8 | H=185.0 | L=183.2 | C=184.2 | V=15500 |
| ts=2026-07-03T11:30+08:00 | O=184.2 | H=185.5 | L=183.8 | C=184.5 | V=16000 |
| ts=2026-07-03T13:00+08:00 | O=184.5 | H=185.4 | L=183.8 | C=184.2 | V=15000 |
| ts=2026-07-03T14:00+08:00 | O=184.2 | H=185.8 | L=183.5 | C=185.0 | V=18000 |

_needs_synthesis("60分钟", db_rows, cutoff_date):
  → last_ts = "2026-07-03T14:00:00+08:00" → _ensure_tz_naive → 2026-07-03 14:00:00
  → _get_period_start_ts(last_ts) → 2026-07-03 14:00:00
  → next_period_start = 2026-07-03 15:00:00
  → cutoff_dt = _ensure_tz_naive("2026-07-03T14:45:00+08:00") → 2026-07-03 14:45:00
  → 14:45 >= 14:00 AND 14:45 < 15:00 → True ★ 需要合成!

_find_immediate_finer_tf("60分钟", ["15分钟","60分钟","日线","周线"]):
  → 检查 TFS 映射 → "15分钟" ✓ (15分钟 < 60分钟, 且是最接近的更低TF)

_synthesize_incomplete_bar(target_tf="60分钟", finer_tf="15分钟", ...):
  → last_ts = 2026-07-03T14:00:00+08:00
  → query_start = 2026-07-03 14:00:00 (当前60分钟周期的开始)
  → cutoff_dt = 2026-07-03 14:45:00

  ★ 查询15分钟数据 (用于合成):
  _query_tf_for_period("AAPL", "15分钟", "2026-07-03T14:00:00", "2026-07-03T14:45:00")
  SQL: SELECT ... FROM kline WHERE ticker='AAPL' AND timeframe='15分钟'
       AND ts >= '2026-07-03T14:00:00' AND ts <= '2026-07-03T14:45:00'
       ORDER BY ts ASC

  返回 (不完整的60分钟周期内的3条15分钟bar):
  ┌──────────────────────┬────────┬────────┬────────┬────────┬───────┐
  │ ts                   │ Open   │ High   │ Low    │ Close  │ Vol   │
  ├──────────────────────┼────────┼────────┼────────┼────────┼───────┤
  │ 2026-07-03T14:15:00  │ 184.9  │ 185.4  │ 184.5  │ 185.2  │ 5000  │
  │ 2026-07-03T14:30:00  │ 185.2  │ 185.8  │ 184.8  │ 185.1  │ 4600  │
  │ 2026-07-03T14:45:00  │ 185.1  │ 185.6  │ 184.9  │ 185.4  │ 5200  │
  └──────────────────────┴────────┴────────┴────────┴────────┴───────┘

  finer_synth_bar = synth_cache["15分钟"]["synth_bar"] = None
  (15分钟没有合成bar, 直接用DB数据)

  _aggregate_bars(3条15分钟bar) → 合成60分钟bar:
  ┌──────────────────────────────────────┬────────┐
  │ 字段                                 │ 值     │
  ├──────────────────────────────────────┼────────┤
  │ ts (合成的Date)                      │ 2026-07-03T14:45:00+08:00 │
  │   ← _format_synth_date: 带时区, 匹配60分钟DB格式          │
  │ Open  ← first bar's Open (14:15)    │ 184.9  │
  │ High  ← max(185.4, 185.8, 185.6)    │ 185.8  │
  │ Low   ← min(184.5, 184.8, 184.9)    │ 184.5  │
  │ Close ← last bar's Close (14:45)    │ 185.4  │
  │ Volume ← sum(5000+4600+5200)        │ 14800  │
  └──────────────────────────────────────┴────────┘

_build_output_df(db_rows(119条) + synthesized_bar(1条), max_bars=120):
  → data = 119 + 1 = 120条
  → 120 ≤ 120 → 不截断
  → df最后一条即合成bar

★ 写入: data/display/60分钟.parquet
  内容: 119条完整60min bar + 1条合成bar (覆盖14:00~14:45的未完成周期)
  ✅ 变更前缺失的未完成周期现在被合成bar补全!
```

### 数据流总结

```
TF=15分钟 (min_tf):
  DB读取: 120条完整bar
  合成: 无 (min_tf跳过)
  parquet: 120条 (全部来自DB)
  ts范围: 2026-07-03T11:00+08:00 ~ 2026-07-03T14:45+08:00 (假设)

TF=60分钟:
  DB读取: 119条完整bar (最后ts=2026-07-03T14:00+08:00)
  合成输入: 3条15分钟DB bar (14:15, 14:30, 14:45)
  合成输出: 1条60分钟合成bar (ts=2026-07-03T14:45+08:00, Close=185.4)
  synth_cache: 保存合成bar供下游使用
  parquet: 120条 (119 DB + 1 合成)

TF=日线:
  DB读取: N-1条完整bar (最后ts=2026-07-02T00:00:00)
  合成输入: 5条60分钟DB bar + 1条60分钟合成bar(级联!)
  合成输出: 1条日线合成bar (ts=2026-07-03T14:45:00, Close=185.4)
  Close来源: 60分钟合成bar的Close (级联传递!)
  parquet: N条 (N-1 DB + 1 合成)

TF=周线:
  DB读取: M-1条完整bar (最后ts=2026-06-22T00:00:00)
  合成输入: 4条日线DB bar + 1条日线合成bar(级联!)
  合成输出: 1条周线合成bar (ts=2026-07-03T14:45:00, Close=185.4)
  Close来源: 日线合成bar的Close → 60分钟合成bar的Close (双层级联!)
  parquet: M条 (M-1 DB + 1 合成)
```

### 级联Close值追踪

```
15分钟DB bar (14:45): Close = 185.4  ← 最细粒度的原始数据
          │
          ▼ _aggregate_bars
60分钟合成bar:       Close = 185.4  ← 直接取自15分钟最后一bar的Close
          │
          ▼ _aggregate_bars
日线合成bar:         Close = 185.4  ← 取自60分钟合成bar的Close (级联1次)
          │
          ▼ _aggregate_bars
周线合成bar:         Close = 185.4  ← 取自日线合成bar的Close (级联2次)
```

185.4 这个值从15分钟原始数据一路传递到周线合成bar，体现了级联合成的数据一致性。

## 5. 差异总结表

| TF | 变更前parquet内容 | 变更后parquet内容 | Bar合成来源 | 数据完整性 | 最后一条ts |
|----|------------------|------------------|------------|-----------|-----------|
| 15分钟 | 120条完整 | 120条完整 | 无 (min_tf) | 一致 | 2026-07-03T14:45+08:00 |
| 60分钟 | 119条完整 | 120条(119 DB + 1 合成) | 15分钟DB bar(3条) → 60分钟合成 | ★ 补全未完成周期 | 2026-07-03T14:45+08:00 (合成) |
| 日线 | N-1条完整 (缺7/3) | N条(N-1 DB + 1 合成) | 60分钟DB(5条) + 60分钟合成bar(1条) → 日线合成 | ★ 补全当日 | 2026-07-03T14:45:00 (合成, 无时区) |
| 周线 | M-1条完整 (缺本周) | M条(M-1 DB + 1 合成) | 日线DB(4条) + 日线合成bar(1条) → 周线合成 | ★ 补全本周 | 2026-07-03T14:45:00 (合成, 无时区) |

### 核心变更点

| 维度 | 变更前 | 变更后 |
|------|--------|--------|
| 调用方式 | 每个TF独立调用 `_sync_to_display` | 一次 `_sync_all_cascading` 调用所有TF |
| 合成逻辑 | 无 | 有: 从min_tf逐级向上合成 |
| 数据共享 | 无 (各自查询DB) | 有: synth_cache跨TF共享合成bar |
| 60分钟完整性 | ❌ 缺失未完成周期 | ✅ 补全 |
| 日线完整性 | ❌ 缺失当日 | ✅ 补全 |
| 周线完整性 | ❌ 缺失本周 | ✅ 补全 |
| Close值一致性 | N/A | 级联保证: 15min→60min→日线→周线 Close=185.4 一致 |
| Date格式 | 纯DB格式 | min_tf/60分钟带时区; 日线/周线不带时区 (匹配各自DB) |
