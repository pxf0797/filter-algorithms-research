## 6. 风险与注意事项

### 6.1 删除 JSONL 后受影响的功能

| 删除文件 | 受影响场景 | 影响程度 | 缓解措施 |
|---------|-----------|---------|---------|
| `events.jsonl` | 调试 BS 信号生命周期问题；审计 add/remove/modify 事件时序 | 中 | 保留 `--debug` 模式开关；或从 parquet `_trade` 列反向推导交易事件 |
| `bs_snapshot.jsonl` | 验证 parquet `_bs_entry`/`_bs_exit` 正确性 | 低 | parquet 数据已是最终展示数据，无需二次验证 |
| `schmitt_snapshot.jsonl` | 重新计算或验证 `_sig`/`_eps` 值 | 低 | Schmitt 参数属于中间计算，展示层不需要 |
| `filter_tail.jsonl` | 重新计算或验证 `_filtered` 值 | 低 | 滤波结果为中间计算 |
| `trade_summary.jsonl` | 快速查看各 step 的 win_rate 汇总 | 低 | 可从 parquet `_trade` + `_trade_return` 重新聚合 |
| `backtest_result.csv` | 在 Excel 中直接打开查看 | 低 | 可用 pandas `pd.read_parquet().to_csv()` 按需转换 |
| `backtest_data.csv` | 查看 OHLCV 原始数据 + Schmitt 参数 | 低 | OHLCV 数据在回测输入源中已存在；Schmitt 参数为中间计算 |

### 6.2 需要同步检查的代码位置

| 文件/模块 | 检查内容 |
|----------|---------|
| BacktestRunner（回测运行器） | 移除 JSONL/CSV 写入调用；确保 parquet 和 metadata.json 写入不受影响 |
| `view_backtest.py` | 确认仅依赖 parquet + metadata.json（根据 T2 分析，当前已是如此） |
| `docs/backtesting/回测结果可视化.html` | 确认仅依赖 `col(data, name)` 从 parquet 序列化数据读取（根据 T2 分析，当前已是如此） |
| `filter/backtest/dashboard.py` | 确认仅通过 pandas 读取 parquet（根据 T2 分析，当前已是如此） |
| 任何读取 JSONL 的测试/脚本 | 搜索 `events.jsonl`、`bs_snapshot.jsonl`、`schmitt_snapshot.jsonl`、`filter_tail.jsonl`、`trade_summary.jsonl` 的引用 |
| 任何读取 CSV 的测试/脚本 | 搜索 `backtest_data.csv`、`backtest_result.csv` 的引用 |

### 6.3 数据完整性保证

- **Parquet 包含所有展示必需数据。** T2 分析确认：51 列覆盖了 HTML 全部 7 个图表 section + Streamlit 全部功能。
- **Metadata.json 包含所有会话配置。** view_labels、视图参数、时间范围等均在其中。
- **JSONL 是中间产物，不是最终数据。** 数据流为 `JSONL（中间计算）→ BacktestRunner 聚合 → Parquet（最终数据）→ 展示层`。删除中间产物不影响最终展示。

### 6.4 回滚方案

如需恢复 JSONL 输出，只需在 BacktestRunner 中重新启用对应的写入调用。所有 JSONL 写入逻辑保持不变，仅需移除"不写入"的条件判断。

## 7. 决策总结

| 决策点 | 建议 | 理由 |
|--------|------|------|
| 删除 5 个 JSONL 文件 | **强烈建议** | 占 89.9% 空间（20.2 MB），展示层零引用，数据已全量写入 parquet |
| 删除 2 个 CSV 文件 | **强烈建议** | 占 9.6% 空间（2.1 MB），是 parquet 的冗余副本，展示层不读取 |
| 精简 parquet 列 | **不建议（当前）** | parquet 仅 118 KB，列级精简收益不足 36 KB，但需修改 HTML/Streamlit 代码，投入产出比极低 |
| 添加 debug 开关 | **建议** | 在配置中添加 `save_debug_data` 开关，默认关闭，按需开启 JSONL/CSV 输出 |

**最终推荐方案：仅输出 2 个文件（parquet + metadata.json），总大小约 125 KB，精简比例 99.5%。展示层代码无需任何修改。**
