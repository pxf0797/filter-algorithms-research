# filter_research 单支股票深度研究方法论

> **版本**: v1.0  
> **日期**: 2026-07-27  
> **适用范围**: 基于 filter_research 工具的实战操作手册  
> **核心原则**: 每条指令都是"打开终端就能执行"的级别

---

## 一、研究哲学

**核心理念：多时间帧共识 + 多滤波器验证 + 加速度信号过滤。**

传统均线交叉或 MACD 有两个致命缺陷：一是滞后性（价格走了一大段才出信号），二是震荡市中频繁假突破。filter_research 的设计哲学绕过了这些问题：

1. **不直接用价格交叉，用加速度突破。** Schmitt 触发器监测的是拟合抛物线的加速度 a 是否突破自适应死区，而非价格本身是否突破某个线。加速度是价格的二阶导数，比一阶（速度/动量）更早捕捉趋势反转。自适应死区（死区宽度 = k_eps x EWMA波动率）在高波动时自动放宽，避免被噪声震出；低波动时收窄，保持灵敏度。

2. **不是单一滤波器，是 10 滤波器共识。** 单滤波器输出的信号不可靠，但如果在 SMA/EMA/Kalman/Savitzky-Golay/Butterworth 等多个滤波器上，同一时间帧、同一方向都出现加速度突破，这个信号的可信度就大幅提升。

3. **不是单时间帧，是 4 视图跨周期验证。** 日线定方向（做多还是做空），60 分线找节奏（趋势是否健康），15 分线等入场（信号共振），5 分线精确执行。粗周期约束细周期，而不是反过来。

一句话总结：**用粗周期定战略（方向），用多滤波器求共识（可靠性），用加速度信号定战术（时机）。**

## 二、完整研究流程

### Phase 1: 数据准备与初步观察

**目标**: 建立对这支股票的基本认知 — 它的"性格"是什么。

#### 步骤 1.1: 拉取数据

```bash
# 启动 filter_research 工具（根据实际入口）
cd /path/to/filter_research

# 确认数据可用（以 3690.HK 为例）
python -c "
from data.cache_manager import CacheManager
cm = CacheManager()
info = cm.get_symbol_info('3690.HK')
print(f'Records: {info[\"row_count\"]}, Date range: {info[\"date_range\"]}')
for tf in ['1m','5m','15m','60m','1d','1wk','1mo']:
    count = cm.get_row_count('3690.HK', tf)
    print(f'  {tf}: {count} bars')
"
```

**Go 标准**: 至少要有 500+ 根日线 bar（约 2 年数据），15 分钟线至少 10000+ bar。

#### 步骤 1.2: 初始观察 — 裸 K 线

```bash
# 在 UI 中操作：
# 1. 打开 browse 模式
# 2. 选择标的: 3690.HK
# 3. 时间帧: 1d (日线)
# 4. 滤波器: 选择 "None" 或任意滤波器但不关注信号
# 5. 拖动时间范围滑块，观察最近 6-12 个月的价格走势
```

**手工记录**（在笔记中）:
- 当前价格处于近 1 年的什么位置？（高位/中位/低位）
- 有明显的上升/下降/横盘趋势吗？（肉眼判断）
- 日均波动幅度大概多少%？
- 有无跳空缺口密集区？（港股/美股财报季常见）

#### 步骤 1.3: 快速滤波器扫描

```bash
# 在 browse 模式，4 视图网格中设置：
# 视图1: 1d, SMA(20)    — 看中长期趋势骨架
# 视图2: 1d, Kalman(Q=0.01,R=0.1) — 看状态估计的平滑路径
# 视图3: 1d, LOWESS     — 看非线性趋势
# 视图4: 1d, Savitzky-Golay(窗口=15,阶数=3) — 看转折形态保留

# 观察要点：
# - 4 个滤波器在日线上是否给出大致相同的方向感？
# - 哪些区域滤波器和裸价格差异大？（→ 噪声大的区域，信号可能不可靠）
```

**No-Go 标准**: 如果 4 个滤波器在日线上方向互相矛盾（2 个看多 2 个看空），该股票可能处于强烈震荡期，不适合趋势跟踪策略。考虑换标的或等待方向明确。

### Phase 2: 多时间帧趋势研判

**目标**: 确定主趋势方向和强度，找到潜在的入场时间帧。

#### 步骤 2.1: 设置 4 视图网格

```
UI 操作：
┌─────────────────────────────────────────────────┐
│ 视图1: 1d    │ 视图2: 60m   │                   │
│ 滤波器: SMA  │ 滤波器: Kalman│                  │
│ Schmitt: ON  │ Schmitt: ON   │  目的：定方向     │
│ k_eps: 2.0   │ k_eps: 1.5    │                   │
├──────────────┼───────────────┤                   │
│ 视图3: 15m   │ 视图4: 5m    │                   │
│ 滤波器: EMA  │ 滤波器: ALMA  │  目的：找入场     │
│ Schmitt: ON  │ Schmitt: ON   │                   │
│ k_eps: 1.2   │ k_eps: 1.0    │                   │
└─────────────────────────────────────────────────┘
```

**参数设置原则**:
- k_eps 从粗周期到细周期递减：日线 2.0 → 60m 1.5 → 15m 1.2 → 5m 1.0。粗周期用更宽的死区过滤噪声，细周期用更窄的死区捕捉精确入场。
- 粗周期滤波器选稳健型（SMA/Kalman/LOWESS），细周期滤波器选快速型（EMA/ALMA）。

#### 步骤 2.2: 粗周期定方向（视图1 + 视图2）

```
检查清单（日线 + 60分钟线）：
□ 日线滤波器曲线方向是向上还是向下？
  → 向上 = 多头偏好，向下 = 空头偏好
□ Schmitt 触发器在日线上最近 20 根 bar 内是否有长信号（绿色标记）或短信号（红色标记）？
  → 信号方向与滤波器方向一致吗？不一致 → 警告信号
□ 60 分钟线是否与日线方向一致？
  → 一致 = 趋势健康，不一致 = 可能反转或震荡
□ 物理抛物线预测（如果开启）显示的回转路径是否与当前趋势方向匹配？
  → 抛物线预测回落方向 = 反趋势方向，如果预测回落幅度很小 → 趋势强劲
```

**趋势有效 vs 震荡的判断标准**:

| 指标 | 趋势有效 | 震荡无方向 |
|------|---------|-----------|
| 日线滤波器斜率 | 持续单向，30 根 bar 以上 | 频繁上下交替 |
| Schmitt 信号密度 | 稀疏但持续（每 10-20 bar 一个） | 密集但频繁反转（每 3-5 bar 翻转） |
| 60m 与日线方向一致性 | ≥80% 时间同向 | 经常矛盾 |
| 物理抛物线曲率 | | |a| 小且稳定 | |a| 大或符号频繁变化 |

**No-Go 标准**: 如果日线滤波器斜率在过去 40 根 bar 内改变了 3 次以上方向 → 震荡市，不适合趋势跟踪。考虑换标的或使用更短的时间帧做区间交易（但 filter_research 的设计偏向趋势跟踪）。

#### 步骤 2.3: 细周期找入场（视图3 + 视图4）

```
检查清单（15 分钟 + 5 分钟线）：
□ 15 分钟线上，是否出现了与日线方向一致的 Schmitt 信号？
  → 如果日线看多，等 15m Schmitt 出现长信号
□ 15m 信号的 "v 和 a 同向" 条件是否满足？
  → v（速度，即一阶导数）和 a（加速度）必须同向，这是 Schmitt 的内置过滤
□ 5 分钟线上是否有确认信号？
  → 5m 信号不是必须的，但如果 1d/60m/15m/5m 四个帧同时出现同向信号 → 强共识，高可信度
```

#### 步骤 2.4: 推荐滤波器组合及理由

**日常分析组合** (4 视图默认配置):

| 视图 | 时间帧 | 滤波器 | 理由 |
|------|--------|--------|------|
| 1 | 1d | Kalman (Q=0.01, R=0.1) | 状态估计最稳健，小 Q 表示信任模型，适合定大方向 |
| 2 | 60m | SMA(20) 或 Butterworth | SMA 简单可靠无过拟合；Butterworth 零相位适合离线分析 |
| 3 | 15m | EMA(12) | 快速追踪近期变化，适合捕捉入场窗口 |
| 4 | 5m | ALMA | 最低延迟，适合精确执行 |

**深度验证组合**（当上面组合给出信号后，换一组滤波器验证）:

| 视图 | 时间帧 | 滤波器 | 理由 |
|------|--------|--------|------|
| 1 | 1d | LOWESS | 非线性稳健，验证 Kalman 的方向是否被过拟合 |
| 2 | 60m | Savitzky-Golay(15,3) | 保留转折形态，看是否有被 SMA 平滑掉的局部转折 |
| 3 | 15m | Gaussian | 通用平滑，不同于 EMA 的指数衰减权重 |
| 4 | 5m | Median | 异常值免疫，排除毛刺假信号 |

**核心原则**: 两组滤波器的信号方向一致 → 高可信度。两组矛盾 → 信号不可靠，放弃或等待。

### Phase 3: 策略回测验证

**目标**: 验证信号在历史上是否真的能赚钱。

#### 步骤 3.1: 回测参数设置

```
UI 操作（backtest 模式）：
┌────────────────────────────────────────────┐
│ 标的: 3690.HK                               │
│ 时间帧: [1d, 60m, 15m, 5m] (4 视图并行)     │
│ 滤波器: 与 Phase 2 确定的组合一致            │
│ Schmitt k_eps: 与 Phase 2 一致              │
│                                             │
│ Bar 范围:                                   │
│   训练集: 最近 500 根 bar 之前的历史数据     │
│   验证集: 最近 500~200 根 bar                │
│   测试集: 最近 200 根 bar（留出，不用于调参） │
│                                             │
│ 止损: 2% (日线) / 0.5% (60m) / 0.3% (15m)   │
│ 止盈: 不设（让利润奔跑）                     │
│ 保护期: 5 bar (日线) / 10 bar (60m)          │
│                                             │
│ 步进间隔: 1 bar (精细回测)                   │
│ 最小 bar 数: 500 (低于此数统计无意义)         │
```

#### 步骤 3.2: 避免过拟合的纪律

**参数调优三原则**:

1. **固定大部分参数，只调关键 2-3 个。** 10 种滤波器 x 各自的参数 + 4 个 k_eps + 止损% + 保护期 = 太多自由度。必须锁定：滤波器类型（1 种）、时间帧组合（固定 4 个）、止损逻辑类型（固定为百分比止损）。

2. **只调 k_eps 和滤波器内部 1 个参数（如 Kalman 的 Q/R）。** k_eps 控制信号灵敏度，Q/R 控制平滑度。这两个是最直接影响信号质量的参数。

3. **训练集上网格搜索，验证集上选最优，测试集只跑一次。** 绝不能在测试集上看到结果后再回去调参数 — 这是最致命的过拟合。

**调参网格示例**（训练集上）:

```
固定参数:
  滤波器: Kalman
  时间帧: 1d,60m,15m,5m
  止损: 2% / 0.5% / 0.3% / 0.2%
  保护期: 5 / 10 / 15 / 20 bar

搜索网格:
  k_eps:  [1.0, 1.5, 2.0, 2.5, 3.0]     → 5 个值
  Q:      [0.001, 0.01, 0.1]             → 3 个值
  R:      [0.01, 0.1, 1.0]               → 3 个值

  总共: 5 x 3 x 3 = 45 组参数
  每组在训练集上跑一次 → 选验证集上 Sharpe 最高的那组
```

#### 步骤 3.3: 核心判断指标（优先级排序）

**第一优先**（必看，决定生死）:

| 指标 | 合格线 | 优异线 | 说明 |
|------|--------|--------|------|
| Sharpe Ratio | > 1.0 | > 2.0 | 风险调整后收益，最核心指标 |
| Max Drawdown | < 20% | < 10% | 最大回撤，超过 30% 心理上很难承受 |
| Calmar Ratio | > 0.5 | > 1.0 | 年化收益/MaxDD，综合收益和风险 |

**第二优先**（辅助判断）:

| 指标 | 合格线 | 说明 |
|------|--------|------|
| Sortino Ratio | > 1.5 | 只看下行波动的 Sharpe，比 Sharpe 更真实 |
| Win Rate | > 45% | 趋势跟踪胜率不高是正常的（靠盈亏比赚钱） |
| Profit Factor | > 1.5 | 总盈利/总亏损，低于 1.3 说明盈亏比不足 |

**第三优先**（细查）:

| 指标 | 关注点 |
|------|--------|
| MaxDD Duration | 回撤持续了多少根 bar？如果超过 100 根日线 bar（约 4-5 个月），要考虑能否承受 |
| Avg Win / Avg Loss | 平均盈利必须 > 平均亏损，理想比例 > 1.5:1 |
| Annual Return | 年化收益，但要结合 MaxDD 看。20% 收益但 30% 回撤不如 10% 收益但 5% 回撤 |

**红旗标志**（任一出现即放弃该策略）:
- 训练集 Sharpe > 2.0 但验证集 Sharpe < 0.5 → 严重过拟合
- 测试集 MaxDD > 训练集 MaxDD 的 2 倍 → 参数不稳定
- Win Rate > 70% 但 Avg Win / Avg Loss < 0.5 → 靠高频小盈覆盖偶尔大亏，不可持续
- 任何单一交易贡献了总利润的 30%+ → 靠一笔运气交易撑起结果

### Phase 4: 结果分析与决策

**目标**: 判断策略是否值得实盘。

#### 步骤 4.1: KPI 解读顺序

```
打开 HTML Dashboard → 按以下顺序阅读：

1. 【KPI 卡片】  — 3 秒扫一遍：Sharpe > 1.0? MaxDD < 20%?
   → 不满足 → 直接放弃，下面的不用看了
   → 满足 → 继续

2. 【PnL 曲线】  — 看曲线形状：
   □ 是稳步上升还是靠几笔大交易拉升？
     → 曲线楼梯状上升（平台期+跳跃）= 健康的趋势跟踪
     → 曲线靠少数几笔垂直拉升 = 运气成分大
   □ 回撤段有多长？恢复需要多久？
     → 看平台段的持续时间
   □ 最近一段（最近 50 根 bar）的 PnL 表现如何？
     → 如果最近表现明显差于历史平均 → 策略可能在失效

3. 【信号对比】  — 看不同滤波器之间的信号重叠度：
   □ 多个滤波器在同一时间产生同向信号吗？
   □ 盈利交易来自多滤波器共识还是单滤波器独立信号？
     → 共识信号盈利 = 策略可靠
     → 独立信号盈利 = 运气成分大

4. 【持仓热力图】— 看不同时间段的表现：
   □ 收益是否集中在某个时间段？
     → 策略可能只在特定市场环境下有效
   □ 亏损是否集中在某个时间段？
     → 策略是否有特定的失效模式

5. 【交易分析】  — 逐笔检查：
   □ 最大亏损交易的触发原因？（止损触发还是信号反转？）
   □ 最大盈利交易持有了多少根 bar？
   □ 连续亏损最多几笔？（超过 5 笔连续亏损需要心理准备）

6. 【10 滤波器对比工具】— 如果时间允许：
   □ 其他滤波器在同一时段的表现如何？
   □ 当前滤波器是明显最优还是只是中等水平？
     → 如果其他滤波器表现接近 → 策略稳健
     → 如果当前滤波器远超其他 → 可能过拟合
```

#### 步骤 4.2: 跨周期一致性验证

```
检查清单：
□ 日线 PnL 和 60m PnL 是否方向一致？
  → 日线赚钱但 60m 亏钱 → 信号在粗周期有效但细周期失效，有问题
□ 4 个时间帧的 Sharpe Ratio 是否按周期粗细递减？
  → 日线 > 60m > 15m > 5m 是正常的（细周期噪声大）
  → 如果 5m Sharpe 反而最高 → 警惕过拟合
□ 跨周期 PnL 对齐功能：
  → 打开跨周期 PnL 对齐视图
  → 检查同向性过滤是否改善了结果
  → 如果开启同向性过滤后 PnL 大幅提升 → 跨周期共识是真实 alpha
  → 如果开启后 PnL 反而下降 → 可能过度约束，丢失了独立信号的价值
```

#### 步骤 4.3: 运气 vs 技能的判别

```
如果以下条件全部满足 → 大概率是技能（策略有效）：
□ 训练/验证/测试集 Sharpe 趋势：训练 > 验证 > 测试，且都在合格线以上
  （递减是正常的，但不能断崖式下跌）
□ 4 个时间帧至少 3 个的 PnL 为正
□ 多滤波器共识信号的盈利能力明显优于单滤波器独立信号
□ 盈亏比（Avg Win / Avg Loss）> 1.5
□ MaxDD 发生在明确的市场下行期（可解释），而非随机分布

如果以下条件任一满足 → 大概率是运气（策略无效）：
□ 去掉最好的一笔交易后，整体 PnL 变负
□ 某个时间帧的 PnL 远超其他帧（1d Sharpe=3.0, 60m Sharpe=-0.5）
□ 换一组滤波器参数（如 k_eps +/- 0.5）后结果剧烈变化
□ 训练集和测试集表现反向（训练集做多赚钱，测试集做多亏钱）
```

## 三、避免随机性陷阱的纪律

### 3.1 必须固定的参数（不允许调优）

| 参数 | 固定值 | 原因 |
|------|--------|------|
| 时间帧组合 | [1d, 60m, 15m, 5m] | 4 视图是工具设计的基础，改变这个等于改变策略逻辑 |
| bar 步进间隔 | 1 | 不等于 1 的回测是在自欺欺人 |
| 数据集划分比例 | 60% 训练 / 20% 验证 / 20% 测试 | 标准的时序划分，防止未来信息泄露 |
| 回测最小 bar 数 | 500 | 低于 500 统计无意义（约 2 年日线数据） |

### 3.2 必须多次运行取平均的步骤

由于 Kalman 滤波器内部使用随机噪声初始化，以下步骤必须执行**至少 5 次**取平均：

```
步骤 A: Kalman 滤波器信号生成（每次运行信号边界可能有 ±1-2 bar 偏差）
  → 运行 5 次，记录每次的信号时间点
  → 取"至少 4 次一致"的信号作为可靠信号
  → 只在 5 次中 2-3 次出现的信号标记为"低可信度"

步骤 B: 10 滤波器对比工具（未设置随机种子）
  → 运行 3 次，取各指标的中位数而非均值
  → 如果某次某滤波器表现异常突出 → 可能是随机性导致的，需要更多验证

步骤 C: 物理抛物线预测（曲率拟合对噪声敏感）
  → 运行 3 次，观察预测回落路径的一致性
  → 如果 3 次预测路径差异超过 5% → 当前时段抛物线预测不可靠
```

### 3.3 如何区分信号和噪声

```
信号特征（可信）：
- 多个滤波器同时出现同向 Schmitt 信号（至少 2/4 视图）
- 信号出现在多时间帧（至少 2/4 时间帧）
- 信号出现时，价格确实突破了近期的波动范围
- 信号方向与粗周期滤波器方向一致

噪声特征（忽略）：
- 单个滤波器、单个时间帧的孤立信号
- 信号持续时间极短（< 3 bar 就被反转）
- 信号出现时成交量异常低（如果数据包含量）
- 5 分钟线的信号密集但 15 分钟线完全没有反应
```

## 四、实战检查清单

### 完整流程 N 步走

```
[ ] Step 1: 数据检查
    操作: CacheManager 查询标的的数据范围和质量
    命令: 见 Phase 1.1
    Go 标准: 日线 >= 500 bar, 无大面积缺失
    No-Go: 数据不足 500 bar → 换标的或接受结果不可靠

[ ] Step 2: 裸 K 线观察
    操作: browse 模式，日线，无滤波器，拖动时间范围
    命令: UI 操作
    Go 标准: 趋势可辨识（肉眼能看出大致方向）
    No-Go: 价格完全随机游走，无任何趋势特征 → 不适合趋势策略

[ ] Step 3: 快速滤波器扫描
    操作: 4 视图网格，各用不同滤波器看日线
    命令: 见 Phase 1.3
    Go 标准: 至少 3/4 滤波器方向一致
    No-Go: 滤波器方向严重矛盾 → 震荡市，放弃

[ ] Step 4: 多时间帧研判
    操作: 设置 4 视图（日线/60m/15m/5m），开启 Schmitt
    命令: 见 Phase 2.1 和 2.2
    Go 标准: 粗周期方向一致 + 细周期出现同向信号
    No-Go: 日线与 60m 方向相反超过 30% 时间 → 趋势不健康

[ ] Step 5: 确定核心参数
    操作: 选定滤波器类型、k_eps、Q/R
    命令: 手工记录在配置中
    Go 标准: 参数组合在浏览模式下产生清晰的信号（不密不疏）
    No-Go: 参数调整 3 轮后仍无法产生合理密度信号 → 该标的可能不适合

[ ] Step 6: 训练集回测
    操作: 固定参数，在最近 500 bar 之前的历史数据上跑
    命令: 见 Phase 3.1
    Go 标准: Sharpe > 1.0 且 MaxDD < 20%
    No-Go: Sharpe < 0.5 → 放弃，换参数或换标的

[ ] Step 7: 验证集回测
    操作: 用训练集选出的最优参数，在验证集上跑
    命令: 见 Phase 3.1
    Go 标准: 验证集 Sharpe > 训练集 Sharpe x 0.6（允许一定衰减）
    No-Go: 验证集 Sharpe < 0.3 → 严重过拟合，放弃

[ ] Step 8: 多滤波器交叉验证
    操作: 跑 10 滤波器对比工具
    命令: UI 中打开 filter_comparison_tool，运行 3 次取中位数
    Go 标准: 当前滤波器排名前 3，且前 5 名结果接近
    No-Go: 当前滤波器第 1 名但远超第 2 名 → 可能过拟合

[ ] Step 9: Kalman 多次运行验证
    操作: 如果使用 Kalman，运行 5 次取共识信号
    命令: 重复 Step 6-7，每次重启工具以重置随机状态
    Go 标准: 5 次中至少 4 次 Sharpe > 0.8
    No-Go: 5 次结果标准差/均值 > 30% → 随机性主导，Kalman 不适合该标的

[ ] Step 10: 测试集最终验证
    操作: 参数完全固定，在测试集上跑一次（只跑一次！）
    命令: 见 Phase 3.1
    Go 标准: 测试集 Sharpe > 0.5 且 MaxDD < 训练集 MaxDD x 1.5
    No-Go: 测试集亏损或 MaxDD 翻倍 → 策略不可靠

[ ] Step 11: 仪表盘深度解读
    操作: 按 Phase 4.1 的顺序解读 Dashboard
    命令: 打开 HTML Dashboard
    Go 标准: 所有红旗标志均未触发
    No-Go: 任一红旗标志触发 → 深入调查或放弃

[ ] Step 12: 跨周期一致性确认
    操作: 检查 4 个时间帧 PnL 的方向一致性
    命令: 见 Phase 4.2
    Go 标准: 至少 3/4 时间帧 PnL 为正
    No-Go: 2 个以上时间帧亏损 → 策略不稳定

[ ] Step 13: 最终决策
    操作: 综合所有结果，做出 Go/No-Go 决策
    Go 标准: 满足 Step 1-12 全部 Go 标准
    观望标准: 大部分 Go 标准满足，但有 1-2 个处于临界值
    No-Go 标准: Step 1-12 中任一 No-Go 被触发且无法解释
```

## 五、完整案例：3690.HK（美团）

### Phase 1: 数据准备与初步观察

**输入**:
```bash
python -c "
from data.cache_manager import CacheManager
cm = CacheManager()
info = cm.get_symbol_info('3690.HK')
print(info)
"
```

**假设输出**:
```
Symbol: 3690.HK
Records: 141,000 (全时间帧合计)
Date range: 2018-09-20 ~ 2026-07-25
日线 bars: 1,923 ✓ (>500)
60m bars: 9,615 ✓
15m bars: 38,460 ✓
5m bars: 115,380 ✓
```

**决策**: 数据量充足，Go。

**初始观察**（browse 模式，日线裸 K）:
- 2025.06 ~ 2026.07: 价格在 100-150 HKD 区间宽幅震荡
- 2025.01 ~ 2025.06: 明显的上升趋势，从 80 涨到 150
- 2024 下半年: 下降趋势，从 180 跌到 80
- 整体来看有明显的趋势特征（上升→下降→上升→震荡），不是完全随机游走

**快速滤波器扫描**（日线，4 滤波器）:
- SMA(20): 近 3 个月缓慢上升
- Kalman: 近 3 个月缓慢上升，斜率较小
- LOWESS: 近 3 个月轻微上升
- Savitzky-Golay: 近 3 个月呈现微小的上升趋势，但保留了一些局部转折

**决策**: 4 个滤波器在日线上方向大致一致（偏多），Go。

### Phase 2: 多时间帧趋势研判

**4 视图网格设置**:

| 视图 | 时间帧 | 滤波器 | Schmitt k_eps | 观察结果 |
|------|--------|--------|---------------|---------|
| 1 | 1d | Kalman(Q=0.01,R=0.1) | 2.0 | 方向向上，近 30 根 bar 斜率稳定为正。出现 2 个长信号 |
| 2 | 60m | SMA(20) | 1.5 | 方向向上但与日线比更曲折。近 50 根 bar 有 3 个长信号 |
| 3 | 15m | EMA(12) | 1.2 | 方向偏多但短期有回调。出现多个短信号（回调卖出） |
| 4 | 5m | ALMA | 1.0 | 噪声较大，信号密集且频繁反转 |

**趋势研判**:
- 日线 Kalman: 多头 ✓
- 60m SMA: 多头 ✓
- 日线/60m 方向一致性: ~85% ✓
- 物理抛物线曲率 |a|: 较小（趋势健康）✓

**决策**: 主趋势方向为多头。15m 等待入场信号。5m 噪声大，不作为主要参考。

**滤波器组合确认**:
- 主滤波器: Kalman (Q=0.01, R=0.1) — 稳健的状态估计
- 辅助验证: SMA(20)
- 入场帧: 15m / EMA(12) / k_eps=1.2
- 执行帧: 5m / ALMA / k_eps=1.0

### Phase 3: 策略回测验证

**参数设置**:
```
标的: 3690.HK
时间帧: 1d, 60m, 15m, 5m (4 视图)
主滤波器: Kalman (Q=0.01, R=0.1)
Schmitt k_eps: 2.0 / 1.5 / 1.2 / 1.0
止损: 2% / 0.5% / 0.3% / 0.2%
保护期: 5 / 10 / 15 / 20 bar
趋势跟踪期: 止盈仅由信号反转触发

Bar 范围划分（假设共 1923 根日线 bar）:
  训练集: bar 0 ~ 1150 (约 60%, 2018-09 ~ 2023-05)
  验证集: bar 1150 ~ 1540 (约 20%, 2023-05 ~ 2024-11)
  测试集: bar 1540 ~ 1923 (约 20%, 2024-11 ~ 2026-07)
```

**训练集回测（网格搜索）**:

```bash
# 伪代码 — 实际在 UI 中手工执行
for k_eps in [1.5, 2.0, 2.5]:
  for Q in [0.001, 0.01, 0.1]:
    for R in [0.01, 0.1, 1.0]:
      run_backtest(symbol="3690.HK", bar_range="0:1150", ...)
      record_sharpe()
```

**假设最优结果**: k_eps=2.0, Q=0.01, R=0.1 (与浏览模式选择一致，好兆头)

**训练集假设结果**:

| 指标 | 日线 | 60m | 15m | 5m |
|------|------|------|-----|----|
| Sharpe | 1.35 | 1.12 | 0.78 | 0.42 |
| MaxDD | 15.2% | 18.7% | 22.1% | 28.5% |
| Win Rate | 48% | 45% | 43% | 41% |
| Profit Factor | 1.8 | 1.6 | 1.4 | 1.2 |

**验证集假设结果**:

| 指标 | 日线 | 60m | 15m | 5m |
|------|------|------|-----|----|
| Sharpe | 1.15 | 0.95 | 0.62 | 0.31 |
| MaxDD | 17.8% | 20.3% | 24.5% | 30.1% |

**决策**: 训练→验证衰减合理（约 15%），Go。日线和 60m 策略可靠，15m 和 5m 仅作为辅助参考。

**测试集（最终验证，只跑一次）**:

| 指标 | 日线 | 60m |
|------|------|------|
| Sharpe | 1.05 | 0.88 |
| MaxDD | 18.5% | 21.2% |
| Profit Factor | 1.6 | 1.4 |

### Phase 4: 结果分析与决策

**KPI 解读**（按 Phase 4.1 顺序）:

1. **KPI 卡片**: 日线 Sharpe=1.05 > 1.0 ✓, MaxDD=18.5% < 20% ✓
2. **PnL 曲线**: 阶梯状上升，有平台期（震荡期）和跳跃期（趋势期），形态健康。最近 50 bar PnL 略有回撤但幅度在历史范围内
3. **信号对比**: 盈利交易中约 70% 出现在多滤波器共识时；单滤波器独立信号的盈亏接近打平
4. **持仓热力图**: 收益在 2024 下半年（下降趋势中的空头信号）和 2025 上半年（上升趋势中的多头信号）都有分布，非集中在一个时期
5. **交易分析**: 最大亏损交易 = 止损触发（-2%），可接受。最大连续亏损 = 4 笔，在预期范围内
6. **10 滤波器对比**: Kalman 排名第 2，前 5 名结果接近（Sharpe 差距 < 0.2），说明策略对滤波器选择不敏感

**跨周期一致性**:
- 日线 ✓, 60m ✓ (PnL 为正)
- 15m △ (Sharpe 0.62, 勉强合格)
- 5m ✗ (Sharpe 0.31, 不合格)
- 同向性过滤开启后，15m 提升到 0.72 → 跨周期共识有效

**最终决策**: **Go — 日线和 60m 多头策略可考虑实盘。**

但有以下注意事项：
- 只用日线和 60m 信号，忽略 15m 和 5m（它们噪声大，只能辅助确认方向）
- 实盘时需考虑交易成本和滑点（工具未建模），预计实际收益打 6-7 折
- combined_pnl = max(long, short) 不可实盘实现，实盘中需要明确选择只做多或只做空
- 建议先用小仓位试运行 1-2 个月，验证实盘与回测的一致性后再加仓
