## 1. 从 3690.HK 的 30 根 Bar 中看到了什么

### 1.1 开场：一个矛盾的故事

2026 年 3 月 31 日凌晨 2:30，3690.HK 股价 83.60 元。

在接下来的 26.5 小时里，发生了这样一件事：

- **周线视图 (v0) 全程看多**：19 次做多信号，0 次做空，从未动摇
- **日线视图 (v1) 全程看空**：30 次做空信号，0 次做多，从未动摇
- **两者从第一根 bar 到最后一根 bar，没有一秒同向过**

这不是数据错误。这是 3690.HK 在那个时刻的真实状态：**周线级别的中期趋势仍向上，但日线和日内级别的短期走势已经全面转空**。

最终结果：价格从 83.60 跌到 81.00，跌幅 -2.51%。日线赢了。

### 1.2 矛盾如何一步步解决

价格走势分为 7 个阶段，每个阶段都在讲述"周线惯性 vs 日线现实"的拉锯：

```
P1 上探 (83.60→83.95)  周线看多，日线看空，60分钟看空    → 严重分歧
P2 阴跌 (83.95→82.85)  周线看多，日线看空，60分钟震荡    → 分歧持续，但价格在跌
P3 反弹 (82.85→83.05)  周线看多，日线看空               → 弱势反弹，多头挣扎
P4 急跌 (83.05→82.50)  周线首次转中性！                → ⚠️ 关键信号出现
P5 反弹 (82.50→83.40)  周线回到看多，日线坚持看空        → 最后的诱多
P6 主跌 (83.40→81.90)  周线再次转中性，三个视图一致看空  → 空头全面释放
P7 整理 (81.90→81.00)  周线全中性，其余一致看空          → 弱势寻底
```

**关键转折点**：周线 v0 的 Schmitt 信号在 P4（bar 64）和 P6（bar 70）两次从 `long` 转为 `neutral`。这不是"震荡"，而是**"多头放弃"**——当周线不再坚持看多，空头力量彻底释放。两次转中性后分别出现了 -0.66% 和 -1.26% 的单 bar 暴跌。

### 1.3 EPS 说了什么：压缩到极致就是爆发

15 分钟视图的 eps 带宽（自适应波动率缓冲区）从 **0.0437 压缩到 0.0087**，降幅 **80%**。

把这翻译成人话：15 分钟级别的滤波器对价格的"容忍度"急剧缩小，价格被牢牢夹在一个极窄的通道里运行。这不是止跌——这是**能量积蓄**。在下跌趋势中，eps 压缩 = 弹簧被压到极限，突破后跟随趋势方向加速。

数据验证：v3 eps 收窄事件后的平均前瞻收益全部为负（-0.19% 到 -0.28%），价格在压缩后继续下跌而非止跌反弹。

### 1.4 49 笔交易全部盈利——但这意味着什么？

v2（60 分钟）和 v3（15 分钟）合计执行了 49 笔交易：
- v2: 19 笔 exit_short，每笔 +1.80%
- v3: 19 笔 exit_long (+0.34%) + 11 笔 exit_short (+1.34%)
- 100% 止盈离场，0 次止损

做空止盈（+1.34%~+1.80%）的收益是做多止盈（+0.34%）的 4-5 倍。

**这告诉我们的不是"策略完美"**，而是两件事：

1. **趋势方向决定止盈效率**——顺势做空的止盈更容易触发且获利更大，逆势做多的止盈需要等待更小的反弹，获利微薄
2. **这个回测窗口是"收获期"**——系统在持续平掉此前建立的仓位，没有开新仓。49 笔止盈不代表 49 次正确的开仓决策

### 1.5 一句话总结 3690 教会我们的

**股票变化的逻辑链是**：多时间框架滤波带定锚 --> 信号分歧/一致 --> eps 带宽变化 --> 价格突破方向。

在 3690 上，这个链条的每一步都留下了清晰的数据痕迹。

## 2. 股票变化逻辑的"四层透视法"

以下是将两份报告的方法论整合后的系统化分析流程。每一层回答一个问题，每一层都用一个 3690 的实际数据验证。

### 第一层：定锚 —— 30 秒看清大格局

**要回答的问题**：这只股票当前处于什么状态？

**看哪些数据列（按顺序）**：

| 步骤 | 数据列 | 看什么 | 问什么 |
|------|--------|--------|--------|
| 1 | metadata.json | view_labels 映射 | v0/v1/v2/v3 分别是什么周期？ |
| 2 | `v0_sig`, `v1_sig`（粗周期信号） | 最后 20 bar 的主导方向 | 周线和日线意见一致吗？ |
| 3 | `v0_eps`, `v1_eps`（粗周期 eps） | eps 近期趋势（上升/下降/稳定） | 波动在放大还是收敛？ |

**判断规则**：

| 粗周期信号特征 | 意味着什么 | 3690 验证 |
|-------------|-----------|----------|
| 周/日线 sig=+1 一致 | 中期上涨趋势确立 | — |
| 周/日线 sig=-1 一致 | 中期下跌趋势确立 | — |
| **周线 sig=+1，日线 sig=-1** | **跨周期矛盾**——趋势在转换窗口 | 3690 的精确状态 |
| 周/日线 sig=0 | 中期方向不明，震荡或突破前兆 | — |

**3690 实例**：
```
周线(v0): sig=+1（19次），eps 稳定 0.33-0.35
日线(v1): sig=-1（30次），eps 稳定 0.19-0.22
判断: 严重跨周期矛盾 → 趋势转换窗口 → 进入第二层
```

**Go/No-Go 标准**：
- 粗周期 sig 一致且 eps 稳定 --> Go（趋势明确）
- 粗周期 sig 矛盾或 eps 快速变化 --> Go（转折窗口）
- 粗周期 sig 频繁翻转 + eps 低且稳定 --> No-Go（纯震荡）
- 数据量 < 100 bar --> 仅做定性扫描，不做定量分析

### 第二层：定位 —— 找到转折点

**要回答的问题**：趋势在哪个 bar 开始变？为什么在那个时刻变？

**看哪些数据列**：

| 步骤 | 数据列 | 看什么 | 问什么 |
|------|--------|--------|--------|
| 1 | 所有 `v*_sig` | 信号翻转的 bar 和时间 | 哪个周期先翻？哪个后翻？ |
| 2 | 所有 `v*_sig` | 跨周期矛盾 bar 列表 | 细周期是否在"说服"粗周期？ |
| 3 | `v*_eps`（在翻转点前后） | eps 在翻转前还是在翻转后变化 | eps 是先行指标还是滞后指标？ |

**核心发现：信号传导方向决定真假**

| 传导模式 | 含义 | 3690 验证 |
|---------|------|----------|
| 15min 先翻 -> 60min 跟进 -> 日线跟进 | **有效转折**（细周期领跌/领涨） | 本次未完整出现（日线从未跟细周期同向） |
| 周线转 neutral + 日线/60min/15min 全空 | **加速信号**——多头放弃，空头释放 | P6 阶段（bar 70），3/4 视图一致看空后价格加速下跌 |
| v2/v3 反转但 v1 不变 | **假反转/噪音**——短周期过度敏感 | bar 65-68，v2 出现 short->long->short，造成 -4.28 PnL 回撤 |
| 所有周期同时翻转 | **异常**——粗周期有内在滞后性，不该同步 | — |

**3690 实例**：
```
v0（周线）信号翻转序列：
  bar 50: N/A → LONG（开仓看多）
  bar 64: LONG → NEUTRAL  ← 价格 83.05→82.50（-0.66%急跌）
  bar 65: NEUTRAL → LONG  ← 假信号！反弹仅持续4 bar
  bar 70: LONG → NEUTRAL  ← 价格 83.40→82.35（-1.26%暴跌）

规律: 周线 long→neutral = 强下跌预警
     周线 neutral→long 在下跌市中 = 假信号
```

**Go/No-Go 标准**：
- 找到了细->粗传导序列 --> Go（进入第三层验证）
- 跨周期矛盾但无传导规律 --> 记录，不深入
- 无任何信号翻转 --> 数据窗口太短或强趋势中，跳过第三层

### 第三层：验证 —— 区分真信号和噪音

**要回答的问题**：这个信号是有效的还是噪音？

**看哪些数据列**：

| 步骤 | 数据列 | 看什么 | 问什么 |
|------|--------|--------|--------|
| 1 | `v*_sig` + `close` | 信号出现后 5/10/20 bar 的价格方向 | 价格是否按信号方向走？ |
| 2 | `v*_pnl_long`, `v*_pnl_short` | 信号方向的 PnL 是否在增长 | 市场是否在"奖励"这个信号？ |
| 3 | `v*_trade_reason` | 离场原因分布 | 是止盈还是止损？ |

**判断标准**：

| hit_rate (20 bar) | 信号质量 | 意味着 |
|------------------|---------|--------|
| > 70% | 优秀 | 信号方向大概率正确，可作交易依据 |
| 50-70% | 勉强 | 有参考价值，需配合其他条件 |
| < 50% | 无效 | 不比抛硬币好——信号来自噪声 |

**3690 实例**：

```
信号方向准确率（单 bar）:
  v0（周线）做多: 9/19 = 47%
  v1（日线）做空: 15/30 = 50%
  v2（60分钟）做空: 9/20 = 45%
  v3（15分钟）做空: 7/17 = 41%

所有视图的单 bar 准确率均不超过50%——接近随机。
Schmitt 信号在单 bar 级别不具备短线择时能力。

但扩展到 5-bar:
  v1 做空 5-bar 前瞻收益: -0.49%（方向正确）
  v0 做多 5-bar 前瞻收益: -0.51%（方向错误，周线滞后）

PnL 验证（更可靠）:
  空头 PnL 持续上升（v1: +25%, v2: +15%, v3: +8%）
  多头 PnL 持平或回撤（v0: -1.47%, v3: -0.04%）
  → 市场在用钱投票：做空有效，做多无效
```

**噪音信号的 4 个识别标志**：
1. 信号持续时间 <= 3 bar 就翻转
2. eps 极窄（低于中位数的 30%）
3. 翻转时 filtered 价格几乎没变化（< 0.1%）
4. 粗周期信号是 0（无共鸣）——单一周期孤立的信号

### 第四层：总结 —— 形成可迁移认知

**要回答的问题**：这次分析最核心的发现是什么？下次看另一支股票时怎么用？

**每次分析后必答的 4 个问题**：

1. **最有效的信号特征是什么？**——哪个视图/指标的哪个变化最准确预测了后续走势？
2. **最大的噪声来源是什么？**——哪个视图频繁假翻转？什么条件下噪声最多？
3. **当前参数是否适合？**——eps 带宽是否太宽（信号滞后）或太窄（频繁假信号）？
4. **下次第一眼看什么？**——形成个人的快速扫描 SOP

**3690 的可迁移认知**：

```
1. 最有效信号: 周线 long→neutral + 三个短周期同向 → 趋势加速确认
2. 最大噪声: v3（15分钟）信号，14次翻转/29 bar，平均每30分钟翻一次，
   单独使用不可靠，只能配合更高级别
3. 参数评估: 日线 eps（0.19-0.22）对15分钟噪声完全免疫，参数合理
4. 下次SOP: 
   ① 看周/日线是否矛盾（30秒定锚）
   ② 矛盾时，看谁的 PnL 在涨（市场用钱投票）
   ③ PnL 方向 = 短期真实趋势方向
```

## 3. 6 种市场状态的可观测特征（速查表）

以下表格是操作手册。当你在看回测数据时，对照每个状态的数据特征，判断当前处于哪种状态。

| # | 市场状态 | 价格特征 (close) | 信号特征 (sig) | eps 特征 | filtered 特征 | PnL 特征 | 3690 实际数字 |
|---|---------|-----------------|---------------|---------|-------------|---------|-------------|
| **S1** | **强趋势上涨** | close 持续高于 filtered，连创新高 | 所有周期 sig=+1 一致 | eps 稳定或缓降 | filtered 斜率正且稳定 | long_pnl 稳步上升，short_pnl 不动 | 本次未出现 |
| **S2** | **趋势衰竭（顶部）** | close 开始跌破 filtered，不再创新高 | **粗周期仍 +1，细周期率先转 0 或 -1** | eps 开始放宽（波大是转向前兆） | filtered 斜率从正趋平 | long_pnl 从峰值回落 | **3690 的精确状态**：周线+1，日线-1，15分钟 eps 压缩80%，v0多头PnL -1.47% |
| **S3** | **下跌启动** | close 持续低于 filtered，连创新低 | 细周期 -1 确认后粗周期跟进 | eps 明显放大（下跌波动>上涨） | filtered 斜率负向加速 | short_pnl 快速上升 | P6 主跌浪：v2/v3 一致看空，5-bar -1.80% |
| **S4** | **震荡区间** | close 围绕 filtered 上下穿越 | 信号频繁翻转（<5 bar/次） | eps 窄幅低波动 | filtered 几乎水平 | 多空 PnL 均在 100 附近 | P1-P2 过渡区：v2/v3 信号快速切换 |
| **S5** | **突破前兆** | close 开始突破 filtered 但未拉开 | 细周期先转，粗周期观望；共识逐步建立 | eps 从低位开始走高 | filtered 斜率从 0 开始偏转 | 一侧 PnL 从 100 向上突破 | P4 急跌前：v0 首次转 neutral，短周期趋同 |
| **S6** | **假突破（陷阱）** | close 短暂突破 filtered 后迅速回落 | 细周期短暂翻 ±1（<5 bar）后回归 0；粗周期未确认 | eps 短暂放大后迅速回落（尖峰） | filtered 斜率短暂偏转后回归 | PnL 短暂盈利后回吐 | bar 65-68：v2 false reversal，PnL 回撤 -4.28 |

### 如何使用这张表

**不要在盘中逐一检查所有单元格。** 按这个顺序：

1. **先看 sig**：现在多头还是空头？
2. **再看 eps**：波动在放大还是收敛？（稳定 = 趋势持续，变化 = 转折临近）
3. **对照 filtered vs close**：价格在滤波上方还是下方？价差在扩大还是缩小？
4. **查看 PnL**：哪个方向的 PnL 在涨？——这是市场用钱投的票
5. **最后看 trade**：离场是止盈还是止损？——验证前几步的判断

## 4. 在过程中有效识别的 5 个前瞻指标

> 核心问题：如何在过程中（而非事后）识别状态变化？
>
> 核心答案：以下 5 个指标在信号翻转之前就已经在变化——它们是真正的先行指标。

### 4.1 EPS 压缩比 —— 弹簧指数

**定义**：短期 eps 均值与长期 eps 均值的比值。衡量波动率是在加速还是减速。

**计算方式**：
```
eps_ratio = eps_5bar_mean / eps_20bar_mean
```
- \> 1.3：波动明显放大（转折或加速前兆）
- 0.8-1.2：正常范围
- < 0.8：波动明显收缩（能量积蓄）

**3690 中的实际值**：

| 视图 | EPS 起始 | EPS 结束 | 压缩比 | 趋势 |
|------|---------|---------|--------|------|
| v0 (周线) | 0.3494 | 0.3347 | 0.96 | 缓慢收窄 |
| v1 (日线) | 0.1913 | 0.2198 | 1.15 | **持续放宽** |
| v2 (60分钟) | 0.0653 | 0.0590 | 0.90 | 逐步收窄 |
| v3 (15分钟) | 0.0437 | 0.0087 | **0.20** | **急剧收窄 80%** |

**识别规则**：

| eps_ratio | eps_accel | 当前信号 | 这意味着 |
|-----------|-----------|---------|---------|
| > 1.3 | > 0（加速中） | sig=+1 | 上涨可能加速见顶——波动放大往往是筑顶信号 |
| > 1.3 | > 0（加速中） | sig=0 | 突破前兆——波动先来，方向随后 |
| < 0.8 | < 0（减速中） | sig=+1 或 -1 | 趋势衰弱——低波动趋势可能很快被打破 |
| < 0.2 | — | 任何 | **极度压缩**——弹簧压到极限，突破在即。方向看上一级趋势 |

**3690 验证**：v3 eps 压缩到 0.20（即 80% 压缩）后，价格在后续 bar 中加速下跌。在下跌趋势中，eps 压缩不代表止跌，而是波动率积蓄后向趋势方向释放。

### 4.2 信号持续期趋势 —— 稳定性指数

**定义**：每次信号连续同向的 bar 数变化趋势。dur 在缩短 = 信号越来越不稳定 = 即将翻转。

**计算方式**：
```
dur_trend = 最近5次信号的平均持续期 / 更早信号的平均持续期
```
- < 0.7：持续期缩短（不稳定，即将翻转）
- 0.7-1.3：稳定
- \> 1.3：持续期延长（稳定化）

**3690 中的实际值**：

| 视图 | 信号段数 | 平均持续 | 最短 | 最长 | 趋势判断 |
|------|---------|---------|------|------|---------|
| v0 (周线) | 3 段 | 9.7 bar | 5 bar | 11 bar | 稳定 |
| v1 (日线) | 1 段 | 30 bar | 30 bar | 30 bar | 极度稳定 |
| v2 (60分钟) | 多段 | 2-5 bar | 1 bar | 6 bar | 频繁翻转 |
| v3 (15分钟) | 14 段 | 2.1 bar | 1 bar | 6 bar | 极度不稳定 |

**识别规则**：
- 日线 dur=30（全场未翻）-> 日线方向是"定锚"，极度可靠
- v3 dur=2.1 bar（平均 31 分钟翻一次）-> 15 分钟信号单独使用是自杀
- 如果日线的 dur 开始缩短（从 10+ 降到 5-），那是重大预警

### 4.3 Filtered 斜率变化 —— 趋势动量指数

**定义**：滤波后价格的斜率变化。斜率趋近于零 = 趋势动量耗尽。

**计算方式**：
```
slope = (filtered[-1] - filtered[-5]) / filtered[-5]   # 最近5 bar的滤波变化率
slope_warning = abs(当前斜率) < abs(前5 bar斜率) * 0.3   # 斜率趋零
```

**3690 中的实际值**：

| 视图 | Filtered vs Close 偏离 | 方向 | 含义 |
|------|----------------------|------|------|
| v0 (周线) | +1.70% | filtered > close | 周线滤波在价格上方——向上"拉" |
| v1 (日线) | -1.64% | filtered < close | 日线滤波在价格下方——向下"推" |
| v2 (60分钟) | -0.01% | 几乎重合 | 60分钟滤波紧贴价格 |
| v3 (15分钟) | -0.00% | 几乎重合 | 15分钟滤波紧贴价格 |

**3690 的关键发现**：周线和日线的滤波偏离方向完全相反（+1.70% vs -1.64%），偏离幅度几乎对称。价格夹在两条滤波曲线之间——这就是"过滤带夹击"：周线滤波在上方拉价格看多，日线滤波在下方推价格看空。最终价格向更紧贴当前市价的滤波方向（日线）靠拢。

**识别规则**：

| 斜率状态 | 信号状态 | 这意味着 |
|---------|---------|---------|
| 斜率趋近于 0 | sig=+1 | 上涨动量耗尽——准备平多 |
| 斜率趋近于 0 | sig=-1 | 下跌动量耗尽——准备平空 |
| 斜率刚过零（正->负） | sig 仍为 +1 | **信号滞后**——filtered 已转空但 sig 未翻，这是翻转前兆 |
| 斜率为正且加速 | sig=0 或刚转+1 | 趋势启动确认——可加仓 |

**重要提醒**：filtered 是同步指标而非领先指标。交叉相关分析显示，所有视图在 lag=0 时相关性最高（0.94-1.00）。它的价值不在于预测方向，而在于衡量趋势强度。lag=-1 的负相关（-0.32 到 -0.38）揭示的是**均值回归**特征：当滤波与价格偏离过大时，价格倾向于回归。

### 4.4 多周期收敛-发散 —— 共识指数

**定义**：4 个时间框架信号的一致程度。收敛 = 趋势健康，发散 = 转折前兆。

**计算方式**：
```
consensus_score = sum(v0_sig, v1_sig, v2_sig, v3_sig)  # 范围 -4 到 +4
consensus_strength = abs(consensus_score)               # 0-4，越高越一致
```

**3690 中的实际值**：

| 阶段 | v0 | v1 | v2 | v3 | 共识得分 | 强度 | 后续走势 |
|------|----|----|----|----|---------|------|---------|
| P1 上探 | +1 | -1 | -1 | 混合 | -1~0 | 弱 | 先跌后涨 |
| P2 阴跌 | +1 | -1 | 震荡 | 偏空 | 0~-1 | 弱 | 持续阴跌 |
| P4 急跌 | 0 | -1 | -1 | 分歧 | -1~-2 | 中 | 急跌 |
| P6 主跌 | 0 | -1 | -1 | -1 | **-3** | **强** | 最大跌幅 |
| P7 整理 | 0 | -1 | -1 | -1 | **-3** | **强** | 持续下跌 |

**3690 验证**：P6（主跌浪）和 P7（低位整理）期间，除周线外的三个视图首次达成高度一致看空（共识强度=3），此时价格下跌最猛烈。多视图一致性不代表立即暴跌，而是**持续性下跌的高概率区间**。

**识别规则**：

| 共识模式 | 强度趋势 | 这意味着 | 操作 |
|---------|---------|---------|------|
| 4 周期全票（strength=4） | 持续 | 强趋势中 | 持仓，等发散信号 |
| 从 4->3 或 3->2 | **下降** | 最早期的转折信号——某周期开始质疑方向 | 减仓或收紧止损 |
| 从 2->1 或 1->0 | 下降 | 趋势已明显减弱 | 平仓观望 |
| 从 0->1->2->3->4 | **上升** | 突破确认中——共识在建立 | 跟随建仓 |
| 0 附近持续 | 稳定 | 震荡市 | 不参与或做震荡策略 |

### 4.5 PnL 斜率 —— 市场的投票机

**定义**：PnL 曲线的近期斜率。PnL 是市场对当前信号方向的"投票结果"。

**计算方式**：
```
PnL_slope = (pnl[-1] - pnl[-10]) / 100  # 最近10 bar 的 PnL 变化（百分比）
PnL_decelerating = abs(近期斜率) < abs(更早期斜率) * 0.5  # 动量减速预警
```

**3690 中的实际值**：

| 视图 | 多头 PnL 变化 | 空头 PnL 变化 | 市场在奖励谁？ |
|------|-------------|-------------|-------------|
| v0 | 125.67 -> 123.82 (-1.47%) | 100.00（不变） | 做多在亏钱 |
| v1 | 100.00（不变） | 125.20 -> 121.76 (-2.75%) | 做空在回吐（反弹段） |
| v2 | 100.00 -> 103.32 (+3.32%) | 115.10 -> 115.33 (+0.20%) | 多空都有小赚 |
| v3 | 101.08 -> 101.04 (-0.04%) | 100.00 -> 105.28 (+5.28%) | **做空在大赚** |

**3690 验证**：
- v3 空头 PnL 斜率一致向上（+5.28%），v3 做空止盈每笔 +1.34%
- v3 多头 PnL 几乎持平（-0.04%），做多止盈每笔仅 +0.34%
- 同一 15 分钟视图上，做空止盈是做多的 **4 倍**
- v1 空头回撤 -2.75% 对应 P5 反弹阶段——是假反弹导致的利润回吐

**识别规则**：

| PnL 状态 | 信号状态 | 这意味着 |
|---------|---------|---------|
| 空头 PnL 持续上升，多头 PnL 持平 | 所有信号 | **市场在奖励做空**——空头是正确方向 |
| PnL 斜率开始走平 | 信号同向 | 当前信号方向的市场效率在降低——信号在失效 |
| PnL 方向与信号方向不一致 | — | **信号不可信**——市场用钱投了反对票 |
| PnL 单 bar 出现 > 3% 的回撤 | — | 查该 bar 的信号翻转——可能是假反转造成的强制平仓 |

**最重要的原则**：当信号和 PnL 打架时，相信 PnL。PnL 是市场用真金白银投的票，信号只是数学模型。

## 5. 一键分析脚本

以下是最小可用版本——换一个 parquet 文件就能跑。

### 5.1 脚本

```python
#!/usr/bin/env python3
"""
股票变化逻辑一键分析脚本
用法: python3 analyze.py <session_dir>
示例: python3 analyze.py backtest_output/3690_20260727-223514-3690
"""

import json, sys, warnings
from pathlib import Path
import numpy as np
import pandas as pd

warnings.filterwarnings("ignore")

SESSION_DIR = sys.argv[1] if len(sys.argv) > 1 else "."


def load(session_dir):
    sd = Path(session_dir)
    df = pd.read_parquet(sd / "backtest_result.parquet")
    meta = json.load(open(sd / "metadata.json")) if (sd / "metadata.json").exists() else {}
    v2l = meta.get("view_labels", {})
    return df, meta, v2l


def macro_scan(df, v2l):
    """第一层：30秒宏观扫描"""
    print("=" * 60)
    print("【第一层】宏观扫描")
    print("=" * 60)

    n = len(df)
    print(f"数据: {n} bar | {df['bar_timestamp'].iloc[0]} ~ {df['bar_timestamp'].iloc[-1]}")
    print(f"价格: {df['close'].min():.2f} ~ {df['close'].max():.2f} | 涨跌: {df['close'].iloc[-1] - df['close'].iloc[0]:+.2f}")

    # 粗周期信号
    for v in ["v0", "v1"]:
        sig = df[f"{v}_sig"]
        recent = sig.iloc[-20:]
        dom = recent.mode().iloc[0] if not recent.mode().empty else 0
        flip_count = (recent.diff().fillna(0) != 0).sum()
        lbl = v2l.get(v, v)
        print(f"  {lbl}({v}): 主导={dom:+d} | 翻转={flip_count}次 | "
              f"多={(recent==1).mean():.0%} 空={(recent==-1).mean():.0%} 观={(recent==0).mean():.0%}")

    # eps 趋势
    print("\neps 趋势:")
    for v in ["v0", "v1", "v2", "v3"]:
        eps = df[f"{v}_eps"]
        s5, s20 = eps.iloc[-5:].mean(), eps.iloc[-20:].mean() if n >= 20 else eps.mean()
        ratio = s5 / s20 if s20 > 0 else 1
        trend = "↑放大" if ratio > 1.1 else ("↓收缩" if ratio < 0.9 else "→稳定")
        lbl = v2l.get(v, v)
        print(f"  {lbl}({v}): eps={eps.iloc[-1]:.4f} | 趋势={trend} | ratio={ratio:.2f}")

    # 跨周期一致性
    print("\n跨周期矛盾检测:")
    coarse = df["v0_sig"]
    fine = df["v1_sig"]
    both = (coarse != 0) & (fine != 0)
    if both.sum() > 0:
        conflict = (coarse[both] != fine[both]).sum()
        rate = conflict / both.sum()
        flag = "⚠️ 严重" if rate > 0.5 else ("△ 中等" if rate > 0.2 else "✓ 一致")
        print(f"  {v2l.get('v0','v0')} vs {v2l.get('v1','v1')}: 矛盾率={rate:.1%} {flag}")

    # PnL 总览
    print("\nPnL 总览:")
    print(f"  {'视图':<8} {'周期':<8} {'多头':>10} {'空头':>10} {'赢家':>8}")
    for v in ["v0", "v1", "v2", "v3"]:
        lr = df[f"{v}_pnl_long"].iloc[-1] - 100
        sr = df[f"{v}_pnl_short"].iloc[-1] - 100
        w = "多头" if lr > sr else "空头"
        print(f"  {v:<8} {v2l.get(v,v):<8} {lr:>+8.2f}% {sr:>+8.2f}% {w:>8}")


def turning_points(df, v2l):
    """第二层：转折点定位"""
    print("\n" + "=" * 60)
    print("【第二层】转折点定位")
    print("=" * 60)

    for v in ["v0", "v1", "v2", "v3"]:
        sig = df[f"{v}_sig"]
        flips = (sig.diff().fillna(0) != 0)
        flip_idx = df.index[flips]
        lbl = v2l.get(v, v)

        if len(flip_idx) == 0:
            print(f"  {lbl}({v}): 无翻转")
            continue

        # 列出翻转
        flip_info = []
        for i in flip_idx:
            pos = df.index.get_loc(i)
            fr = int(sig.iloc[max(0, pos - 1)])
            to = int(sig.iloc[pos])
            flip_info.append(f"bar{df['bar_index'].iloc[pos]}:{fr}→{to}")

        # 信号持续期统计
        runs, cur_start, cur_sig = [], 0, sig.iloc[0]
        for i in range(1, len(sig)):
            if sig.iloc[i] != cur_sig:
                if cur_sig != 0:
                    runs.append(i - cur_start)
                cur_start, cur_sig = i, sig.iloc[i]
        avg_dur = np.mean(runs) if runs else 0

        dur_judge = "极不稳定" if avg_dur <= 3 else ("不稳定" if avg_dur <= 5 else (
            "稳定" if avg_dur <= 15 else "极稳定"))
        print(f"  {lbl}({v}): {len(flip_idx)}次翻转 | 平均持续={avg_dur:.1f}bar({dur_judge})")
        print(f"    最近5次: {flip_info[-5:]}")


def forward_indicators(df, v2l):
    """前瞻指标计算"""
    print("\n" + "=" * 60)
    print("【前瞻指标】5个先行指标")
    print("=" * 60)

    n = len(df)

    for v in ["v1", "v2"]:  # 聚焦主要交易周期
        lbl = v2l.get(v, v)
        eps = df[f"{v}_eps"]
        sig = df[f"{v}_sig"]
        filtered = df[f"{v}_filtered"]

        # 1. EPS 压缩比
        s5, s20 = eps.iloc[-5:].mean(), eps.iloc[-20:].mean() if n >= 20 else eps.mean()
        eps_ratio = s5 / s20 if s20 > 0 else 1

        # 2. 信号持续期趋势
        runs = []
        cs, cl = sig.iloc[0], 0
        for i in range(1, len(sig)):
            if sig.iloc[i] != cs:
                if cs != 0: runs.append(i - cl)
                cs, cl = sig.iloc[i], i
        dur_trend = "—"
        if len(runs) >= 10:
            ra = np.mean(runs[-5:])
            ea = np.mean(runs[:-5])
            dur_trend = "↓缩短" if ra < ea * 0.7 else ("↑延长" if ra > ea * 1.3 else "→稳定")

        # 3. Filtered 斜率
        if n >= 10:
            s_rec = (filtered.iloc[-1] - filtered.iloc[-5]) / filtered.iloc[-5]
            s_old = (filtered.iloc[-6] - filtered.iloc[-10]) / filtered.iloc[-6]
            slope_warn = abs(s_rec) < abs(s_old) * 0.3
        else:
            s_rec, slope_warn = 0, False

        # 4. 多周期共识
        consensus = pd.Series(0, index=df.index)
        for vi in ["v0", "v1", "v2", "v3"]:
            if f"{vi}_sig" in df.columns:
                consensus += df[f"{vi}_sig"].fillna(0).astype(int)
        c_rec = consensus.abs().iloc[-10:].mean()
        c_old = consensus.abs().iloc[-30:-10].mean() if n >= 30 else c_rec
        c_trend = "发散" if c_rec < c_old * 0.9 else ("收敛" if c_rec > c_old * 1.1 else "稳定")

        # 5. PnL 动量
        pnl_key = f"{v}_pnl_long" if sig.iloc[-1] == 1 else f"{v}_pnl_short"
        pnl = df[pnl_key]
        pnl_rec = (pnl.iloc[-1] - pnl.iloc[-min(10, n)]) / 100 if n >= 10 else 0
        pnl_old = (pnl.iloc[-min(11, n)] - pnl.iloc[-min(20, n)]) / 100 if n >= 20 else 0
        pnl_decel = abs(pnl_rec) < abs(pnl_old) * 0.5 if pnl_old != 0 else False

        print(f"\n  {lbl}({v}):")
        print(f"    1. EPS压缩比: {eps_ratio:.2f} {'⚠️极度压缩' if eps_ratio < 0.3 else '⚠️放大' if eps_ratio > 1.3 else ''}")
        print(f"    2. 信号持续期: {dur_trend}")
        print(f"    3. Filtered斜率: {s_rec:+.4%} {'⚠️趋零' if slope_warn else ''}")
        print(f"    4. 多周期共识: {c_trend} (强度={c_rec:.1f})")
        print(f"    5. PnL动量: {pnl_rec:+.2f}% {'⚠️减速' if pnl_decel else ''}")

        # 综合预警
        w = sum([eps_ratio > 1.3 or eps_ratio < 0.3, dur_trend == "↓缩短", slope_warn,
                 c_trend == "发散", pnl_decel])
        if w >= 3:
            print(f"    ⚠️ 高概率状态变化 ({w}/5)")
        elif w >= 1:
            print(f"    △ 存在变化风险 ({w}/5)")
        else:
            print(f"    ✓ 当前状态稳定")


def signal_validation(df, v2l):
    """第三层：信号有效性验证"""
    print("\n" + "=" * 60)
    print("【第三层】信号有效性验证")
    print("=" * 60)

    for v in ["v0", "v1", "v2", "v3"]:
        lbl = v2l.get(v, v)
        sig = df[f"{v}_sig"]
        close = df["close"]

        entries = df[(sig != sig.shift(1)) & (sig != 0) & (sig.shift(1).fillna(0).astype(int) == 0)]
        if len(entries) == 0:
            print(f"  {lbl}({v}): 无入场信号")
            continue

        results = {"signal": [], "hit_5": [], "hit_10": [], "hit_20": [], "chg_20": []}
        for idx in entries.index:
            es = sig[idx]
            ec = close[idx]
            results["signal"].append(int(es))
            for nb, k in [(5, "hit_5"), (10, "hit_10"), (20, "hit_20")]:
                fi = min(idx + nb, len(df) - 1)
                chg = (close.iloc[fi] - ec) / ec
                results[k].append((es == 1 and chg > 0) or (es == -1 and chg < 0))
            results["chg_20"].append((close.iloc[min(idx + 20, len(df) - 1)] - ec) / ec * 100)

        dr = pd.DataFrame(results)
        n_sig = len(dr)
        print(f"\n  {lbl}({v}): {n_sig}次入场")
        for side, sd in [("多头", dr[dr["signal"] == 1]), ("空头", dr[dr["signal"] == -1])]:
            if len(sd) == 0: continue
            print(f"    {side}({len(sd)}次): "
                  f"5bar={sd['hit_5'].mean():.0%} "
                  f"10bar={sd['hit_10'].mean():.0%} "
                  f"20bar={sd['hit_20'].mean():.0%} "
                  f"均价变={sd['chg_20'].mean():+.2f}%")


def main():
    df, meta, v2l = load(SESSION_DIR)
    print(f"视图映射: {v2l}")
    print(f"数据形状: {df.shape[0]}行 x {df.shape[1]}列\n")

    macro_scan(df, v2l)
    turning_points(df, v2l)
    forward_indicators(df, v2l)
    signal_validation(df, v2l)

    print(f"\n{'='*60}")
    print("分析完成。")
    print(f"数据窗口: {len(df)} bar → {'仅定性扫描' if len(df) < 100 else '可定量分析'}")


if __name__ == "__main__":
    main()
```

## 6. 从 3690 学到什么（可迁移到下一支股票）

### 6.1 这次分析的核心认知

**认知 1：时间框架矛盾是最大的信息源**

当周线和日线方向相反时，你不是看到了"噪声"——你看到的是**趋势转换的现场直播**。矛盾本身就包含信息：粗周期代表惯性（历史趋势的余威），细周期代表边际变化（正在发生的转折）。

3690 上，周线看多 + 日线看空 = 惯性向上 + 边际向下 = 最终向下。

**认知 2：PnL 比信号更诚实**

信号是数学模型的计算结果，PnL 是市场的投票结果。当两者冲突时，PnL 是对的。

3690 上，v3 做空 PnL 从 100 涨到 105.28（+5.28%），做多 PnL 几乎不动（-0.04%）。不需要看任何其他指标，仅凭 PnL 就知道正确方向是做空。

**认知 3：EPS 压缩是能量积蓄，不是止跌**

新手看到 eps 收窄会以为是"市场平静了"。实际上，在趋势市中 eps 压缩 = 弹簧被压到极限 = 即将向趋势方向释放。

3690 上，v3 eps 压缩 80% 后价格加速下跌。eps 收窄事件的后续平均收益全部为负。

**认知 4：周线 long -> neutral 是"多头投降"，比直接转 short 更有信息量**

周线从看多变成观望，比直接变成看空更可怕——因为它意味着长线资金不再坚持原有观点，但还没有建立反向观点。这是一个"信念真空期"，趋势最容易加速。

3690 上，两次 long->neutral 后分别出现 -0.66% 和 -1.26% 的单 bar 暴跌。

**认知 5：49 笔交易全盈利不代表策略无风险**

100% 止盈率听起来完美，但这是"收获期"的特征——系统在平老仓而非开新仓。真正的风险在开仓阶段，不在平仓阶段。

### 6.2 下次看 AAPL / MSFT / 其他股票时的复用清单

**第一步（30 秒）**：
1. 打开 parquet，读 metadata.json 确认视图映射
2. 看 v0_sig 和 v1_sig 的最后 10 bar——同向还是反向？
3. 看 PnL 曲线——哪个方向在涨？

**第二步（5 分钟）**：
4. 如果 v0 和 v1 矛盾 --> 这就是关键观察窗口，进入深层分析
5. 如果 v0 和 v1 一致 --> 看 eps 趋势（稳定 = 趋势持续；变化 = 注意转折）
6. 看 v3 eps 是否在压缩 --> eps 压缩比 < 0.5 = 能量积蓄中

**第三步（如果时间允许）**：
7. 跑一键脚本，看 5 个前瞻指标的综合预警数
8. 如果预警数 >= 3 --> 高概率即将发生状态变化
9. 如果预警数 0-1 --> 当前状态稳定，按趋势方向操作

**第四步（形成认知）**：
10. 写下一句话："这支股票最有效的信号是 XXX，最大的噪声来源是 XXX"
11. 这句话就是你下次看同类股票时的"第一眼"检查项

### 6.3 方法论的边界

| 局限 | 含义 | 应对 |
|------|------|------|
| 数据量 < 100 bar | 统计指标无意义 | 仅做定性扫描 |
| eps 是波动率代理，非真实波动率 | 不要和 ATR/布林带混淆 | 比较 eps 的趋势方向，不比较绝对值 |
| filtered 有滞后性（Savgol 窗口） | 斜率零点是确认而非预测 | 配合 eps 变化率使用 |
| 单边强趋势中无信号翻转 | 转折点检测全失效 | 换用趋势强度评估方法 |
| 参数（k_eps）不同则 eps 不可比 | 跨 session 的 eps 绝对值无意义 | 比较 eps 变化率而非绝对值 |

## 附录 C：信号状态快速判断流程

```
拿到 Parquet 数据
    │
    ├─ 读 metadata.json 获取 view_labels 映射
    │
    ├─ 看粗周期(周/日)的 v{i}_sig 最近值
    │   ├─ 全 +1 → 强上涨 → 查 eps 趋势: 稳定=持仓, 上升=注意筑顶
    │   ├─ 全 -1 → 强下跌 → 查 eps 趋势: 稳定=持仓, 上升=注意筑底
    │   ├─ 矛盾(部分+1 部分-1) → 转折窗口 → 查传导方向(细→粗 or 粗→细)
    │   └─ 全 0 → 震荡 → 查 eps 是否开始上升(突破前兆)
    │
    ├─ 查 v{i}_pnl_long/short 的最近斜率
    │   ├─ PnL 方向与 sig 一致 → 信号有效
    │   └─ PnL 方向与 sig 不一致 → 信号在失效 ← 相信 PnL
    │
    └─ 形成判断: 当前状态 + 置信度
```
