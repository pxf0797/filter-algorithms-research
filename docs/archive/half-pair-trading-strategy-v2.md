# 半边多空对交易策略（v2：C 周期多空对门控）

> 起点即入场（不等锁定），C 周期多空对状态定生死，核心仍在离场

---

## 一、核心认知：永远在操作半边多空对

**一句话：** 不管是回测推进还是实时交易，你永远站在窗口最右边缘，当前正在走的那段多空对永远只有起点、没有终点——这就是"半边"，它不是特殊情况，它是唯一现实。

### 1.1 什么是多空对，什么是"半边"

**多空对（Pair）= 一段连续同向的趋势。** 它由三个要素定义：

| 要素 | 含义 | 来源 |
|------|------|------|
| 起点 | 趋势诞生的那一根 K 线（Sig 从 0 变为 ±1） | Schmitt 触发器状态转移 |
| 终点 | 趋势结束、反向趋势诞生的那一根 K 线 | 下一段反向段的起点 |
| 方向 | +1（多）或 -1（空） | 段内 Sig 的符号 |

起点和终点都有的，就是**完整多空对**——一段走完的历史，回看时涨到哪、跌到哪都已确定。当下正在走的这一段不一样：它有起点（趋势已诞生），却**没有终点**（谁也不知道它何时结束）。这种"有头无尾"的多空对，就是**半边多空对**。

```
完整多空对：  起点 ●━━━━━━━● 终点      （历史，已定型）
半边多空对：  起点 ●━━━━━━━▶ ???       （当下，还在走）
```

### 1.2 为什么说"永远"操作半边

**一句话：** 无论回测第几帧、还是实时此刻，最右边那个多空对永远是半边——因为"当下"这个位置，天然就是趋势还没走完的地方。

```
    过去 ◀─────────────────────────  现在
    │完整│完整│完整│完整│  半边 ▶ (你在这里)
     已定型 已定型 已定型 已定型   还在走
```

回测每前进一根 K 线，边缘右移一格，但"最右边那段是半边"这个事实从不改变。今天的半边明天可能走完、变成完整多空对被甩到左边，那时又会有**新的**半边出现在最右边。所以：**你操作的对象，永远、且只能是这个半边多空对。**

### 1.3 策略骨架（v2）

**一句话：** 半边的起点一出现就入场（靠 C 周期同向背书，不再等锁定），入场之后唯一要做的事就是判断怎么离场——离场是全部难点。

```
        永远操作半边多空对
                │
       ┌────────┴────────┐
       ▼                 ▼
   起点出现即入场        怎么离场
   （C同向背书）        = 核心
                       （三种机制 + 兜底）
```

**v2 相对 v1 改了两件事：**

1. **入场不再等"起点锁定"。** 起点一出现（Sig 0→±1）当帧就判，靠 C 同向过滤假信号，不靠时间等待。理由：等锁定要 3-5 根 K 线，趋势往往已走一大段，进场太晚意义不大。
2. **同向判断从看 C.Sig 改为看 C 的"多空对状态"（4 态）。** 不是看 C 某一帧的瞬时符号，而是判断 C 这一整段趋势的健康度：STRONG_ALIGN / WEAK_ALIGN / MISALIGN / NO_DIRECTION。重点处理中间态 WEAK_ALIGN——"C 离场信号已给但多空对未结束"（C 趋势衰竭中）。

下面：第二章讲新入场（不等锁定），第三章讲 C 多空对状态（新核心），第四、五章讲决策表与离场。

## 二、入场：起点即判定（不等锁定）⭐升级

### 2.1 为什么不等锁定

**一句话：** 等锁定 = 好几根 K 线过去 = 趋势已走一大段 = 可能已涨/跌很多 = 进场太晚意义不大；用 C 同向确认替代时间等待。

v1 要求"起点离开边缘区（锁定）"才入场，代价是延迟 3-5 根 bar。但趋势最值钱的就是起步那一段，等锁定往往错过它。v2 的思路是：**不再用时间换确定性，而用空间（C 周期背书）换确定性**——起点一诞生就判，让上级周期的同向趋势替我们过滤假信号。

### 2.2 入场时机与条件

**一句话：** B 半边起点一出现（Sig 0→±1）当帧判入场，唯一门槛是 C 多空对状态 = 强同向。

```
入场 IF:
    B 当前半边起点当帧诞生 (pair_start_B == i)      # 时机：0 延迟
    AND C_pair_state(dir_B, i) == STRONG_ALIGN      # 背书：C 强同向（默认）
    [可配置 allow_weak：WEAK_ALIGN 时降级入场/减仓]
```

- **时机**从"锁定后"提前到"起点当帧"，零延迟吃到趋势起步段。
- **门槛**从"起点锁定"换成"C 强同向"（STRONG_ALIGN，详见第三章）。这是 v2 的核心替换：确定性不再来自等待，而来自上级趋势的背书。

### 2.3 不锁定的风险与双重兜底

**一句话：** 不等锁定 = 起点可能是边缘区假信号（下一帧蒸发），这份风险由"入场时 C 背书"和"入场后快速刮损"两层兜底消化。

不锁定引入了一个新风险：起点可能是边缘区的闪烁噪声，几根 bar 后就消失。v1 靠"等锁定"对它天然免疫；v2 取消了等待，就必须补上兜底：

| 兜底 | 时点 | 机制 |
|------|------|------|
| 兜底① C 强同向确认 | 入场时 | B 单边假信号与"C 已有同向活跃半边"同时出现的概率，远低于 B 单独假信号。C 背书把假起点概率大幅压低。 |
| 兜底② 入场依据消失快速离场 | 入场后 | 若起点在边缘窗口内蒸发，立刻小损离场（`entry_void`，详见 5.5），把假起点的伤害限制在几根 bar 内。 |

一句话：**入场前用 C 挡掉大部分假起点，入场后用快速离场限制漏网假起点的损失。**

### 2.4 新旧入场对比

| 维度 | v1（等锁定） | v2（起点即入场） |
|------|------------|----------------|
| 入场时机 | 起点离开边缘区后（延迟 3-5 bar） | 起点诞生当帧（0 延迟） |
| 假信号防线 | 等锁定（时间成本换确定性） | C 强同向确认 + 事后快速离场 |
| 进场点位 | 趋势已走一段（可能已涨/跌很多） | 趋势起点（性价比最高） |
| 上级过滤单元 | C.Sig 或 dir_C（瞬时/粗糙） | **C 多空对状态**（4 态，含中间态） |
| 假起点残留风险 | 天然免疫（消失的起点等不到锁定） | 由快速离场兜底（限损几根 bar） |

## 三、同向判断：看 C 的多空对状态 ⭐升级（核心）

### 3.1 为什么不看 C.Sig 而看多空对状态

**一句话：** Sig 是瞬时值，一根 K 线就翻；多空对状态反映 C 这一整段趋势的健康度。

C.Sig 会在 0 和 ±1 之间抖动，用它判同向会被单帧噪声反复误导。更致命的是它**看不见"C 趋势即将衰竭"这个阶段**——C 的 +1 半边已经降速（Sig 掉回 0）或冒出反向苗头（短暂 -1 但未确认），此时 C 这段趋势正在尾部，B 若此刻入场 = 在 C 趋势末端上车，是最危险的进场。Sig 无法表达"活跃但衰竭中"这个中间层，多空对状态可以。

C 周期不是被动提供一个方向，而是**自己也在操作半边多空对**——它同样有起点、有活跃半边、也会给自己的离场信号。B 要判断的是 C 这个多空对**整体处于什么阶段**。

### 3.2 一个物理事实：C 趋势衰竭是渐进的

**一句话：** Schmitt 触发器永不 +1↔-1 直跳，必经 0；所以 C 转向必先降速→到 0→再反向，"C 正在走弱"是可观测的渐进过程，不是突变。

这是整个状态模型的物理地基。读码确认：`_schmitt_trigger` 的状态机里，`+1→0` 的条件是加速度掉头（`a<-ε`），而建立 `-1` 还要再等 `a<-ε AND v<0`。这个天然的"先降速到 0、再反向"两段式，意味着：

```
C 的 +1 半边由盛转衰的真实路径：
   健康奔跑            降速             反向确认
   Sig=+1  ───────▶  Sig=0  ───────▶  Sig=-1(连续N根)
   STRONG_ALIGN      WEAK_ALIGN        MISALIGN
   （满速）          （尾部衰竭中）    （已翻向）
```

**关键结论：中间态不是硬造出来的，它是触发器里天然存在的物理阶段。** 既然 C 不可能从满速多头瞬间跳成满速空头，那么"C 正在衰竭"就一定有可观测的物理表现（先降速到 0），我们只要把这个阶段量化出来即可。

### 3.3 C 周期多空对的四种状态

**一句话：** 先取 C 当前半边方向 dir_C，再看它是否已给离场信号，组合成 4 态。

先定义 C 当前半边方向 `dir_C`（= 最右侧已确认的合并非零段符号；无活跃非零段则 dir_C=0），相对 B 的方向 `d_B`：

| 状态 | 定义 | 语义 | 对 B 入场 |
|------|------|------|----------|
| **STRONG_ALIGN** | dir_C == d_B 且未给离场信号 | C 有活跃同向半边、健康奔跑、未露衰竭 | ✅ 入场 |
| **WEAK_ALIGN** | dir_C == d_B 且已给离场信号 | C 同向但趋势尾部衰竭中（未正式结束） | ⚠️ 降级/减仓/不入 |
| **MISALIGN** | dir_C == -d_B | C 活跃半边方向相反，或 C 已确认翻向 | ❌ 不入场 |
| **NO_DIRECTION** | dir_C == 0 | C 无活跃非零半边，观望中、方向未表态 | ❌ 无背书，保守不入 |

只有 STRONG_ALIGN 是打开入场的钥匙；MISALIGN、NO_DIRECTION 明确不入；WEAK_ALIGN 是需要重点处理的灰区。

### 3.4 中间态 WEAK_ALIGN：离场信号已给但未结束（重点）

**一句话：** C 同向（dir_C 仍等于 d_B），但已露出结束前兆——B 此时入场 = 在 C 尾部进场，高风险。

这是整个模型的核心。C 的同向半边尚未正式结束（dir_C 没翻），但已经在衰竭。3.2 说过衰竭是渐进、可观测的，我们用**两个严格可量化的硬检测器**把它抓出来：

**检测器 A — 反转预警（reversal_warning）：C 反向苗头已冒但未确认**

```
reverse_run = 末尾连续 sign == -dir_C 的 bar 数（截至 i_C）
IF 0 < reverse_run < N_confirm:
    reversal_warning = True     # 反向苗头已现，但 dir_C 尚未翻（未结束）
```

> 注：一旦 `reverse_run >= N_confirm`，C 的离场①触发、dir_C 翻转 → 已经是 MISALIGN，不再属于中间态。所以中间态里 reverse_run 恒 < N_confirm，两个状态的边界严丝合缝、不重叠。

**检测器 B — 破位预警（deviation_warning）：C 趋势不利偏离超阈**

```
pred_val_C(i_C) = C 半边预测轨道值（_fit_physics_parabola）
signed_dev = 不利方向偏离
           = (dir_C=+1) (pred_val - price)/pred_val
           = (dir_C=-1) (price - pred_val)/pred_val
IF signed_dev > MAX_DEV_PCT_C:
    deviation_warning = True    # C 离场②已触发，但 Sig 未反转（未结束）
```

**软检测器（可选）— 降速预警（decel_warning）：C.Sig 从 dir_C 掉回 0**

```
IF sig_C[i_C] == 0 AND last_nonzero_sign(C, i_C) == dir_C:
    decel_warning = True        # 加速度掉头，趋势降速但未反向
```

三者取或即"C 已给离场信号但多空对未结束"：

```
c_exit_signal_given = reversal_warning OR deviation_warning [OR decel_warning]
→ 为 True 且 dir_C==d_B 时，状态 = WEAK_ALIGN
```

**为什么 WEAK 要谨慎？** 因为 B 若在此时入场，等于在 C 趋势的尾部上车：C 随时可能反向确认（转 MISALIGN），把 B 的半边连根拔起。所以默认对 WEAK **降级或不入**（`allow_weak_entry` 控制），宁可错过也不在 C 尾部冒险。

### 3.5 C 状态判定流程

```
                    ┌─────────────────────┐
                    │  取 dir_C（当前半边） │
                    └──────────┬──────────┘
                               ▼
                     dir_C == 0 ? ──是──▶ NO_DIRECTION
                               │否
                               ▼
                  dir_C == -d_B ? ──是──▶ MISALIGN（已确认反向）
                               │否 (dir_C == d_B)
                               ▼
              ┌────────────────────────────────┐
              │ 中间态检测：                     │
              │  A 反转预警 0<reverse_run<N_conf│
              │  B 破位预警 signed_dev>MAX_DEV_C│
              │  C 降速预警 sig_C==0（软，可关）│
              └───────────────┬────────────────┘
                              ▼
                任一为真 ? ──是──▶ WEAK_ALIGN（尾部衰竭中）
                              │否
                              ▼
                          STRONG_ALIGN（健康奔跑）
```

`dir_C` 复用 `_find_all_pairs` 的收集非零段 + 跨零合并逻辑，取截至 i_C 最后一个合并段的符号；若反向尾巴已达 N_confirm，则反向段成为当前半边（dir_C 已翻）。这保证"翻转确认"与"中间态"边界一致、不重叠。

## 四、入场决策表（升级版）

**一句话：** B 半边方向（当帧起点）× C 多空对状态（4 态）→ 入场/降级/不入场。

| # | B 起点当帧 | C 多空对状态 | 决策 | 原因 |
|---|-----------|-------------|------|------|
| 1 | 是 | STRONG_ALIGN | ✅ 入场（满仓） | C 同向健康奔跑，最可靠 |
| 2 | 是 | WEAK_ALIGN | ⚠️ 降级：`allow_weak` 开→半仓+紧离场；关→不入 | C 同向但已衰竭，在 C 尾部进场高风险 |
| 3 | 是 | MISALIGN | ❌ 不入场 | 逆 C 大势的反弹，不参与 |
| 4 | 是 | NO_DIRECTION | ❌ 不入场（默认保守） | C 无背书，B 单边假信号风险裸奔 |
| 5 | 否（非起点帧） | 任意 | — 不判入场 | 仅在起点当帧判入场 |

只有第 1 行是无条件入场；第 2 行是可配灰区；3/4/5 均不入场。

**与 v1 决策表的关键差异：** v1 有一行"起点未锁定 → 等待锁定"，v2 **取消了这一行**——起点当帧就判，不存在"等锁定"。同时上级过滤单元从 v1 的"C 方向（同向/观望/反向）3 分类"升级为"C 多空对状态 4 态"，多出的正是中间态 WEAK_ALIGN。

## 五、离场：策略的核心（三种机制）

### 5.1 为什么离场更重要了

**一句话：** 入场时看的是起点（看得见），离场时要判断终点（看不见、还没发生）；v2 不锁定后，假起点风险后移到离场兜底，离场比 v1 更吃重。

入场是"确认一个已存在的事实"，离场是"预判一个尚未发生的事件"——这是不对称的根源，也是策略全部智慧所在。v2 取消等锁定后，边缘假起点的风险从"入场前拦截"改为"入场后快速离场兜底"，所以离场网多了一道 `entry_void`。升级后的离场优先级：

| 优先级 | 离场机制 | 触发（v2） |
|--------|---------|-----------|
| 1（最高） | ③ 上级反向 | **C 多空对状态 → MISALIGN**（非 C.Sig 瞬时翻） |
| 2 | 入场依据消失（新增） | 边缘窗口内 B 起点蒸发（见 5.5） |
| 3 | ② 趋势偏离 | B 不利偏离 > MAX_DEV，全程 |
| 4 | ① 进入下一多空对 | B 反向段 ≥ N_confirm |
| （保留） | 预测保护期止损 | 入场初期击穿轨道 |

### 5.2 离场①：进入下一个多空对（趋势反转）

**一句话：** 当前多头半边，若 Sig 翻 -1 并连续持续 N_confirm 根，新空头半边诞生、取代当前半边，本级趋势反转，止盈离场。

```
reverse_run = 连续反向 Sig 的 bar 数
IF reverse_run ≥ N_confirm（默认 2）:
    → 确认进入下一多空对，离场（take_profit）
```

N_confirm 缓冲滤掉边缘区的单 bar 噪声翻转，代价是回吐 1-2 根 bar 利润。

### 5.3 离场②：趋势偏离过大（全程生效）

**一句话：** 价格不利偏离预测轨道超阈，说明趋势破位，离场——只看不利方向。

```
deviation(i) = |实际价格 - pred_val| / pred_val   （仅取不利方向）
IF deviation > MAX_DEV_PCT（默认 4%）:
    → 趋势破位，离场（trend_deviation）
```

做多只惩罚跌破上升轨道，涨超预测是好事、继续奔跑；做空反之。与"预测保护期止损"互补：保护期止损只管入场初期防错方向，趋势偏离离场管整个持仓期。

### 5.4 离场③：上级反向——改用 C 多空对状态（非 C.Sig）⭐升级

**一句话：** v1 认 C.Sig 瞬时翻就走（易被单帧噪声误触）；v2 只有 C 状态 = MISALIGN（已确认反向）才触发，WEAK_ALIGN 只收紧不强退。

```
持仓期每帧重算 c_pair_state(dir_持仓, i):
    == MISALIGN     → 🚪 立即离场（离场③，最高优先级，战略否定）
    == WEAK_ALIGN   → ⚠️ 不强制离场，只收紧其余阈值
                       （可选：MAX_DEV_PCT 减半 / 提前止盈）
    == STRONG_ALIGN → 继续持有
    == NO_DIRECTION → ⚠️ 背书消失，默认继续持有，靠 ①②兜底
```

要点：**只有 MISALIGN 才触发离场③。** WEAK_ALIGN（C 衰竭中但未反）不强制离场，只做风险收紧——避免被 C 的中间态噪声频繁甩出正常持仓。这正是"用状态而非 Sig"的价值：Sig 一抖就走会过度交易，状态模型能区分"真反向（MISALIGN）"与"衰竭波动（WEAK）"。

### 5.5 新增离场：入场依据消失（entry_void 快速离场）

**一句话：** 不锁定入场的配套兜底——若边缘窗口内 B 起点蒸发，立刻小损离场，把假起点损失限制在几根 bar。

```
edge_window = 边缘区宽度（默认 3~5 bar，= 旧锁定所需根数）
入场后，对 i in [entry+1, entry+edge_window]:
    dir_now = current_half_pair_direction(sig_B, i)   # 重算当前半边方向
    IF dir_now != entry_dir:          # 起点方向不再是入场方向 = 起点蒸发
        exit_idx = i
        exit_reason = "entry_void"    # 依据消失，快速小损离场
        break
```

**与离场①（take_profit）区分：** 离场①是趋势正常走完后才反转，`entry_void` 是趋势根本没成立——入场时赌"这个起点是真的"，若边缘窗口内 B 当前半边方向已不是入场方向（Sig 塌回 0 未复位或直接冒反向），说明当初那个起点是边缘噪声，立即快速刮损。edge_window 外不再检查（此时半边已站稳，回归常规三离场）。

## 六、完整决策流程

**一句话：** 每帧，无仓就查"起点当帧 + C 强同向"决定是否入场，有仓就按优先级跑离场网（含 entry_void）决定走或留。

```
┌──────────────────────────────────────────────────┐
│ 每帧 i：算各周期 Sig，识别 B 当前半边，              │
│         对 C 也算多空对状态 c_pair_state           │
└───────────────────────┬──────────────────────────┘
                        ▼
               ┌────────────────┐
               │  当前是否持仓？  │
               └───┬────────┬───┘
              无仓 │        │ 有仓
                   ▼        ▼
   ┌────────────────────┐  ┌────────────────────────────────┐
   │   入场判定（v2）     │  │  离场判定（按优先级 if-elif）      │
   ├────────────────────┤  ├────────────────────────────────┤
   │ B 起点当帧诞生？     │  │ 优1 C状态==MISALIGN？→离场（③）  │
   │   ├ 否 → 不判       │  │ 优2 边缘窗口内起点蒸发？→entry_void│
   │   └ 是 ↓           │  │ 优3 不利偏离>MAX_DEV？→离场（②）  │
   │ C 多空对状态？       │  │ 优4 反向段≥N_confirm？→离场（①） │
   │   ├ STRONG→✅入场   │  │ （保护期止损：初期击穿→离场）      │
   │   ├ WEAK →⚠️降级/不 │  │ （WEAK：不强退，只收紧阈值）       │
   │   ├ MISALIGN→❌不入 │  │ 否则 → 继续持有                  │
   │   └ NO_DIR →❌不入  │  └────────────────────────────────┘
   └────────────────────┘
                   │
                   ▼
           记录交易 / 更新 PnL
```

**要点：** 入场分支去掉了 v1 的"起点锁定"判断，改为 C 多空对状态门控；有仓分支在离场网顶部加了 C 状态版离场③和 entry_void 检查。单持仓模型，同帧不同时开多仓。

## 七、实战走查（bar 级，升级场景）

以下 Sig 来自 Schmitt 触发器（+1 多 / 0 观望 / -1 空）。

### 场景 1：起点即入场，C 强同向 ✅

```
B (60分钟)：新多头半边诞生，起点当帧（pair_start == i），未等锁定
C (日线)：  dir_C = +1，无反转/破位预警 → STRONG_ALIGN

判定：起点当帧 ✓ + C STRONG_ALIGN ✓ → ✅ 入场（做多）
解读：v2 标准入场。零延迟吃到趋势起步段，C 健康奔跑背书压低假信号概率。
      v1 此刻还在"等锁定"，要再等 3-5 根才进，趋势已走一段。
```

### 场景 2：C 弱同向（离场信号已给），降级不入 ⚠️

```
B (60分钟)：新多头半边起点当帧
C (日线)：  dir_C = +1（仍同向），但末尾出现 1 根 Sig=-1
           → 0 < reverse_run(1) < N_confirm(2) → reversal_warning
           → C 状态 = WEAK_ALIGN

判定：allow_weak 关（默认）→ ❌ 不入场
解读：C 虽仍是多头，但已冒反向苗头、趋势尾部衰竭中。此刻入场 = 在 C 尾部
      上车，C 一旦反向确认会连根拔起 B。宁可错过，不在 C 尾部冒险。
```

### 场景 3：进入下一多空对，离场 ①

```
持仓：多头，已持有 8 bar，C 仍 STRONG_ALIGN
B：连续 2 根 Sig=-1（reverse_run=2 ≥ N_confirm）

判定：反向段 ≥ 2 → ✅ 确认进入下一多空对 → 🚪 离场（take_profit）
解读：本级趋势正常反转，多头旅程走完，止盈。N_confirm=2 已滤掉单 bar 噪声。
```

### 场景 4：趋势偏离过大，离场 ②

```
持仓：多头，价格本应沿上升预测轨道走
B：实际价格跌破轨道，不利偏离 5% > MAX_DEV_PCT(4%)

判定：signed_dev = 5% > 4% → 🚪 离场（trend_deviation）
解读：Sig 还没翻，但价格已明显脱离上升轨道——动能失效，提前离场。
```

### 场景 5：C 转 MISALIGN，上级反向离场 ③（最高优先级）

```
持仓：多头，B.Sig 仍 = +1（本级还看多）
C (日线)：dir_C 的反向段已连续 ≥ N_confirm，dir_C 翻成 -1
         → C 状态 = MISALIGN（已确认反向，非瞬时抖动）

判定：C 状态 == MISALIGN → 🚪 立即离场（最高优先级，压过本级 +1）
解读：为 B 背书的日线大势已确认崩了，战略级否定。
      注意与 v1 的差别：v1 认 C.Sig 瞬时翻就走，若那是单帧噪声就误伤；
      v2 要求 C 走到 MISALIGN（反向确认）才走，中间的 WEAK 只收紧不强退。
```

### 场景 6：不锁定但假起点消失，entry_void 快速离场 🚪

```
入场：B 多头起点当帧 + C STRONG_ALIGN → 已入场（做多）
入场后第 2 bar（仍在 edge_window=3 内）：
   窗口推进重算，起点被算成 0，B 当前半边方向 dir_now ≠ entry_dir(+1)

判定：边缘窗口内起点蒸发 → 🚪 entry_void 快速小损离场
解读：这正是不锁定的代价与兜底。v1 靠"等锁定"对假起点天然免疫（根本没进）；
      v2 进了但用 entry_void 在几根 bar 内快速刮损，把伤害限制到极小。
```

## 八、与现有系统集成

**一句话：** 新增"当前半边识别 + C 多空对状态"函数，对 C 也算 4 态；改 `_compute_strategy_pnl` 的入场与离场支路；全部默认关闭，回测零回归。

### 8.1 新增 / 修改函数

| 改动 | 函数 | 说明 |
|------|------|------|
| **新增** | `_merge_segments(sig_t)` | 抽出 `_find_all_pairs` 的收集非零段+跨零合并逻辑，公共复用 |
| **新增** | `_find_current_half_pair(sig_t, N_confirm)` | 返回最右半边 `(pair_start, cur_idx, dir)`；反向尾达 N_confirm 归入新半边 |
| **新增** | `_c_pair_state(sig_C, price_C, fit_C, i_C, d_B, ...)` | 按第三章逻辑返回 4 态枚举 |
| **新增** | `_get_c_state_at(current_dates, c_dates, c_state_series, i)` | 复用 `_align_pnl_to_current_tf` 时间戳前向对齐，取当前帧 C 状态 |
| **改** | `_compute_strategy_pnl` | 加"起点当帧+C 强同向"入场支路；离场按新优先级（含 entry_void、C 状态版离场③）；参数默认关闭，旧行为逐字节复现 |
| **不改对外** | `_find_all_pairs` | 仅内部改调 `_merge_segments`，保护回测确定性 |

### 8.2 关键代码事实

- `_find_all_pairs` 用 `range(len(merged)-1)` 遍历，**只返回完整多空对，最右半边永远进不了列表** → 必须新增"当前半边识别"。
- `_schmitt_trigger` 的 Sig 永不 +1↔-1 直跳、必经 0，是中间态 WEAK_ALIGN 的物理基础（第 3.2 节）。
- 现 `_compute_strategy_pnl` 离场只认"Sig 完全反转"，不认"降速到 0" → 升级版要把中间态显式变成可观测状态。

### 8.3 C 多空对状态如何获取

对 C 周期**也运行一遍半边识别 + 离场信号计算**（而不仅取 dir_C）：

```
1. C 周期同样跑 _schmitt_trigger 得 sig_C、price_C
2. 对 C 当前半边跑 _fit_physics_parabola 得预测轨道 fit_C（供破位预警）
3. 逐帧算 c_state_series[j] = _c_pair_state(...)，得 C 时间轴状态序列
4. B 每帧 i 通过 _get_c_state_at 前向对齐到最近 C bar，取该帧 C 状态
   → 用于入场门控（第四章）与离场③（5.4）
```

### 8.4 关键超参与向后兼容

| 超参 | 作用 | 默认 |
|------|------|------|
| `N_confirm` | 反向确认根数（决定"反转预警"vs"已反向"边界） | 2 |
| `MAX_DEV_PCT` / `MAX_DEV_PCT_C` | B/C 趋势偏离阈 | 4% |
| `edge_window` | 入场依据消失检查窗口（= 旧锁定根数，现只用于事后兜底） | 3~5 |
| `allow_weak_entry` | WEAK_ALIGN 是否降级入场 | False |
| `use_decel` | 是否把 C.Sig→0 计入 WEAK 中间态 | False |

全部新支路走"增量 + 默认关闭"，关掉开关后系统逐字节复现现有行为——**回测基线零回归是第一道验证。**

## 九、优势与下一步

### 优势

- **入场及时，不错过趋势前段。** 起点当帧即入场，零延迟吃到趋势起步的黄金段，不再为"等锁定"付出 3-5 根 bar 的进场滞后。
- **C 多空对状态比 C.Sig 精确。** 从"一个瞬时符号"升级为"一个有 4 态的多空对状态机"，能区分 C 的"健康奔跑"、"尾部衰竭"、"已反向"，不被单帧噪声误导。
- **中间态预警避免 C 尾部进场。** WEAK_ALIGN 用两个硬检测器（反转预警 + 破位预警）抓住 C 趋势的渐进衰竭，把最危险的"C 末端上车"挡在门外。
- **假起点由 entry_void 兜底。** 不锁定引入的假起点风险，由"入场时 C 背书 + 入场后快速刮损"双重消化，限损到几根 bar。
- **离场③更稳。** 从认 C.Sig 瞬时翻改为认 C 状态 MISALIGN，WEAK 只收紧不强退，避免中间态噪声频繁甩出正常持仓、减少过度交易。

### 下一步（MVP）

```
1. 起点即入场      —— 识别 B 当前半边 + C 多空对状态门控（STRONG_ALIGN）
2. C 状态模型      —— 4 态判定，含中间态 WEAK_ALIGN 两检测器
3. entry_void 兜底 —— 不锁定的假起点快速刮损离场
4. 离场③升级      —— C 状态版（MISALIGN 才强退，WEAK 只收紧）
```

参数调优聚焦：`N_confirm`（中间态边界）、`MAX_DEV_PCT_C`（C 破位阈）、`edge_window`（假起点窗口）、`allow_weak_entry`（灰区开关）。回测对比"v2 策略 vs v1 vs 基线"的胜率、交易次数、最大回撤、Sharpe，量化每一层的边际贡献；先验证关掉全部开关时回测零回归，再逐层打开。
