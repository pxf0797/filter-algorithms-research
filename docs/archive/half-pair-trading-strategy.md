# 半边多空对交易策略

> 永远在操作半边多空对——确认起点即入场，核心在离场

---

## 一、核心认知：永远在操作半边多空对

**一句话：** 不管是回测推进还是实时交易，你永远站在窗口最右边缘，当前正在走的那段多空对永远只有起点、没有终点——这就是"半边"，它不是特殊情况，它是唯一现实。

### 1.1 什么是多空对，什么是"半边"

**多空对（Pair）= 一段连续同向的趋势。** 它由三个要素定义：

| 要素 | 含义 | 来源 |
|------|------|------|
| 起点 | 趋势诞生的那一根 K 线（Sig 从 0 变为 ±1） | Schmitt 触发器状态转移 |
| 终点 | 趋势结束、反向趋势诞生的那一根 K 线 | 下一段反向段的起点 |
| 方向 | +1（多）或 -1（空） | 段内 Sig 的符号 |

一个多空对如果**起点和终点都有**，它就是**完整多空对**——它是一段已经走完的历史，我们回看它时，涨到哪、跌到哪都已经确定，不会再变。

但当下正在走的这一段不一样：它有起点（趋势已经诞生），却**没有终点**（趋势还在延伸，谁也不知道它什么时候结束）。这种"有头无尾"的多空对，就是**半边多空对**。

```
完整多空对：  起点 ●━━━━━━━● 终点      （历史，已定型）
半边多空对：  起点 ●━━━━━━━▶ ???       （当下，还在走）
```

### 1.2 为什么说"永远"操作半边

**一句话：** 无论回测第几帧、还是实时此刻，最右边那个多空对永远是半边——因为"当下"这个位置，天然就是趋势还没走完的地方。

想象一条被切成许多段的趋势序列。你站在时间轴的最右端，往左看全是完整多空对（都走完了、定型了），而你脚下正踩着的这一段——最右边这一段——永远还在延伸：

```
    过去 ◀─────────────────────────  现在
    │完整│完整│完整│完整│  半边 ▶ (你在这里)
     已定型 已定型 已定型 已定型   还在走
```

这个"你在这里"的位置有一个关键性质：**它永远处在窗口最右边缘。** 回测每前进一根 K 线，这个边缘就右移一格，但"最右边那段是半边"这个事实从不改变。今天的半边明天可能走完、变成完整多空对被甩到左边，但那时又会有**新的**半边出现在最右边。

所以结论只有一句：**你操作的对象，永远、且只能是这个半边多空对。** 完整多空对是用来回顾和学习的，能下单的永远只有当下这个半边。

### 1.3 策略骨架（一句话讲清全部）

**一句话：** 确认半边的起点就入场，入场之后唯一要做的事就是判断怎么离场——入场是确定的，离场是全部难点。

```
        永远操作半边多空对
                │
       ┌────────┴────────┐
       ▼                 ▼
   确认起点            怎么离场
   = 入场              = 核心
   （简单）           （三种机制）
```

为什么入场简单、离场是核心？因为半边的**起点是看得见、可确认的**——趋势诞生那一刻就在眼前，只要确认它站稳了、上级周期也点头，就进场。但半边**没有终点**，趋势会走多远、什么时候反转，没有任何现成的信号告诉你。于是"什么时候走"这个判断，承担了这套策略的全部智慧。

下面两章分别展开：第二章讲入场（简单，一章带过），第三章讲离场（核心，重点铺开）。

---

## 二、入场：确认起点（简单）

**一句话：** 起点锁定 + 上级周期同向 = 入场，没有第二种入场逻辑。

### 2.1 起点如何产生和确认

半边的起点，就是 **Sig 从 0 跳到 ±1 的那一刻**——一段新趋势诞生了。但起点刚诞生时并不可靠，原因是**边缘区问题**：

> 趋势滤波算法（SMA、Savitzky-Golay 等）在窗口最右侧的 2-5 根 K 线上存在边界效应。这几根 bar 的滤波值还没被足够的历史数据"锚定"，Sig 会反复跳变——今天看是起点，明天数据一更新，起点可能就消失了。

因此我们区分两种状态：

| 状态 | 含义 | 能否入场 |
|------|------|---------|
| 起点在边缘区 | 刚诞生，还在最右 2-5 根内，随时可能消失 | 否，等待 |
| 起点已锁定 | 已离开边缘区（往左走了足够远），不再改变 | 可以考虑入场 |

**锁定 = 起点离开边缘区。** 一旦起点从最右边缘往左退出 3-5 根 K 线的距离，它就"钉死"了，后续窗口推进不会再抹掉它。这时候起点才算数。

### 2.2 入场两条件

入场只需要同时满足两个条件，缺一不可：

```
① 起点已锁定       —— 半边确实站稳了，不是边缘区的闪烁假信号
② 上级周期 C 同向   —— 更大级别的趋势为这个方向背书
```

- **条件①** 排除了"边缘区假起点"——避免被还没站稳就消失的信号骗进场。
- **条件②** 排除了"逆大势的小反弹"——60 分钟说涨、但日线在跌，这种半边多半是无谓反弹，不值得参与。上级周期同向的判定，完全沿用第五章的多周期门控逻辑。

两个条件都满足，就在**当前这一帧**顺着半边方向入场。就这么简单。

### 2.3 入场决策表

**一句话：** 用"起点是否锁定 × C 周期方向"两个维度，穷举所有入场情形。

| # | 起点锁定？ | C 周期方向 | 结论 | 原因 |
|---|-----------|-----------|------|------|
| 1 | 是 | 同向 | ✅ 入场 | 起点站稳 + 大势背书，最可靠 |
| 2 | 是 | 观望（C=0） | ⚠️ 降级等待 | 大势未表态，保守起见等 C 明朗或不入场 |
| 3 | 是 | 反向 | ❌ 不入场 | 逆大势的反弹，不参与 |
| 4 | 否（边缘区） | 任意 | ⚠️ 等待锁定 | 起点可能消失，等它离开边缘区再判 |

只有第 1 行是明确入场。第 2 行是灰色地带（可配置为保守不入场）；第 3、4 行都不入场。**入场判断到此结束，剩下的全是离场的事。**

## 三、离场：策略的核心（三种机制）

### 3.1 为什么离场是核心

**一句话：** 入场简单——起点确认就进；但半边没有终点，你永远不知道趋势何时结束，所以"怎么离场"承担了策略的全部智慧。

回顾第一章：完整多空对有终点，半边多空对没有。入场时我们看的是**起点**（看得见），离场时我们要判断的是**终点**（看不见、还没发生）。这就是不对称的根源——入场是"确认一个已存在的事实"，离场是"预判一个尚未发生的事件"。

因此我们不能只靠一种信号离场，而是用**三种互补的机制**从三个角度盯着趋势：本级趋势是否反转（离场①）、本级趋势是否破位（离场②）、大势是否掉头（离场③）。任何一个触发，就走。

### 3.2 离场①：进入下一个多空对（趋势反转，全程生效）

**一句话：** 当一个新的反向半边多空对诞生、取代了当前这个，就说明本级趋势反转了，离场。

这是最本质的离场信号。当前是多头半边，如果 Sig 翻成 -1，一段**新的空头半边**诞生——它取代了原来的多头半边成为"最右边那段"。趋势换向了，多头旅程结束，离场。

```
持多头半边 ●━━━━━━━▶ ×  ← Sig 翻 -1，新空头半边诞生 = 离场
```

**但要防假反转。** 第一章讲过，边缘区的单根 bar 有 5-10% 概率是噪声翻转——它翻成 -1，下一帧可能又变回来。如果一见反向 bar 就离场，会被这种噪声反复"假止盈"骗出场。

**缓冲设计（N_confirm）：** 新反向段要**连续持续 N_confirm 根 bar**（默认 2）才确认为真反转：

```
reverse_run = 连续反向 Sig 的 bar 数
IF reverse_run ≥ N_confirm:
    → 确认进入下一个多空对，离场
```

代价是确认期内回吐 1-2 根 bar 的利润，收益是避开边缘噪声的假离场。N_confirm 是回测超参（设为 0 就退化成"见反向即走"）。

### 3.3 离场②：趋势偏离过大（全程生效）

**一句话：** 价格偏离预测轨道超过阈值，说明趋势破位了，离场——但只看不利方向的偏离。

系统用 `_fit_parabolic` / `_fit_physics_parabola` 为当前半边拟合一条**预测曲线**（趋势应该走的轨道）。如果实际价格偏离这条轨道太远，说明趋势的内在动能失效了：

```
pred_val(i)  = 预测曲线在第 i 帧的值
deviation(i) = |实际价格 - pred_val| / pred_val
IF deviation > MAX_DEV_PCT（默认 3%~5%）:
    → 趋势破位，离场
```

**关键：只惩罚不利偏离，让有利偏离继续奔跑。**

- 做多时：只有价格**跌破**上升轨道（跑输预测）才离场；价格**涨超**预测是好事，不离场。
- 做空时：只有价格**涨破**下降轨道才离场；价格跌超预测是好事，不离场。

**对比现有"预测保护期止损"——这是两个不同的东西：**

| 维度 | 现有保护期止损 | 新增趋势偏离离场 |
|------|--------------|----------------|
| 生效区间 | 仅入场后前几根 bar（保护期内） | **整个持仓期，全程** |
| 判定方向 | 单边击穿轨道 | 只看不利方向的绝对偏离 |
| 防的是什么 | 入场初期"进错了方向" | 全程"趋势中途破位/加速失效" |

保护期止损防前期，趋势偏离离场管全程，二者互补不冲突。

### 3.4 离场③：上级周期反向（最高优先级）

**一句话：** C 周期趋势掉头、与当前持仓方向相反，说明大势变了，无条件离场。

第二章入场时，我们要求上级周期 C 同向背书。持仓期间同样盯着 C：一旦 C 周期的方向翻转成与持仓相反，这是"大势否定"——比本级的任何信号都严重，因为它意味着为你的方向背书的那个更大级别趋势本身崩了。

```
持多头 + C 周期翻为做空 → 立即离场（大势已反）
持空头 + C 周期翻为做多 → 立即离场
```

这是三种离场里**优先级最高**的，因为它是结构性的：本级趋势的反转或破位是"战术"问题，上级趋势的掉头是"战略"问题。

### 3.5 离场优先级表

**一句话：** 同一帧多个离场条件同时触发时，按"风险紧迫度"从高到低判定，命中即走。

| 优先级 | 离场机制 | 触发条件 | 语义 |
|--------|---------|---------|------|
| 1（最高） | ③ 上级周期反向 | C 周期翻向与持仓相反 | 大势已反，战略级否定 |
| 2 | ② 趋势偏离过大 | 不利偏离 > MAX_DEV_PCT | 本级趋势破位、脱轨 |
| 3 | ① 进入下一多空对 | 反向段持续 ≥ N_confirm | 本级趋势正常反转，止盈 |
| （保留） | 预测保护期止损 | 入场初期击穿轨道 | 入场初期防错方向 |

实现上在持仓扫描循环里**按此顺序 if-elif 判定，命中即 break**。为什么这个顺序？③①是"趋势判断已被推翻"（结构性），必须先于②"价格脱轨"；而全程性的②要先于仅前期生效的保护期止损。

## 四、完整决策流程

**一句话：** 每一帧，无仓就查起点确认决定是否入场，有仓就按优先级跑三道离场检查决定走或留。

```
┌──────────────────────────────────────────────────┐
│ 每帧 i（回测推进 / 实时 tick）                       │
│   算好各周期 Sig，识别当前半边，取上级周期 C 方向     │
└───────────────────────┬──────────────────────────┘
                        ▼
               ┌────────────────┐
               │  当前是否持仓？  │
               └───┬────────┬───┘
              无仓 │        │ 有仓
                   ▼        ▼
      ┌──────────────────┐  ┌──────────────────────────────┐
      │   入场判定         │  │  离场判定（按优先级 if-elif）   │
      ├──────────────────┤  ├──────────────────────────────┤
      │ 起点已锁定？       │  │ 优先级1 C周期反向？→离场（最高）│
      │   ├ 否 → 等待锁定  │  │ 优先级2 趋势偏离超阈？→离场     │
      │   └ 是 ↓          │  │ 优先级3 反向段≥N_confirm？→离场│
      │ C 周期同向？       │  │ （保护期止损：初期击穿→离场）   │
      │   ├ 同向 → ✅入场  │  │ 否则 → 继续持有                │
      │   ├ 观望 → 降级等  │  └──────────────────────────────┘
      │   └ 反向 → ❌不入  │
      └──────────────────┘
                   │
                   ▼
           记录交易 / 更新 PnL
```

**流程要点：** 无仓时只有一件事——确认半边起点该不该进；有仓时只有一件事——三道离场网谁先响。单持仓模型，同一帧不同时开多个仓。

## 五、多周期协同（沿用 b-cycle 门控）

**一句话：** C 周期为 B 周期的方向背书，逻辑与 b-cycle 门控完全一致，只是判断单元从单个 Sig 升级为"半边多空对的方向"。

交易在 B 周期发生，C 周期做方向约束。C 周期同样永远站在右边缘，所以 **C 的"当前方向"就是 C 自己那个半边多空对的方向**（记为 `dir_C`）。B 和 C 的半边方向是否一致，决定入场和离场：

| B 周期状态 | C 周期方向 | 决策 |
|-----------|-----------|------|
| B 半边同向、起点锁定 | C 同向 | ✅ 入场（大势背书，最可靠） |
| B 半边同向、起点锁定 | C 观望（dir_C=0） | ⚠️ 降级等待或不入场 |
| B 半边同向、起点锁定 | C 反向 | ❌ 不入场（逆大势反弹） |
| B 持仓中 | C 翻为反向 | 🚪 触发离场③（上级否定，最高优先级） |

核心一句话：**C 同向是打开入场的钥匙，C 反向是最高优先级的离场令。** B 单独的半边有假信号风险（第一章的边缘区消失概率 5-10%），但"B 半边 + C 同向锁定"把假信号概率压到接近 0——这时候才值得上车。

实现上复用现有 `_align_pnl_to_current_tf` 的跨周期时间对齐基建，新增一个轻量函数取当前帧对应的 `dir_C` 即可。这正是 b-cycle 方案已经铺好的路，本策略只是把门控单元从 Sig 换成半边多空对方向。

## 六、实战走查（bar 级）

以下 Sig 来自 Schmitt 触发器（+1 多 / 0 观望 / -1 空），dir_C 为 C 周期半边方向。

### 场景 1：起点确认，入场 ✅

```
B (60分钟)：新多头半边诞生，起点已离开边缘区（锁定）
C (日线)：  dir_C = +1（同向）

判定：起点锁定 ✓ + C 同向 ✓ → ✅ 入场（做多）
解读：半边站稳了，日线也点头，顺着当前趋势上车。这是标准入场。
```

### 场景 2：进入下一个多空对，离场 ①

```
持仓：多头，已持有 8 bar
B：连续 2 根 bar 翻成 Sig=-1（新空头半边诞生，达到 N_confirm）

判定：反向段持续 ≥ 2 → ✅ 确认进入下一多空对 → 🚪 离场
解读：本级趋势反转，多头旅程结束，止盈离场。N_confirm=2 已滤掉单 bar 噪声。
```

### 场景 3：趋势偏离过大，离场 ②

```
持仓：多头，价格本应沿上升预测轨道走
B：实际价格跌破轨道，不利偏离达 5% > MAX_DEV_PCT(4%)

判定：signed_dev = 5% > 4% → 🚪 离场（trend_deviation）
解读：Sig 还没翻，但价格已明显脱离上升轨道——趋势内在动能失效，提前离场，不等它正式反转。
```

### 场景 4：上级周期反向，离场 ③（最高优先级）

```
持仓：多头
B：Sig 仍 = +1（本级还看多）
C (日线)：dir_C 翻成 -1（大势掉头做空）

判定：C 反向 → 🚪 立即离场（最高优先级，压过本级的 +1）
解读：本级趋势还在，但为它背书的日线大势崩了。战略级否定，无条件走。
```

### 场景 5：起点未锁定就消失，没入场（避免损失）✅

```
B：新多头半边刚诞生，但起点还在最右 3 根 bar 内（边缘区）
   → 起点未锁定，入场条件①不满足 → 等待
下一帧：窗口推进，该起点被重算成 0，半边蒸发

判定：从未入场 → 零损失
解读：这正是"起点锁定"条件的价值——边缘区的假起点会消失，我们靠"等锁定"
      对它天然免疫。若贸然在边缘区入场，这里就是一笔基于已被否定信号的幽灵交易。
```

## 七、与现有系统集成

**一句话：** 新增"识别当前半边多空对"的函数，入场复用 b-cycle 门控，离场①②需新增；全部默认可关，回测零回归。

### 7.1 关键代码事实

现有 `_find_all_pairs` 用 `range(len(merged)-1)` 遍历，**只返回完整多空对，不返回当前半边**——配对循环止于倒数第二段，最右侧那个无反向段收尾的半边永远进不了列表。所以要支持本策略，第一步就是新增一个识别"当前半边多空对"的函数，把这个盲区显式暴露出来。

### 7.2 改动范围

| 改动 | 内容 | 说明 |
|------|------|------|
| **新增** `_merge_segments` | 抽出 `_find_all_pairs` 的收集+跨零合并逻辑 | 公共复用，避免逻辑漂移 |
| **新增** `_find_current_half_pair` | 识别窗口最右侧的半边多空对 | 返回 (起点, 当前帧, 方向) |
| **新增** `_get_higher_tf_direction` | 取 C 周期当前半边方向 dir_C | 复用 `_align_pnl_to_current_tf` |
| **改** `_compute_strategy_pnl` | 加半边入场支路 + 三道离场（按优先级） | 参数默认关闭，旧行为不变 |
| **不改** `_find_all_pairs` 对外行为 | 仅内部改调 `_merge_segments` | 保护现有回测确定性 |

### 7.3 向后兼容

- **入场门控** 直接复用 b-cycle 已设计的 A<B<C<D 周期协同，不重复造轮子。
- **离场③（上级反向）** 也是 b-cycle 门控的镜像应用，几乎零新增。
- **离场①②** 是本策略需要新写的核心逻辑。
- 全部改动走"增量支路 + 参数默认关闭"，关掉开关后系统逐字节复现现有行为——**回测基线零回归是第一道验证**。

## 八、优势与下一步

### 优势

- **心智极简。** 全程只有一个操作对象（当下半边）、一个入场判断（起点确认）、一个核心命题（怎么离场）。没有"完整 vs 半边"的语义割裂，没有特殊情况分支。
- **与实盘天然一致。** 回测推进和实时交易都是"站在最右边缘操作半边"，同一套逻辑，不存在回测有效、实盘失效的框架错位。
- **复用 b-cycle 门控。** 入场和离场③直接站在已验证的多周期协同肩上，改动集中在离场①②。
- **对假信号免疫。** "起点锁定"条件让边缘区假起点自动出局（场景 5），不入场即零损失。

### 下一步（MVP）

最小可行版本聚焦三件事，逐层开关、独立回测量化增益：

```
1. 起点确认入场      —— 识别半边 + 起点锁定 + C 同向门控
2. 进入下一多空对离场 —— 离场①，带 N_confirm 缓冲
3. 趋势偏离离场      —— 离场②，全程盯预测轨道
```

离场③（上级反向）因复用 b-cycle 门控可顺带接入。参数调优聚焦三个超参：起点锁定的边缘区宽度、N_confirm 缓冲根数、MAX_DEV_PCT 偏离阈值。回测对比"有策略 vs 基线"的胜率、交易次数、最大回撤、Sharpe，量化每一层的边际贡献。
