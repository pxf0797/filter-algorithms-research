## 0. 设计边界：只补真盲区，先把已处理的划走

T1 用执行验证给出两类结论。本设计**严格分开**对待，不把"已经对的"重做一遍。

**✅ 已正确处理（本次不动）：**

| 已处理项 | T1 事实 | 结论 |
|---|---|---|
| 同向断续合并鲁棒 | `[+1,0,+1]`、`[+1,0,0,0,+1]` 都稳定合并成一段，隔 3 个还是 300 个 0 结果一样 | 对任意 gap 免疫，**无需改** |
| entry_void 抗短暂降速（条件性） | `[+1,0,+1]` 期间 pair 层 dir_now 从不离开 +1，尾随 0 被合并吸收 | 只要 entry_void 挂 **pair-dir**（非裸 sig）就不会误触发，**无需新构件**，实现时钉死判据即可 |

**❌ 4 个真盲区（本设计目标）：** ①异号断续 whipsaw（最尖锐）、②断续度不可见、③同向真启动点丢失、④C 五态无记忆。

**一个诚实前提（贯穿全文）：** 当前 `filter_engine.py` 落地的**不是 v3**——它在 `pair_end`（反向入口边缘）入场、用**单根** `sig==-1` 离场；v3 的 C 五态 / `signed_dev` / `reverse_run` / `entry_void` 在源码里**都不存在**。v1~v3 全是**设计蓝图**。所以下面每条都标注：是**【真新增】**，还是**【补落地 v3 已提出但代码未实现】**。另外，v3 文档里**并没有"纯度"这个构件**（只有当前帧的软 decel 预警），本设计不假装它有。

## 1. 异号断续 whipsaw → N_confirm 缓冲【补落地 v3 已提出】

这是断续序列**最尖锐**的问题，也是唯一"设计早就写了、代码却没落地"的一条。

**盲区事实（T1）：** `_find_all_pairs` 里 pair 的 dir 由 `merged[-1]` 符号决定，**单根反向即翻 dir**；`_compute_strategy_pnl` 用**单根** `sig==-1` 即离场。二者都**无 N_confirm**。于是 `[+1,0,-1,0,+1,0,-1]` 被切成 3 个碎片 pair `[(0,2),(2,4),(4,6)]`，dir 在 +1/-1 间来回跳 4 次 → 潜在 3 笔无缓冲 whipsaw。

**非对称性根因：** 同向断续被 merge 平滑（`+1,0,+1`→一段），异号断续却被放大（单根 `-1` 拆断合并）。**保护同向、放大异号**正是这段代码对震荡序列脆弱的本质。

**设计（不是新发明，是补 v3 早写好的门）：** v3 已假设"`dir_C` 只在 `reverse_run ≥ N_confirm` 才翻"、"离场① 也用 `reverse_run ≥ N_confirm`"。把这个门真正接进 `_find_all_pairs` 的 dir 判定与离场①：

```
reverse_run = 连续同向反向"非零"段的累计根数
0 出现 → reverse_run 归零（保守：要求反转不被打断才算数）
仅当 reverse_run ≥ N_confirm 才翻 dir / 触发离场①
```

**为什么这恰好治好异号断续：** `[+1,0,-1,0,+1]` 中孤立的单根 `-1` 后面紧跟 0，`reverse_run` 被 0 打断、永远够不到 `N_confirm` → **不翻向、不砍仓**，whipsaw 被自然吞掉；而 `[+1,0,-1,-1,-1]` 的连续 `-1` 能累计到 `N_confirm` → 真反转仍被确认。**这印证了 v3 N_confirm 方向正确**：异号单根本就不该立即翻 dir 或砍仓。默认 `N_confirm=2` 起步，`N_confirm=1` 复现现状。

## 2. 断续度量化（gap_count / gap_ratio）【真新增】

**盲区事实（T1）：** 0 在 Step1 就被丢弃，gap 长度与停顿次数无处留存。v2/v3/源码三处都没有量化"这段抖了几次"。一个抖了 5 次的虚弱趋势与一个干净强趋势，信息上不可区分。

**设计：** 在 `_find_all_pairs` 合并时，**不丢弃 gap 信息**，为每个 merged 段附带两个标量：

| 指标 | 定义 | `[+1,0,+1,0,+1]`（merged=(0,4)） |
|---|---|---|
| `gap_count` | 段内被 0 打断的次数 = 合并的子段数 − 1 | 3 子段 → `gap_count=2` |
| `gap_ratio` | 段内 0 根数 ÷ 段总长 | 2 ÷ 5 = `0.4` |

越断续 → `gap_count`/`gap_ratio` 越高 → 该半边质量越低。这是**唯一需要动 `_find_all_pairs` 数据结构**的改动：Step1 记录每个 0-run 的长度，Step2 合并时累加进 merged 段的 `gap_count`/`gap_ratio` 字段。计算 O(n)、零新数学。这两个量是后面第 3、4 节的输入。

## 3. 同向真启动点丢失 → 有效起点重定义【真新增】

**盲区事实（T1）：** merge 把趋势真正发力的后续 +1 折回**最早起点**（V1、V4 的 pair_start 都锚在 index 0）。v3"起点即入场"会锚到可能是噪声的第一个 +1，且**不为真启动生成新 pair_start**——"要么在假起点 index 0 进早了，要么错过 index 4 的真启动，二者必居其一"。

**设计：** 为断续半边定义两个起点，供"起点即入场"择时：

- `earliest_start` = 最早 +1（现状锚点，index 0）。
- `effective_start` = **最近一次 0→+1 的恢复点**（最后一次从停顿中重启的 +1，如 index 4）。

**用法（与断续度联动，不无脑迁移）：**

```
若 gap_count ≤ 阈值(连续型)      → 用 earliest_start（现状，趋势干净、早起点可信）
若 gap_count >  阈值(断续型)      → 入场择时改用 effective_start
                                    （早起点大概率是噪声起步，等最近一次重启才进）
```

这样断续半边不会在可能是噪声的 index 0 入场，而是等"最近一次真启动"。默认阈值高到不触发 = 复现现状。

## 4. C 五态无记忆 → 断续度调节因子【真新增】

**盲区事实（T1）：** v3 的 C 五态是**逐帧无记忆**快照。对 `[...,+1]` 当帧 sig=+1、dev 低 → 判 STRONG_ALIGN，"这段一路 +1,0,+1 震了很多次"的历史不进入判定。抖了 5 次的虚弱趋势与干净强趋势，只要当帧都 +1 且 dev 低，C 状态**完全相同**。软 decel 预警只在恰好当帧 `sig==0` 那一根触发，抖动一过又回 STRONG，不留痕迹。

**设计：** 不新增第 6 态，而是给 STRONG_ALIGN 加一个**断续度调节因子**，把它细分：

| STRONG 子型 | 条件 | 对 B 入场 |
|---|---|---|
| 连续型 STRONG | `gap_count ≤ 阈值` | ✅ 满仓（现状） |
| 断续型 STRONG | `gap_count > 阈值`（或 `gap_ratio > 阈值`） | ⚠️ **质量打折**：降级为"收紧入场"（等同 WEAK 的谨慎处理 / 减半仓 / 抬高其余门槛） |

逻辑：C 名义 STRONG，但它自己这段趋势是抖出来的，背书含金量打折，B 不该按满速强同向对待。这把"断续历史"并入 C 判定，而非只看当前帧。默认阈值高到不触发 = C 状态判定逐字节复现 v3。

## 5. gap 上限（可选，默认关 = 复现现状）【真新增】

**现状（T1）：** 合并**无 gap 上限**，只看符号相同。这是"已正确处理"的一面（抗降速），但极端情况下"隔 300 个 0 仍合并成一段趋势"未必合理——中间隔太久，前后两个 +1 也许是两段独立趋势。

**设计：** 加超参 `MAX_GAP_BARS`：同向合并时，若两子段之间的 0-run 长度 `> MAX_GAP_BARS`，视为**趋势中断/重启**，不合并、后段另起新 pair_start。

```
MAX_GAP_BARS = ∞（默认）→ 永不触发，逐字节复现现状（无 gap 上限）
MAX_GAP_BARS = N（可调） → 隔超 N 根 0 视为断了，后段重新计为新趋势起点
```

这条**默认关**，只作为可回测的旋钮：它与第 3 节的 `effective_start` 是两种应对"gap 太大"的思路（重定义起点 vs 直接断开），留给回测选。

## 6. 汇总：新增 vs 补落地，改动落点

| # | 盲区 | 性质 | 落点 | 默认行为 |
|---|---|---|---|---|
| 1 | 异号断续 whipsaw | **补落地 v3 已有**（N_confirm） | `_find_all_pairs` dir 判定 + 离场① | `N_confirm=1` 复现现状 |
| 2 | 断续度不可见 | **真新增** | `_find_all_pairs`（保留 gap 信息，加 `gap_count/gap_ratio`） | 只计算不动决策 = 无影响 |
| 3 | 真启动点丢失 | **真新增** | `effective_start` + 断续度联动择时 | 阈值高到不触发 = 用 earliest |
| 4 | C 五态无记忆 | **真新增** | C 状态判定加断续度调节因子 | 阈值高到不触发 = 复现 v3 |
| 5 | gap 上限 | **真新增（可选）** | `_find_all_pairs` 合并加 `MAX_GAP_BARS` | `∞` = 复现现状 |

**零回归先行：** 所有开关默认取"复现现状/复现 v3"值，回测基线逐字节一致是第一道验证；随后逐条打开，量化每个断续构件的边际贡献。

**一句话结论：** 断续度量化（gap_count/gap_ratio）是这套升级的**地基**——它一旦可见，第 3、4 节才有输入；而最尖锐的异号 whipsaw 其实不用新发明，只需把 v3 早写好的 N_confirm 真正接进 `_find_all_pairs`。同向断续合并鲁棒这部分**已经是对的，不改**。
