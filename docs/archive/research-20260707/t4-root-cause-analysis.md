## 1. 因果链追踪

### 1.1 完整因果链（带差异程度标注）

```
窗口滑动 (bar_index += 1, cutoff_date 前进)
  │
  ├──[1]── _sync_all_cascading() 重写所有 TF 的 parquet
  │         │  差异程度: 数据窗口整体右移
  │         │  - 最左侧 1 个 bar 移出窗口
  │         │  - 最右侧 1 个新 bar 进入窗口
  │         │  - min_tf: 直接 DB 查询, 无合成, 窗口滑动的数据变化仅在最右端 1 bar
  │         │  - 粗粒度 TF: 级联合成, 最右端可能是合成 bar (不完整 K 线)
  │         │  类别: A (固有特性 — 滑动窗口的必然结果)
  │         │
  │         └──[1a]── 粗粒度周期的级联合成
  │                   差异: 合成 bar 的 OHLCV 在每帧不同 (包含当日部分数据)
  │                   类别: A (固有特性 — 不完整 K 线的本质)
  │
  ├──[2]── _load_chart_data() 读取新 parquet
  │         │  差异程度: 与 [1] 同步, 数据数组整体右移 1 bar
  │         │  类别: A (固有特性)
  │         │
  │         └──[2a]── noisy (收盘价数组) 变化
  │                   - 前 n_pts-1 个值向右平移 1 位 (值本身不变)
  │                   - 第 n_pts 个值变为新的 bar 的收盘价
  │
  ├──[3]── _compute_filters(noisy, t) — 滤波重算
  │         │  差异程度: **取决于滤波器类型**, 从"仅最后 1 点不同"到"全局不同"
  │         │
  │         ├── SMA/EMA/WMA: 仅最后 1-2 个点不同
  │         │   类别: A (固有特性 — 滑动窗口滤波的边界行为)
  │         │
  │         ├── Savitzky-Golay: 最后 ~window/2 个点 (~10 点) 不同
  │         │   类别: A (固有特性 — 多项式拟合在边界的固有不稳定性)
  │         │   影响: 中等传播, 右端 ~10 点的 filtered 值每帧都在变化
  │         │
  │         ├── LOWESS: 最后 ~frac*N 个点 (~12 点 for frac=0.1, N=120) 不同
  │         │   类别: A (固有特性 — 局部加权回归的边界非对称性)
  │         │
  │         ├── Kalman: 最后 1 点进入后, 状态估计调整, 最后 ~20-50 点微调
  │         │   类别: A (固有特性 — 卡尔曼增益对最新观测的响应)
  │         │
  │         └── Butterworth (零相位 filtfilt): **整个序列全局不同**
  │             类别: B (设计选择 — 使用零相位滤波而非因果滤波)
  │             影响: 最严重, 双向滤波意味着窗口内所有历史点的 filtered 值都改变
  │
  ├──[4]── v = np.gradient(filtered, t) — 速度计算
  │         │  差异程度: 取决于 filtered 的变化范围
  │         │  - filtered 仅最后 1 点变化 → v 最后 2 点变化 (中心差分需要邻域)
  │         │  - filtered 全局变化 (Butterworth) → v 全局变化
  │         │  - 边界效应: 最后 1 个 v 使用一阶后向差分 O(h), 非中心差分 O(h²)
  │         │  - 当 bar 前进后, 上一帧的"边界点"变为当前帧的"内部点", 精度提升
  │         │  类别: A (固有特性 — np.gradient 在有限序列边界必然退化)
  │
  ├──[5]── a = np.gradient(v, t) — 加速度计算
  │         │  差异程度: 比 v 更严重 (二阶导数的边界退化)
  │         │  - 最后 2 个 a 使用一阶差分, 非中心二阶差分
  │         │  - v 的变化被 gradient 再次放大
  │         │  - 当 v 全局变化时, a 全局变化且幅度更大
  │         │  类别: A (固有特性 — 二阶导数对输入变化的放大效应)
  │
  ├──[6]── sigma_v = EWMA 递归 — 波动率估计
  │         │  差异程度: **位置 K 的 v 变化 → sigma_v[K:] 全部变化**
  │         │  机制: EWMA 是因果递归, 每个 sigma_v[i] 依赖 v[0..i] 全部历史
  │         │  衰减: alpha = 2/(span+1), span=60 时 alpha≈3.3%
  │         │  - 经 ~60 个点后, 初始条件 sigma_v[0]=0 的影响消失
  │         │  - 但中间任何位置的 v 变化, 影响从该位置延续到末尾
  │         │  - 不是滚动窗口! 这是指数衰减的全局依赖
  │         │  类别: B (设计选择 — EWMA vs 滚动窗口标准差)
  │         │  影响范围: [变化位置, 末尾], 即可能覆盖大量 bar
  │
  ├──[7]── eps = k_eps * max(sigma_v, sigma_min) — 自适应阈值
  │         │  差异程度: 跟随 sigma_v 变化, eps[变化位置:] 全部变化
  │         │  类别: A (固有特性 — 自适应阈值的数学定义)
  │
  ├──[8]── sig = _schmitt_trigger(v, a, eps) — 信号状态机 ⚠️ 关键节点
  │         │  差异程度: **从 eps/a/v 变化位置开始, sig 全部重建**
  │         │  机制: 三态滞回状态机, 状态从过去继承
  │         │  传播: 如果 sig[i] 因 eps[i] 变化而从 0 翻转为 +1,
  │         │        则 i 之后的所有 sig 都从新状态出发重新计算
  │         │        → 一个中间 bar 的 eps 变化可导致整条 sig 序列 Cascade 重写
  │         │  类别: A (固有特性 — 滞回状态机的数学本质) + C (可能 bug — 无防护)
  │         │  严重度: **高** — 这是信号闪烁的根因节点
  │
  ├──[9]── all_pairs = _find_all_pairs(sig) — 配对重建
  │         │  差异程度: 取决于 sig 的变化范围
  │         │  - sig 仅最后 1 点变化 → 可能新增或修改最后一个 pair
  │         │  - sig 中间 bar 变化 → 配对列表全局重建
  │         │  - 合并逻辑 (相邻同号段合并) 加剧了变化的传播
  │         │  类别: A (固有特性 — sig 变化必然导致配对变化)
  │
  ├──[10]── _fit_parabolic / _fit_physics_parabola — 拟合重算
  │          │  差异程度: 每个 pair 独立拟合, 但 pair 的起止 index 变了
  │          │  - 同一 pair 的 start/end 可能因 sig 变化而偏移
  │          │  - 拟合数据点不同 → 参数 (a,b,c) 不同 → pred_up 可能翻转
  │          │  - 新增 pair → 新增拟合曲线
  │          │  - 消失 pair → 拟合曲线被移除
  │          │  类别: A (固有特性 — 输入数据变化导致拟合结果变化)
  │
  ├──[11]── _compute_strategy_pnl(...) — PnL 重建
  │          │  差异程度: ⚠️ **全局重建** — long_pnl 和 short_pnl 全部重新计算
  │          │  关键逻辑:
  │          │  - 入场条件: sig[pair_end]==+1 AND pred_up → long
  │          │  - 止盈条件: sig 反转 (做多时 sig==-1 → 平仓)
  │          │  - 止损: 基于拟合曲线预测值, 仅在保护期内
  │          │  - 前向填充: 使用 100.0 作为哨兵值
  │          │  → sig 变化 → 入场/离场 bar index 变化 → trade_records 完全重建
  │          │  → long_capital/short_capital 累积路径不同 → 整条曲线不同
  │          │  类别: A (固有) + C (哨兵值 100.0 的 bug)
  │
  ├──[12]── _align_pnl_to_current_tf(...) — 跨周期对齐
  │          │  差异程度: 与高周期 PnL 同步变化
  │          │  类别: A (固有特性 — 输入变化导致输出变化)
  │
  └──[13]── _compute_holding_masks(...) — 持仓遮罩
            差异程度: 跟随 entry/exit markers 变化
            类别: A (固有特性)
```

### 1.2 差异传播路径总览

```
                    ┌──────────────────────────────────────────────────┐
                    │            传播放大效应量化                         │
                    └──────────────────────────────────────────────────┘

滤波边界效应 (filtered 变化 M 个点, M ∈ [1, N])
  │
  ├──→ v 变化 [M+1 个点]  (gradient 邻域放大: M → M+1)
  │     │
  │     └──→ a 变化 [M+2 个点]  (二阶导数: M+1 → M+2, 且幅度放大)
  │           │
  │           └──→ sigma_v 变化 [(N-K) 个点]  (EWMA 递归: M → N-K, K=变化起始位置)
  │                 │                                   ↑ 放大倍数: (N-K)/M, 最大可达 N/M
  │                 │                                   例: M=1, K=60, N=120 → 60x 放大
  │                 │
  │                 └──→ eps 变化 [(N-K) 个点]  (1:1 跟随 sigma_v)
  │                       │
  │                       └──→ sig 变化 [≥(N-K) 个点, 最多 N-K_init 个点]
  │                             │               (状态机 Cascade: 变化向后传播)
  │                             │
  │                             ├──→ all_pairs 可能全局重建
  │                             │     │
  │                             │     ├──→ fit 参数变化
  │                             │     │     └──→ pred_up 可能翻转 (方向翻转率 ≈ 取决于边界附近信号密度)
  │                             │     │
  │                             │     └──→ pair 数量增减
  │                             │
  │                             └──→ PnL 曲线全局重建 (long_pnl, short_pnl 全部重算)
  │                                   │
  │                                   └──→ 跨周期 PnL 对齐变化 (低周期看到的高周期 PnL 也变了)
```

**关键发现**: 传播路径中存在两个"放大器":
1. **EWMA 递归放大器**: 1 个点的 filtered 变化 → EWMA sigma_v 可能影响 60+ 个点的 eps
2. **状态机 Cascade 放大器**: 1 个 bar 的 sig 翻转 → 后续所有 bar 的 sig 从新状态重新判定

## 2. 根本原因分类

### 2.1 A 类: 不可消除的算法固有特性

| # | 根因 | 涉及环节 | 严重度 | 为什么不可消除 |
|---|------|---------|--------|---------------|
| A1 | **滑动窗口的数据更替** | T2-[1]: parquet 重写 | 中 | 回测的本质是在模拟"时间推进"。每帧只能看到截止到当前时刻的数据, 新 bar 进入和旧 bar 移出是滑动窗口的数学定义, 无法消除 |
| A2 | **np.gradient 边界差分退化** | T1-1.1, T3-5B | 中 | `np.gradient` 在有限序列的首尾必然使用一阶差分(O(h)), 而非中心差分(O(h²))。这是数值微分的固有局限。当边界 bar 变为内部 bar 时, 精度提升可能导致信号值变化 |
| A3 | **滤波器的端点效应** | T3-5A, T1-1.1 | 高 | 所有滤波器 (SMA/EMA/Kalman/Savitzky-Golay/LOWESS) 在有限窗口的右边界都存在端点不稳定性。这是数字信号处理的数学本质——窗口截断必然导致频谱泄漏和端点失真 |
| A4 | **Schmitt 触发器的滞回 Cascade** | T1-1.4, T3-5D | **高** | 滞回状态机 (hysteresis) 的设计目标就是"状态具有记忆"。状态从过去继承, 中间任何 eps 变化后, 从该位置起状态重新递推——这不是 bug, 这是滞回的定义。但结合 EWMA sigma_v 的全局依赖, 导致传播范围被极度放大 |
| A5 | **自适应阈值 eps 的全局依赖** | T1-1.2 | 高 | eps = k_eps * max(sigma_v, sigma_min), 其中 sigma_v 是 EWMA 递归。eps[i] 自动依赖 v[0..i] 的全部历史——自适应阈值的"自适应"本质上就是全局信息依赖 |
| A6 | **不完整 K 线的级联合成** | T2-4.6 | 低 | 粗粒度周期的最右端 bar 在回测中是"不完整"的 (例如周三时周线只有周一到周三的数据)。级联合成从细粒度周期聚合出这个不完整 bar, 每个时刻的聚合结果不同——这是时间推进的必然 |

### 2.2 B 类: 可改进的设计选择

| # | 根因 | 涉及环节 | 严重度 | 当前设计 | 替代方案 | Trade-off |
|---|------|---------|--------|---------|---------|-----------|
| B1 | **EWMA sigma_v vs 滚动窗口标准差** | T1-1.2 | 高 | EWMA 递归 (alpha=2/(span+1)): 中间 v 的变化影响之后所有 sigma_v | 滚动窗口标准差: 每个位置只看过去 window 个 v 值 | EWMA 优点: 平滑、对异常值不敏感; 滚动窗口优点: 局部性更好, 变化的传播范围有限。但滚动窗口会引入滞后 (标准差对均值偏移响应慢) |
| B2 | **全局 np.gradient vs 局部差分** | T1-1.1, T3-5B | 中 | `np.gradient` 使用中心差分 (O(h²)), 边界退化为一阶差分 | 统一使用前向差分 (O(h)), 所有点精度一致 | 前向差分精度低但对边界一致性好; 中心差分精度高但边界退化导致"信号闪烁"——一个 bar 从边界变为内部时, 精度跃升 |
| B3 | **零相位滤波 (Butterworth filtfilt)** | T3-4 | **高** | `sosfiltfilt` 双向滤波, 添加新数据点后整个序列重算 | 因果滤波 (lfilter): 只向前看, 添加新点不改变历史值 | filtfilt 优点: 零相位失真, 平滑效果好; 缺点: 历史值在每帧都变化, 信号极不稳定。因果滤波通过牺牲相位精度换取历史稳定性 |
| B4 | **pair 合并逻辑: 0 视为同方向延续** | T1-2.1 | 中 | `_find_all_pairs` Step 2: 相邻同号非零段合并, 中间 0 视为同方向延续 | 严格配对: 0 = 离场, 不合并跨 0 的非零段 | 当前设计更激进 (信号更连续), 但也意味着 0 的插入/移除会触发合并/拆分, 放大 sig 变化的影响 |
| B5 | **前向填充哨兵值 100.0** | T1-4.3 | 中 | 用初始值 100.0 作为"未持仓"的标记, 前向填充时依赖此值判断 | 用 np.nan 作为未持仓标记, 或使用独立的 bool mask | 100.0 哨兵在 PnL 恰好回到 100.0 时会导致前向填充逻辑错误 (把真实值当哨兵), 虽然概率低但后果严重 |

### 2.3 C 类: 实际 Bug

| # | 根因 | 涉及环节 | 严重度 | 描述 | 可验证假设 |
|---|------|---------|--------|------|-----------|
| C1 | **哨兵值 100.0 冲突** (T1 发现) | `_compute_strategy_pnl` 行 843-858 | **高** | PnL 初始化为 100.0, 前向填充逻辑用 `long_pnl[i] == 100.0` 判断"未持仓区"。如果某 bar 的浮动盈亏恰好使 PnL 回到 100.0, 前向填充会错误地将其视为未持仓, 导致该 bar 及之后的 PnL 填充错误 | **假设**: 构造一个场景, 某笔交易收益恰好为 0% (价格回到入场价), 观察 PnL 曲线是否出现异常水平直线。**验证方法**: 用模拟数据测试, 设置入场价=离场价, 观察前向填充行为 |
| C2 | **跨周期 PnL 不写入 session_state** (T3 发现) | `_compute_strategy_display` 行 279-313 | 中 | `if has_strategy and trade_records:` 条件要求 trade_records 非空才写入 session_state。如果某帧 has_strategy=True 但窗口内无有效交易 (所有 pair 的 pred_up 与 sig 矛盾), 则旧 PnL 残留在 session_state 中, 下一帧渲染低周期时读到的是过期数据 | **假设**: 选择一个信号稀疏的股票/参数组合, 让某帧无交易记录, 观察低周期图表中的跨周期 PnL 参考线是否未更新。**验证方法**: 回测中定位"无交易帧", 对比 session_state 中的 PnL 与实际当帧计算的 PnL |
| C3 | **日线合成永不触发 bug (已修复)** (T2 发现) | `_needs_synthesis` v1 | 低 (已修复) | 旧逻辑 `cutoff >= period_start`, 日线的 period_start 是次日 00:00, 同日 15:45 < 次日 00:00 永不触发合成。已通过 v2 的 `cutoff_dt >= last_ts` 修复 | 已修复, 不再可复现 |
| C4 | **时区字符串拼接 bug (已修复)** (T2 发现) | `_synthesize_incomplete_bar` v1/v2 | 低 (已修复) | v1/v2 通过字符串拼接时区偏移, "14:45+08:00" → "14:45-04:00" 是不同的绝对时间。v3 使用 `tz_convert()` 修复 | 已修复, 不再可复现 |

## 3. 误操作场景分析

### 场景1: "信号闪烁 — 做多信号消失"

- **前置条件**: 用户使用 Savitzky-Golay 滤波 (window=21), 在回测 bar=500 (约 21 个交易日前) 处看到日线 Sig=+1 (做多信号), sigma_v 的 EWMA span=60
- **操作**: 用户基于此信号判断"上升趋势确认", 在实际交易中于次日开盘做多
- **窗口滑动**: 前进到 bar=501, 新一天的数据进入, Savitzky-Golay 的右端 ~10 个点的 filtered 值微调
- **变化**: 
  - filtered[490] 从 102.3 变为 102.1 (Savitzky-Golay 边界效应, 差 0.2%)
  - v[490] 和 a[490] 随之微调
  - sigma_v[490:] (EWMA 递归, 影响 490~501 共 11 个点) 全部变化
  - eps[490] 从 0.15 变为 0.14 → a[490] 恰好跨过阈值
  - sig[490] 从 +1 变为 0 → 状态机 Cascade: sig[490:] 全部重建
  - all_pairs 中对应 pair 的 pair_end 从 520 变为 490 (提前结束)
  - PnL 曲线从有交易变为无交易
- **后果**: 用户已基于消失的信号做了真实交易决策, 但回测回顾时信号已不存在, 策略回测结果与实际持仓矛盾
- **根因**: A3 (Savitzky-Golay 边界效应) + A4 (状态机 Cascade) + B1 (EWMA sigma_v 的全局依赖)
- **发生概率**: **高频** (每次 bar 前进, 右端 ~10 个 bar 的 Sig 都可能变化)

### 场景2: "PnL 曲线面目全非"

- **前置条件**: 用户使用 Butterworth 零相位滤波, 在 bar=300 处回顾过去 120 个 bar 的策略表现, 看到 PnL 曲线稳步上升 (累积收益 +15%), 有 5 笔交易记录
- **操作**: 用户截图保存, 准备将策略推荐给他人
- **窗口滑动**: 前进到 bar=301
- **变化**:
  - Butterworth `sosfiltfilt` 是零相位双向滤波, 新数据点进入后**整个 120 个 bar 的 filtered 全部重新计算** (T3 发现)
  - filtered 全局变化 → v/a/sigma_v/eps/sig 全局变化
  - sig 序列可能完全不同 → all_pairs 完全重建 → 交易数量从 5 笔变为 3 笔
  - PnL 曲线从 +15% 变为 +8%, 形态完全不同
  - 交易入场/离场 bar index 全部改变
- **后果**: 用户之前看到的 +15% 收益曲线在新的回测视角下变成了 +8%, 之前认为优秀的策略表现实际上是滤波器的边界假象
- **根因**: B3 (Butterworth filtfilt 零相位设计) — 这是设计选择问题, 不是 bug, 但影响极严重
- **发生概率**: **每次必现** (Butterworth 下整个序列每帧都重算)

### 场景3: "跨周期信号矛盾导致双重误判"

- **前置条件**: 周线视图显示 Sig=+1 (做多), 日线视图显示同向性对齐子图 (alignment subplot) 为绿色高亮, 用户认为"周线做多+日线同向=强确认信号"
- **操作**: 用户据此加重仓位
- **窗口滑动**: 前进 1 个 bar
- **变化**:
  - 新 bar 进入 → 周线的 filtered 右端变化 → 周线 Sig 在 bar=50 处从 +1 变为 0
  - 周线 PnL 重建 → 写入 `session_state._pnl_周线`
  - 日线渲染时: Step 3 读取周线 PnL → 对齐到日线时间轴
  - 周线 Sig 变化 → 周线 trade_records 变化 → entry/exit markers 变化 → holding masks 变化
  - **但如果周线新 PnL 的 trade_records 为空 → session_state 不更新 (Bug C2)**
  - 日线读到的仍是旧周线 PnL → 同向性判断基于过期数据
- **后果**: 用户看到的日线 alignment 子图是基于"已消失的周线信号"的过期数据, 双重误判
- **根因**: A4 (状态机 Cascade) + C2 (跨周期 PnL 不写入的 bug)
- **发生概率**: **中频** (在信号稀疏的股票上更容易触发)

### 场景4: "配对消失 — 预测曲线蒸发"

- **前置条件**: 用户关注某 pair 的抛物线拟合, 橙色拟合曲线 + 紫色预测延伸线显示"预测曲线上翘, 即将做多"
- **操作**: 用户将 n_extend 设为 20, 等待预测验证
- **窗口滑动**: 前进 5 个 bar
- **变化**:
  - 每前进 1 个 bar: filtered 右端变化 → sig 右端变化 → all_pairs 变化
  - 到第 5 帧时, 原 pair 的结束点 (pair_end) 处的 sig 从 +1 变为 0
  - 原 pair 的 merged segment 被拆分 → 原 pair 消失
  - 预测曲线也从图表上消失
- **后果**: 用户跟踪了 5 帧的预测曲线突然消失, 之前基于预测的决策依据被推翻
- **根因**: A4 (状态机 Cascade) + B4 (pair 合并逻辑)
- **发生概率**: **高频** (每次 bar 前进, 靠近右端的 pair 都可能变化)

### 场景5: "回测重放不一致 — 同一 bar 两次看到不同信号"

- **前置条件**: 用户在自动播放模式下观看回测, 从 bar=100 播放到 bar=200
- **操作**: 用户注意到 bar=180 处的信号很漂亮, 暂停后手动回退到 bar=180 仔细研究
- **窗口滑动**: 手动设置 bar_index=180 (通过 slider)
- **变化**:
  - 自动播放时数据窗口是 [60, 180] (n_pts=120)
  - 手动回退时数据窗口是 [60, 180] (相同!)
  - **理论上应该看到完全相同的信号**
  - 但实际上: 级联合成中的合成 bar 可能有微小差异 (时区处理、浮点精度)
  - 如果完全相同, 信号也该完全相同 (系统从 parquet 加载后纯计算)
- **后果**: 如果手动回退看到的信号与播放时不同, 用户对系统可靠性失去信任
- **根因**: 理论上应一致 (所有计算是确定性的, 输入相同→输出相同), 但如果 parquet 写入/读取有缓存不一致, 可能有微小差异。主要是**信任危机**
- **发生概率**: **低频** (仅在用户手动回退时触发, 且需要存在缓存不一致)

## 4. 影响量化

### 4.1 信号变化概率与范围

| 指标 | 估算值 | 依据 |
|------|--------|------|
| **Sig 在已有 bar 上变化的概率** (每前进 1 bar) | **取决于滤波器**: Butterworth ~95%; Savitzky-Golay ~30-50%; LOWESS ~20-40%; Kalman ~10-20%; SMA/EMA ~5-10% | Butterworth 全局重算, 几乎所有历史 sig 都可能变; SMA/EMA 只有右端 1-2 个点变化, 只有最后几个 sig 可能变 |
| **变化的 bar 数** | 最后 1~120 个 bar (取决于滤波器) | Butterworth: 全部 120 bar; Savitzky-Golay: 最后 ~10 bar; SMA: 最后 1-2 bar |
| **受影响 bar 的范围** | 数据窗口靠右 1%~100% | 位置由"filtered 变化起点"到末尾 |
| **PnL 曲线变化幅度** | 从"微小调整"到"完全不同的形态" | SMA 滤波器下仅最后 1-2 笔交易可能微调; Butterworth 下整个 PnL 曲线可能面目全非 |
| **信号方向翻转概率** (在各 bar 上) | ~1-5% (SMA), ~10-30% (Savitzky-Golay), ~30-60% (Butterworth) | 取决于 eps 阈值附近信号的密度; Butterworth 历史值全变, 翻转概率最高 |

### 4.2 不同周期受影响程度

| 周期 | 受影响程度 | 原因 |
|------|-----------|------|
| **分钟级 (60min, 15min, 5min, 1min)** | **低-中** | 数据频率高, 单个 bar 的信息增量小, filtered/eps 变化幅度小; 但级联合成中的合成 bar 可能引入额外噪声 (粗粒度周期从分钟级聚合) |
| **日线** | **中-高** | 日线是核心分析周期, 窗口 120 天约 6 个月, 滤波边界效应明显 (特别是 Savitzky-Golay 和 LOWESS); 日线也是级联合成的关键中转节点 (日线合成 bar 被周线/月线/季线使用) |
| **周线** | **高** | 120 周约 2.3 年, 每个 bar 的信息量大, 级联合成中的不完整周线 bar 的 Close 每帧都在变化; 周线 Sig 的变化通过 session_state 传递到日线/60 分钟的对齐视图 |
| **月线/季线** | **中-低** | 虽然级联合成也在运行, 但 120 月=10 年, bar 数量少, 信号本身的稳定性高 (低频周期天然对噪声不敏感) |


## 5. 关键结论

### 5.1 根因一句话总结

**Sig/PnL 在回测窗口滑动后发生变化的根本原因是: 滤波器的端点效应 + np.gradient 的边界退化 + EWMA sigma_v 的全局递归依赖 + Schmitt 状态机的 Cascade 传播, 四个环节形成了一个"放大链"——1 个 bar 的 filtered 变化经过 gradient 放大、EWMA 全局传播、状态机 Cascade 后, 可能导致几十个 bar 的 Sig 序列完全重建和整条 PnL 曲线面目全非。这不是单一的 bug, 而是"滑动窗口 + 自适应信号处理"这一架构的系统性特性。**

### 5.2 三个最关键的可操作发现

1. **Butterworth 零相位滤波是最大的信号不稳定源** (B3, 严重度: 高): 双向滤波导致每帧整个序列重算, 信号历史完全不可信。建议 T5 方案中将 Butterworth 标记为"不适合回测模式"或替换为因果滤波 (lfilter)。

2. **EWMA sigma_v + Schmitt 状态机构成了"乘法放大效应"** (A4+A5+B1, 严重度: 高): 一个 bar 的 v 变化通过 EWMA 传播到 ~60 个点的 eps, 再通过状态机 Cascade 到之后的全部 sig。建议 T5 考虑将 EWMA 替换为滚动窗口标准差以限制传播范围, 或在 Schmitt 触发器中引入"信号锁定"机制 (信号一旦产生, 在一定区间内不因阈值微调而翻转)。

3. **哨兵值 100.0 和跨周期 PnL 不写入是两个已确认的 bug** (C1+C2, 严重度: 高/中): C1 在 PnL 回到 100.0 时导致前向填充错误; C2 在无交易帧导致低周期看到过期跨周期 PnL。这两个 bug 应在 T5 方案中优先修复。

### 5.3 对 T5 策略方案设计的输入

T5 在设计缓解方案时应考虑:

- **短期** (不改架构): 修复 C1 和 C2 两个 bug; 将 Butterworth 标记为"实验性/仅供浏览模式"; 在 UI 上增加"信号置信度"标注 (标记靠近右边界的 bar 的 Sig 不稳定)。
- **中期** (局部重构): 将 EWMA sigma_v 替换为滚动窗口标准差 (限制传播范围); 在 Schmitt 触发器中增加"最小持仓 bar 数"约束 (避免信号闪烁); 使用 np.nan 替代 100.0 哨兵值。
- **长期** (架构优化): 考虑"锁定历史信号"机制 — 已经过确认的历史 bar 的 Sig 不应因新数据加入而改变 (可通过固定滤波 + 仅对新 bar 运行状态机实现); 实现增量更新而非全量重算。
