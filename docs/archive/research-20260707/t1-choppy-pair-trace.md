## 0. 关键事实：跨零合并的确切规则（先给结论）

逐行读 `_find_all_pairs`（L542–576）得到三步：

- **Step1 收集非零段（L542–554）**：线性扫描，把每一段连续相同的非零值收成 `(start,end,val)`。**所有 0 在这一步被直接丢弃**——0 不进 segments，也不留任何"gap 长度"信息。
- **Step2 跨零合并（L559–566）**：`merged=[segments[0]]`，逐个看下一段 `if seg[2]==last[2]` 就合并 `merged[-1]=(last[0], seg[1], seg[2])`。判据**只有一个：符号相同**。
- **Step3 异号配对（L568–576）**：相邻 merged 段异号则 `pairs.append((s1, s2))`，即 `(前段起点, 后段起点)`。

由此得到两条确切规则，均已由执行验证：

1. **没有 gap 上限。** 合并只看"符号是否相同"，完全不看两段之间隔了几个 0。V2 `[+1,0,0,0,+1]` 隔 3 个 0 仍合并成 `(0,4,+1)`（已执行确认）。隔 3 个还是隔 300 个 0，结果一样——只要中间**没有非零反向段**。
2. **合并只被"反向非零段"打断，哪怕只有 1 根。** V3 `[+1,0,-1,0,+1,0,-1]` 中间的单根 `-1` 让两个 `+1` 无法合并（它们在 segments 里不相邻）。所以 **同向断续被平滑、异号断续被放大** 是这段代码的核心非对称性。

**合并后 pair 的锚点（L564, L574）**：
- 合并段 `start = 第一段的 start`（最早那个 +1），`end = 最后一段的 end`。
- `pair = (s1, s2)`：`pair_start` = 当前方向合并段起点（最早的 +1）；`pair_end` = **下一个反向合并段的起点**（反向信号入口边缘），不是本方向段的终点。

## 1. 五个变体逐步追踪（中间值均为代码输出）

### V1 `[+1,0,+1,0,-1]`（主问题）
```
Step1 segments = [(0,0,+1), (2,2,+1), (4,4,-1)]
Step2 merged   = [(0,2,+1), (4,4,-1)]          # 两个 +1 跨中间的 0 合并
Step3 pairs    = [(0,4)]                        # pair_start=0(第一个+1), pair_end=4(-1入口)
current half-edge (若截到此) = (0,2,+1)
```
两个断续 `+1` 合并为 `(0,2,+1)`；配对止于反向 `-1` 的入口 index 4。**pair 起点被定为第一个 +1（index 0），不是第二个（index 2）。**

### V2 `[+1,0,0,0,+1]`（大 gap，多个 0）
```
Step1 segments = [(0,0,+1), (4,4,+1)]
Step2 merged   = [(0,4,+1)]                     # 隔 3 个 0 照样合并
Step3 pairs    = []                             # 只有一个方向, 无异号 → 无 pair
current half-edge = (0,4,+1)  dir=+1
```
**验证"无 gap 上限"**。当前半边 = 从 index 0 延续到 index 4 的单一 `+1`；无完整 pair 输出（`_find_all_pairs` 只吐完整对，不吐结尾半边）。

### V3 `[+1,0,-1,0,+1,0,-1]`（多空交替震荡）
```
Step1 segments = [(0,0,+1),(2,2,-1),(4,4,+1),(6,6,-1)]
Step2 merged   = 同上, 无合并            # 相邻全异号, 一根都不并
Step3 pairs    = [(0,2),(2,4),(4,6)]     # 3 个单根 pair
```
逐帧 dir_C（右边缘增量，取 merged[-1] 符号，代码输出）：
```
frame0 +1→dir +1 | frame1 0→dir +1 | frame2 -1→dir -1 | frame3 0→dir -1
frame4 +1→dir +1 | frame5 0→dir +1 | frame6 -1→dir -1
```
**单根反向即翻 dir**：dir_C 在 +1/-1 间来回跳 4 次，且每帧的 0 不改变 dir（保持上一段方向）。震荡产生 3 个 pair → 潜在 3 笔交易。

### V4 `[+1,0,+1,0,+1]`（断续型半边，末尾未反向）
```
Step1 segments = [(0,0,+1),(2,2,+1),(4,4,+1)]
Step2 merged   = [(0,4,+1)]              # 三段全合并
Step3 pairs    = []                      # 无异号 → 无 pair
current half-edge = (0,4,+1)  dir=+1
```
断续但同向的半边被完全平滑成一段 `(0,4,+1)`，起点锚在 index 0。

**四变体对照总表：**

| 变体 | segments | merged | pairs | 现象 |
|---|---|---|---|---|
| V1 同向停顿+反转 | 3 段 | `[(0,2,+1),(4,4,-1)]` | `[(0,4)]` | 同向合并，止于反向入口 |
| V2 大 gap 同向 | 2 段 | `[(0,4,+1)]` | `[]` | 无 gap 上限，合并 |
| V3 多空震荡 | 4 段 | 不合并 | `[(0,2),(2,4),(4,6)]` | 单根反向碎片化→3 笔 |
| V4 同向断续半边 | 3 段 | `[(0,4,+1)]` | `[]` | 断续被平滑成一段 |

## 3. 对 v3 五个构件的影响（逐条：现在怎么处理 + 是否有问题）

### a. 半边起点定义
- **现在怎么处理**：`_find_all_pairs` 把断续同向的起点合并锚定到**第一个 +1**（V1→index 0，V4→index 0）。源码 PnL 实际不用 pair_start 入场（用 pair_end），所以对当前回测**无直接失真**。
- **v3 若实现（起点即入场）**：起点被锚到最早的 +1。问题真实存在——V4 若第一个 +1 是随后衰减的噪声起步，v3 会在 index 0 入场；而**真正的趋势可能在第三个 +1（index 4）才启动，但 merge 把 index 4 折进 index 0 的段里，不会产生新的 pair_start**。→ 结果是"要么在假起点 index 0 进早了，要么错过 index 4 的真启动，二者必居其一"。
- **判定**：⚠️ **分类盲区（v3 层）**。同向断续下，"趋势真正发力点"无法作为新起点被识别；merge 抹平了它。

### b. 半边纯度（无中间 0）
- **现在怎么处理**：**源码里根本没有"纯度"这个量**。逐行确认：既无 0 计数、也无 gap 长度记录（0 在 Step1 就被丢弃）。文档中"Sig→0"只作为 WEAK_ALIGN 的**软降速预警**（L157/L240 "sig_C==0，软，可关"），且**只看当前帧**，不累计历史停顿次数。
- **是否有问题**：用户设问里"v3 用 Sig 纯度作可靠性指标"这一前提**与文档不符**——v3 文档并没有纯度评分构件，只有当前帧的软 decel 预警。所以 `[+1,0,+1,0]` 的低纯度**当前不被任何构件扣分**。
- **判定**：⚠️ **分类盲区**。断续历史（隔了几个 0、停顿几次）这一信息在 v2/v3/源码三处都未量化，是共同缺口。

### c. C 的 5 态
- **现在怎么处理**：v3 的 C 五态是**逐帧无记忆**的——只看当帧 `dir_C / signed_dev / reverse_run / sig_C==0`。对 V4 `[...,+1]` 当前帧 sig=+1、dev 低 → 判 **STRONG_ALIGN**。"这段一路 +1,0,+1 震了很多次"的历史**不进入状态判定**。
- **是否有问题**：一个抖了 5 次的虚弱趋势与一个干净强趋势，只要当帧都是 +1 且 dev 低，C 状态**完全相同**。软 decel 预警只在"恰好当帧 sig==0"那一根触发，抖动一过又回 STRONG，不留痕迹。B 会在这种貌似 STRONG、实则断续的 C 上照常入场。
- **判定**：⚠️ **分类盲区**。C 五态缺一个"累计断续度/衰竭度"维度；当前只有瞬时快照。

### d. N_confirm 反转
- **现在怎么处理（源码）**：`_compute_strategy_pnl` 离场用**单根** `sig_t[i]==-1`（L774），**无 N_confirm**。V3 `[+1,0,-1,0,+1]` 中那根 1 bar 的 `-1` 会**直接触发多头止盈平仓**（reverse_run 等价=1 即离场）。→ 假反转砍仓 + 随后 index 4 又 +1，典型 whipsaw。
- **现在怎么处理（`_find_all_pairs` 的 dir_C）**：更严重——pair 的 dir 由 `merged[-1]` 符号决定，**单根反向即翻 dir**（V3 逐帧输出：dir 在 +1/-1 间跳 4 次）。`_find_all_pairs` 内**没有任何 N_confirm 门控**。
- **v3 设计**：假定 `dir_C` 只在 `reverse_run ≥ N_confirm` 才翻（→MISALIGN）。这与源码**实际的即时翻转 dir 相矛盾**——文档假设的 N_confirm 门尚未在 `_find_all_pairs` 里实现。断续震荡会让 reverse_run 反复在 0 处重置（V3 frame3 的 0 打断 -1 计数），既确认不了真反转，又因源码即时翻 dir 而**制造假反转**。
- **判定**：❌ **分类盲区 + 源码与设计不一致**。这是断续序列最尖锐的问题：同向抖动被 merge 保护，反向抖动却毫无缓冲，一根就翻向/砍仓。

### e. entry_void
- **现在怎么处理**：源码**未实现** entry_void（入场在 pair_end 反转边缘，不存在"起点蒸发"场景）。仅能评估 v3 假设。
- **v3 若实现**：关键取决于 entry_void 用哪种 dir。追踪 `[+1,0,+1]` 增量：frame1 数据 `[+1,0]`，merged=`[(0,0,+1)]`，**dir_now 仍 = +1**（尾随单个 0 不改 pair 方向）；frame2 再 +1 合并。→ 整个 `[+1,0,+1]` 期间 pair 层 dir_now 从不离开 +1。
  - 若 entry_void 判据是 **pair 层 dir_now**：merge 天然保护，**不会误触发**（短暂降速的 0 被吸收）。✅
  - 若 entry_void 判据是 **原始 sig_C==0**：第 2 根就误判"起点蒸发"→ 误砍仓。❌
- **判定**：✅ **已可正确处理（条件性）**——只要 entry_void 挂在 pair 层 dir（而非裸 sig）上，`_find_all_pairs` 的合并逻辑就已经把"短暂降速 0"消化掉了。这是本次追踪中唯一"现有合并逻辑已正确兜底"的构件，需在实现时明确用 pair-dir。

## 4. 明确标注：已正确处理 vs 分类盲区

**✅ 现有逻辑已正确处理：**
1. **同向断续的合并**（V1/V2/V4）：`+1,0,+1` 稳定合并成一段，对任意 gap 鲁棒（无 gap 上限），不会因中间降速的 0 把一段趋势拆成两段。
2. **entry_void 抗短暂降速**（条件性）：pair 层 dir_now 在尾随 0 时保持原向，若 entry_void 挂在 pair-dir 上则不会被 `[+1,0,+1]` 误触发。

**❌ 分类盲区需升级：**
1. **反向单根即翻/即砍（最尖锐）**：`_find_all_pairs` 的 dir 由 merged[-1] 决定，单根 `-1` 即翻 dir；`_compute_strategy_pnl` 单根 `sig==-1` 即离场。二者都**无 N_confirm**，与 v3 假设直接冲突。异号断续 = 无缓冲的 whipsaw。→ 需在 dir 判定与离场①都补 `reverse_run ≥ N_confirm` 门控。
2. **断续度/纯度不可见**：0 在 Step1 即被丢弃，gap 长度与停顿次数无处留存；v3 也无纯度构件。C 状态与半边可靠性都拿不到"这段抖了几次"。→ 需新增累计断续度指标喂给 C 五态 / 可靠性评分。
3. **同向真启动点丢失**：merge 把趋势真正发力的后续 +1 折回最早起点，v3"起点即入场"会锚到可能是噪声的第一个 +1，且不为真启动生成新 pair_start。→ 需区分"噪声起步"与"真启动"，或允许起点在段内迁移。
4. **C 五态无记忆**：逐帧快照使断续弱趋势与干净强趋势在当帧 +1 时判定相同；软 decel 预警不累计。→ 需把断续历史并入 C 状态，而非只看当前帧。

**核心一句话**：这段代码对**同向断续（+1,0,+1）友好**（合并、抗降速），对**异号断续（+1,0,-1,0,+1）脆弱**（单根翻向、单根砍仓、碎片化成多笔）。v3 文档假设的 N_confirm 门控在 `_find_all_pairs`/`_compute_strategy_pnl` 里**尚未落地**，是断续震荡序列被误分类的根因。
