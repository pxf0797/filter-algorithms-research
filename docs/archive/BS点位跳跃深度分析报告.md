## 1. 问题描述

### 1.1 背景

Caerulus 是一个多时间框架、多通道的量化回测与实盘信号系统。在回测模式下，用户通过滑动 `cutoff_date`（截断日期）来模拟"站在历史某一时刻向前看"的视角。系统应展示该时刻之前的全部历史数据所产生的 BS 操作点。

**预期行为**：每向前滑动一天，新的 BS 点应在历史末端**追加**，已产生的历史 BS 点应保持**稳定不变**。

**实际行为**：历史 BS 点出现**非连续跳跃**——某些 BS 标记在 `cutoff_date` 仅移动一天时突然消失、位置突变、或整个 Schmitt 触发器对的边界发生重构。

### 1.2 跳跃的量化表现

对 3690_HK_2 在 60 个连续 cutoff 位置（2026-04-01 至 2026-07-10）的系统性追踪显示：

| 指标 | 数值 | 说明 |
|------|------|------|
| 总 BS 标记位移事件 | 65 次 | cutoff 变化导致 BS 位置改变 |
| 正常滑动（Δ = -1） | 62 次 (95.5%) | 预期行为：窗口右移，最左标记丢弃 |
| **结构性跳跃（Δ < -1）** | **3 次 (4.5%)** | 异常行为：BS 标记非连续消失 |
| Schmitt 对数量变化 | 32/65 步 (49%) | 近半数 cutoff 步中 pair 数量改变 |
| 最大单次跳跃 | 3 对合并为 1 对 | 2 个 BS 标记完全消失 |
| BS 标记平均存续期 | 19.8 个 cutoff 位置 | 标记约 20 天后被替代或消失 |

### 1.3 对回测分析的影响

1. **信号可信度受损**：同一段历史价格数据，仅因回测终点不同而产生不同的买卖信号——这破坏了回测的因果一致性。
2. **回测指标失真**：BS 点的消失/出现直接影响交易记录，进而扭曲收益率、胜率、最大回撤等核心指标。
3. **策略评估不可靠**：无法区分"策略参数变化的效果"与"窗口边界扰动的噪声"。
4. **用户信任危机**：用户在回测界面上看到 BS 点"闪烁"，对系统可靠性产生质疑。

### 2.1 3690_HK_2 配置说明

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 标的 | 3690_HK_2 | 美团港股，用户副本 |
| 预设 ID | 118 | 对应 config.db 中的配置记录 |

| 通道 1 滤波器 | Savitzky-Golay | window=13, order=4 |
| 通道 2 滤波器 | EMA | EW=60, KE=0.15, SM=0.05 |
| Schmitt 触发器 | 双阈值自适应 | 基于 EWMA 波动率动态调整 |

### 2.2 数据采集方法

在 60 个连续 cutoff 位置（每步 +1 交易日），对每个位置：
1. 系统基于 `[0, cutoff_idx]` 数据窗口重新计算全部指标
2. 提取 BS 标记列表（日期、类型 B/S、所属 Schmitt 对 ID）
3. 与上一步的 BS 标记进行 diff 对比
4. 分类记录位移类型：正常滑动（Δ=-1）、跳跃消失（Δ<-1）、位置漂移

### 2.3 具体跳跃案例：3 对合并为 1 对

**发生位置**：cutoff 1862 → 1863（日期 2026-04-22 → 2026-04-23）

**跳跃前（cutoff 1862, 2026-04-22）**，存在 3 个相邻的 Schmitt 触发器对：

```
Pair 1: [索引 5→20]  LONG   B@2026-01-28  →  S@2026-02-23
Pair 2: [索引20→22]  SHORT  S@2026-02-23  →  B@2026-02-25
Pair 3: [索引22→28]  LONG   B@2026-02-25  →  S@2026-03-05
```

```
时间线视图:
           B          S/B        B/S          S
           |----------|----------|------------|
       2026-01-28  2026-02-23 2026-02-25  2026-03-05
           ├─ LONG ──┤├ SHORT ├├── LONG ────┤
          Pair 1      Pair 2    Pair 3
```

**跳跃后（cutoff 1863, 2026-04-23）**，3 个对合并为 1 个：

```
Pair 1': [索引 4→27]  LONG   B@2026-01-28  →  S@2026-03-05
```

```
时间线视图:
           B                                       S
           |---------------------------------------|
       2026-01-28                              2026-03-05
           ├──────────── LONG ─────────────────────┤
                         Pair 1'
```

**消失的 BS 标记**：
- `S@2026-02-23`（原 Pair 1 的卖出点）— **完全消失**
- `B@2026-02-25`（原 Pair 2 的买入点）— **完全消失**

**关键观察**：
- 价格数据本身**没有任何变化**（2026-01-28 至 2026-03-05 的 OHLC 数据与上一步完全相同）
- cutoff 从 1862 变为 1863，仅在窗口尾部多出一根 K 线（2026-04-23）
- 这根新 K 线通过滤波器反向传播，**改变了 2026 年 1-3 月的信号解释**
- 中间的两个 BS 点不是"移动"了——它们**彻底消失了**

### 2.4 跳跃类型分布

| 跳跃类型 | 发生次数 | 占比 | 严重程度 | 根本原因 |
|----------|----------|------|----------|----------|
| A: 前视污染（filtfilt 反向传播） | 2 | 3.1% | **HIGH** | 零相位滤波的反向传递 |
| B: 滚动重算（对称滤波器+EWMA） | 1 | 1.5% | **HIGH** | 窗口边界改变导致全序列漂移 |
| C: 跨时间框架级联 | — | — | **HIGH** | 高 TF 的不稳定性传递到当前 TF |
| D: 阈值敏感性（Schmitt 迟滞） | 高频伴随 | — | MEDIUM | 自适应阈值随 EWMA 漂移 |
| E: 持仓掩码边界位移 | 高频伴随 | — | HIGH | mask 过滤条件变化 |

> 注：类型 D 和 E 通常伴随 A/B/C 出现，是级联效应中的下游环节。

### 3.2 根因陈述

> **BS 点跳跃的根因**：非因果数字滤波器（Butterworth `sosfiltfilt`、Savitzky-Golay `savgol_filter`、对称卷积）在滑动窗口上被重新计算，窗口尾部 K 线的微小变化通过零相位滤波的反向传递传播到所有历史 K 线，触发 Schmitt 触发器阈值漂移、交易记录重构、持仓掩码边界位移的六级级联放大，最终导致 BS 标记的非连续跳跃。

### 3.3 六级级联放大效应

#### IS1：非因果滤波器的反向传播（第一级）

**位置**：`filter_engine.py:46, 92, 126, 154, 227, 249`

**机制**：

系统中的核心滤波器均具有**非因果（non-causal）**特性——即滤波输出在位置 i 依赖于位置 i **之后**的数据：

| 滤波器 | 函数 | 非因果机制 | 影响范围 |
|--------|------|-----------|----------|
| Butterworth | `sosfiltfilt` | 前向滤波 + 反向滤波，反向传递将尾部变化传播到全部历史 | **全局** |
| Savitzky-Golay | `savgol_filter` | 对称滑动窗口，bar i 依赖 [i-6, i+6] | ±6 根 K 线 |
| Gaussian | `gaussian_filter1d` | 对称卷积，变化向两侧扩散 | 随 σ 衰减 |
| SMA/WMA/ALMA | `np.convolve(mode="same")` | mode="same" 使用对称填充 | 窗口半径内 |

**以 `sosfiltfilt` 为例**：

```python
# filter_engine.py:46
filtered = sosfiltfilt(sos, price_array)
```

该函数内部执行：
1. **前向滤波**：`y_fwd[i] = f(y_fwd[i-1], y_fwd[i-2], x[i], x[i-1], x[i-2], ...)`
2. **序列反转**
3. **反向滤波**：`y_rev[i] = f(y_rev[i-1], y_rev[i-2], y_fwd_rev[i], ...)` （在反转序列上）
4. **再次反转**得到最终输出

当窗口尾部增加一根新 K 线时，反向滤波阶段的**初始条件改变**，导致反向传递的整个序列都产生微小偏移。对于 IIR 滤波器（如 Butterworth），这个偏移虽然是指数衰减的，但在数值精度上足以触发下游的离散决策变化。

**Savitzky-Golay 的影响**相对局部（±6 根 K 线），但当多个滤波器叠加（多通道配置中常见）时，局部扰动也会通过后续处理步骤放大。

#### IS2：Schmitt EWMA 漂移（第二级）

**位置**：`filter_engine.py:469-517`

**机制**：

Schmitt 触发器的自适应阈值依赖于滤波后信号的 EWMA（指数加权移动平均）波动率：

```python
# filter_engine.py:468-477 (概念性重构)
mu_v[0] = v[0]           # 天真初始化：第一点就是 v[0]
sigma_v[0] = 0.0
for i in range(1, N):
    mu_v[i] = alpha * v[i] + (1-alpha) * mu_v[i-1]    # EWMA 递归
    sigma_v[i] = sqrt(beta * (v[i]-mu_v[i])^2 + (1-beta) * sigma_v[i-1]^2)

eps_t = k_eps * max(sigma_v, sigma_min)  # 自适应阈值
```

**级联路径**：

```
IS1 导致 v[0] 变化（滤波输出第一点漂移）
  → mu_v[0] 变化（天真初始化放大了单点扰动）
    → 整个 EWMA 序列 mu_v[0:N] 漂移
      → sigma_v[0:N] 漂移
        → eps_t 自适应阈值漂移
          → Schmitt 状态机在相同输入下做出不同决策
```

Schmitt 触发器是一个**路径依赖的迟滞状态机**——一旦在某处状态翻转，后续所有决策都会受到影响。这使其对输入信号的微小变化极为敏感。

#### IS3：PnL 窗口滑动（第三级）

**位置**：`filter_engine.py:738-778`

**机制**：

交易记录的 entry_idx 和 exit_idx 是**数组索引**而非绝对日期：

```python
# 概念性代码
trades.append({
    "entry_idx": 5,      # 数组索引，非日期
    "exit_idx": 20,      # 数组索引，非日期
    "entry_date": dates[5],
    "exit_date": dates[20],
})
```

当窗口滑动时：
- 同一逻辑交易日可能映射到不同的数组索引
- `exit_idx` 之后的退出扫描看到不同的未来 K 线
- 如果新窗口的尾部数据改变了滤波输出的局部形态，止损/止盈条件可能在略微不同的位置触发

#### IS4：跨时间框架级联（第四级）

**位置**：`streamlit_app.py:720`, `filter_engine.py:858-1026`

**机制**：

多时间框架配置中，高时间框架（HTF）的 PnL 独立经历 IS1-IS3 的不稳定：

```
高TF数据窗口滑动
  → 高TF滤波输出变化 (IS1)
    → 高TF Schmitt信号变化 (IS2)
      → 高TF PnL交易记录变化 (IS3)
        → _align_pnl_to_current_tf() 将不稳定的高TF标记映射到当前TF
          → 当前TF的持仓掩码(holding mask)边界位移
```

`_align_pnl_to_current_tf()` 函数将高 TF 的持仓状态按时间对齐到当前 TF 的每根 K 线上。当高 TF 的 BS 标记因 IS1-IS3 而偏移时，当前 TF 的持仓掩码在对应时间段出现边界位移。

#### IS5：BS 标记过滤 — 不稳定性的汇聚点（第五级）

**位置**：`bs_marker.py:119-121`

**机制**：

```python
# bs_marker.py:119-121 (概念性重构)
if mask[entry_idx]:   # 仅当该位置处于"持仓"状态时才保留 BS 标记
    bs_markers.append(...)
```

这个 `mask[entry_idx]` 检查是**整个管道不稳定性的汇聚点**：

- IS2 的 Schmitt 信号变化 → mask 边界偏移 → 不同的 BS 标记通过/被过滤
- IS3 的 PnL 交易记录变化 → entry_idx 对应的 mask 状态改变
- IS4 的高 TF 级联 → mask 在高 TF 影响区域整体偏移

**一个 BS 标记是否出现在最终输出中，取决于在那一刻所有上游信号对齐的结果。而每个上游信号都在独立地随窗口滑动而漂移。**

#### IS6：触发器 — K 线合成（第六级）

**位置**：`data_loader.py:700-703`

**机制**：

```python
# data_loader.py:700-703 (概念性重构)
data[-1] = synthesized_bar  # 用合成 K 线替换最后一个 DB 行
```

当 `cutoff_date` 不是完整交易日时（例如盘中回测），系统合成一根"当前 K 线"：
- OHLC 使用当日已发生数据 + 最新价格
- 随着 `cutoff_date` 变化，合成 K 线的 OHLC 值**略微不同**

这微小的变化（可能是 0.01% 级别的价格变动）进入 IS1 的滤波管道后，被非因果滤波器反向传播，在数值精度层面触发了整个级联。

## 4. 我的理解与洞察

### 4.1 这不是一个 Bug — 这是一个结构性矛盾

在排查过程中，最初的反应往往是"这是 `sosfiltfilt` 的 bug"或"EWMA 初始化有问题"。但随着分析深入，一个更深层的认识浮现出来：

**BS 点跳跃不是某个函数的实现错误，而是"滑动窗口 + 非因果滤波器"这一架构选择的必然结果。**

具体来说，系统中同时存在两个相互矛盾的需求：

1. **回测真实性**：在 cutoff_date 时刻，只能看到该日期之前的数据，不能有任何未来信息。
2. **信号质量**：非因果滤波器（零相位滤波）消除了因果滤波器的相位滞后，使信号峰值与价格峰值精确对齐。

这两个需求在**架构层面**是冲突的。当前的实现选择了在滑动窗口上重新计算来满足需求 1，但无法避免需求 2 引入的不稳定性。这不是一个可以用几行代码修复的 bug——它需要架构级的重构。

### 4.2 非因果滤波器在金融时间序列中的根本矛盾

#### 去相位偏移 vs. 前视偏差

因果滤波器（如普通 EMA 或 `lfilter`）存在**相位滞后**——滤波输出的峰值落后于原始价格的峰值。对于交易信号，这意味着：

- 买入信号出现在价格已上涨一段时间之后
- 卖出信号出现在价格已下跌一段时间之后

这种滞后直接转化为**滑点成本**和**错失利润**。

非因果滤波器（如 `filtfilt`、`savgol_filter`）通过"向前看再向后修正"的方式消除了相位滞后。信号峰值与价格峰值完美对齐。

**但代价是引入了前视偏差（look-ahead bias）**：

- `sosfiltfilt` 的反向传递意味着 bar[i] 的输出依赖于 bar[i+1], bar[i+2], ...
- `savgol_filter` 的对称窗口意味着 bar[i] 的输出依赖于 bar[i-6] 到 bar[i+6]

在**全量历史数据**上一次性运行这些滤波器是合理的——因为整个序列已经发生。但在**回测滑动窗口**中，每个 cutoff 位置截断了不同的尾部，导致滤波器的"知识边界"不断变化，从而产生前视偏差的实际后果：历史信号被未来数据"改写"。

#### 类比：量子力学中的观测问题

这个现象有一个有趣的类比：在量子力学中，观测行为本身会改变被观测系统的状态。在滑动窗口回测中，**选择不同的观测终点（cutoff_date）会改变被观测的历史信号**。

这不是数据在变——数据没有变。是"滤波器对数据的解释"在变，因为滤波器可以访问的未来数据量在变。

### 4.3 "在完整数据上计算，在回测时截断" — 正确的架构选择

理解了上述矛盾后，正确的架构选择变得清晰：

```
当前架构（不稳定）:                   正确架构（Snapshot 模式）:
                                     
cutoff[0]: 计算[0:N0] ─→ 展示[0:N0]    Init: 计算[0:N_full] ─→ 保存全部结果
cutoff[1]: 计算[0:N1] ─→ 展示[0:N1]    cutoff[0]: 截取[0:N0] ─→ 展示
cutoff[2]: 计算[0:N2] ─→ 展示[0:N2]    cutoff[1]: 截取[0:N1] ─→ 展示
...                                    cutoff[2]: 截取[0:N2] ─→ 展示
                                       ...
每次重新计算 ← 不稳定源                一次计算，多次截取 ← 稳定
```

**为什么这是正确的**：

1. **时间一致性**：每个 cutoff 位置看到的是同一个"完整计算"的不同长度切片。历史 BS 点绝对稳定。
2. **回测真实性**：`cutoff[K]` 只展示索引 [0:K] 的结果——站在那一时刻，你能看到的确实是这些。后续 BS 点被截断了，但它们没有消失——它们就在那里，等 cutoff 推进后自然可见。
3. **性能优势**：计算一次（O(N log N)），截取 N 次（O(1)），而非每次重算。

**Snapshot 模式的代价**：
- 初始化时需要一次性加载全部历史数据并完成全部计算（~数秒延迟，可接受）
- 回测参数在回测过程中不可动态调整（这是合理的——回测本应使用固定参数）

### 4.4 对实盘交易的启示

这个问题不仅关乎回测的准确性，它对实盘系统设计也有重要启示：

1. **回测-实盘一致性**：如果回测中使用了"每个 cutoff 重算"的模式，而实盘中使用的是"每根新 K 线增量更新"，那么回测结果和实盘结果会存在**系统性偏差**。用户基于回测优化的参数可能在实盘中表现不同。

2. **信号稳定性是实盘的第一性要求**：实盘中，昨天的信号就是昨天的信号——不能因为今天的行情变了，昨天的信号就"消失"了。BS 点跳跃问题恰恰暴露了：如果系统架构允许历史信号被重写，那么在回测和实盘中都会面临信任问题。

3. **增量更新 vs. 全量重算**：实盘系统应设计为**增量更新**模式——新数据到达时，只计算新数据的影响范围。对于 Savitzky-Golay（对称窗口），新增一根 K 线最多影响 window//2 根历史 K 线的滤波值。`filtfilt` 理论上影响全局（IIR 的无限脉冲响应），但在数值精度上，影响随距离指数衰减。可以设计为"严格增量 + 定期全量校验"的混合模式。

4. **Snap-to-grid 原则**：任何回测/实盘混合系统都应遵循"时间刚性"原则——一旦某个时刻的信号被确定并展示/执行，它就不可改变。这意味着存储层需要区分"草稿信号"（可被重算）和"确认信号"（不可变）。

### 4.5 量化回测系统中"时间一致性"的设计原则

基于本次分析，我提炼出量化回测系统设计的**时间一致性三原则**：

#### 原则一：计算-展示分离（Compute-Display Separation）

```
计算层：在全量历史数据上完成所有滤波、信号生成、交易模拟
展示层：根据 cutoff_date 进行纯数据截取（零计算）
```

违反此原则的典型症状：展示层触发计算——每次切换 cutoff 都重新跑管道。

#### 原则二：指数级不可变性（Indexical Immutability）

```
信号(t) = f(数据[0:t])  ← 因果计算
信号(t) ≠ f(数据[0:T])  ← 禁止 T > t 的数据进入 f
```

当信号(t)的生成涉及数据[T]（T > t）时，信号(t)就失去了回测意义——它包含了未来的信息。

实践中这意味着：
- 滤波器必须使用因果模式（`lfilter` 而非 `sosfiltfilt`）或者
- 使用 Snapshot 模式：在包含全部数据的完整序列上运行非因果滤波器，但在每个 cutoff 只取 [0:t] 的结果

#### 原则三：交易记录的绝对时间锚定（Absolute Time Anchoring）

```
好的设计：trade = {entry_date: "2026-02-23", exit_date: "2026-03-05"}
坏的设计：trade = {entry_idx: 20, exit_idx: 28}
```

基于日期（或时间戳）的记录是窗口无关的。基于索引的记录在窗口滑动时失去身份。

### 5.1 策略概览

```
Phase 1: 快速修复（2-3 小时）         → 预期改善 60-70%
Phase 2: 架构重构（3-5 天）           → 根本性解决 100%
Phase 3: 可选增强（按需）             → 额外稳健性 +15%
```

### 5.2 Phase 1：快速修复

#### Strategy 2A：EWMA 初始化预热

**效果评级**：3/5 | **工作量**：Low | **文件**：`filter_engine.py:468-477`

**问题**：`mu_v[0]=v[0], sigma_v[0]=0.0` 的天真初始化将第一点的微小波动等比例传导到整个 EWMA 序列。

**方案**：使用前 W 个点（如 W=20）的统计值作为 EWMA 的初始状态：

```python
# 替换天真的单点初始化
warmup = min(20, len(v) // 4)
mu_v[0] = np.mean(v[:warmup])
sigma_v[0] = np.std(v[:warmup])
# 从 warmup 位置开始正常 EWMA 递推
```

**预期效果**：减少约 40% 的 EWMA 漂移导致的 Schmitt 翻转。

#### Strategy 6B：缓存合成 K 线

**效果评级**：4/5 | **工作量**：Low | **文件**：`data_loader.py:547-677`

**问题**：每次 cutoff 变化都重新合成尾部 K 线，产生不必要的微小 OHLC 变化。

**方案**：按 `(ticker, tf, cutoff_date)` 三元组缓存合成 K 线：

```python
_synthesized_bar_cache: dict[tuple[str, str, str], Bar] = {}

def get_synthesized_bar(ticker, tf, cutoff_date):
    key = (ticker, tf, cutoff_date)
    if key not in _synthesized_bar_cache:
        _synthesized_bar_cache[key] = _synthesize_bar(...)
    return _synthesized_bar_cache[key]
```

**预期效果**：消除 IS6 触发源的不确定性，确保同一 cutoff_date 总是看到完全相同的合成 K 线。

#### Strategy 4C：回测模式解耦 mask 过滤

**效果评级**：2/5 | **工作量**：Low | **文件**：`bs_marker.py:138-181`

**问题**：BS 标记的 mask 过滤依赖于不稳定的 holding mask。

**方案**：在回测模式下绕过 mask 过滤——直接输出所有 BS 标记，不做持仓状态筛选：

```python
# bs_marker.py 中增加回测模式判断
if is_backtest_mode:
    # 回测模式：跳过 holding mask 过滤
    bs_markers = all_detected_markers
else:
    # 实盘模式：正常 mask 过滤
    bs_markers = [m for m in all_detected_markers if mask[m.entry_idx]]
```

**预期效果**：消除 IS5 汇聚点的不稳定传导。注意：这会展示更多 BS 标记，但与回测分析的需求一致。

#### Strategy 1C：Savitzky-Golay mode='nearest'

**效果评级**：2/5 | **工作量**：Low | **文件**：`filter_engine.py:154`

**问题**：`savgol_filter` 的默认边界处理模式对窗口边界变化敏感。

**方案**：将边界模式从默认的 `'interp'` 改为 `'nearest'`：

```python
# filter_engine.py:154
filtered = savgol_filter(price_array, window_length=13, 
                          polyorder=4, mode='nearest')
```

**预期效果**：减少窗口边界 ±6 根 K 线的滤波值抖动。

```python
# 当前：alpha 固定，对初始值敏感
mu_v[i] = alpha * v[i] + (1-alpha) * mu_v[i-1]

alpha_i = 1.0 / min(i+1, effective_window)
mu_v[i] = alpha_i * v[i] + (1-alpha_i) * mu_v[i-1]
```

**收益**：EWMA 后期极度稳定，几乎不受尾部添加的影响。

### 6.2 术语表

| 术语 | 英文 | 解释 |
|------|------|------|
| BS 标记 | BS Marker | Buy/Sell 操作点标记，在 K 线图上以箭头标注买卖时机 |
| Schmitt 触发器 | Schmitt Trigger | 一种带迟滞的双阈值比较器，用于将连续信号转换为离散的买卖状态。具有上阈值（买入触发）和下阈值（卖出触发），避免信号在阈值附近频繁振荡 |
| EWMA | Exponentially Weighted Moving Average | 指数加权移动平均，越近的数据权重越大，通过衰减因子 α 控制 |
| 持仓掩码 | Holding Mask | 布尔数组，标记每根 K 线是否处于持仓状态。BS 标记的展示需要经过 mask 过滤 |
| cutoff_date | Cutoff Date | 回测截断日期，系统假装"现在"是这个日期，只展示该日期之前的数据和信号 |
| 非因果滤波器 | Non-causal Filter | 输出在时刻 t 依赖于 t 之后输入数据的滤波器。零相位滤波器（如 `filtfilt`）通过前向-反向两次滤波消除相位滞后 |
| 相位滞后 | Phase Lag | 因果滤波器输出信号相对于输入信号的延迟。对于交易，意味着买卖信号滞后于价格转折点 |
| 前视偏差 | Look-ahead Bias | 回测中使用未来数据导致的偏差。非因果滤波器在滑动窗口中隐式引入了前视偏差 |
| 零相位滤波 | Zero-phase Filtering | 通过前向+反向两次滤波使整体相位响应为零，信号峰值与原始数据峰值精确对齐 |
| PnL | Profit and Loss | 盈亏计算。基于 Schmitt 信号生成的模拟交易记录计算收益 |
| 多时间框架 | Multi-TF | 同时使用多个时间框架（如日线+周线）的配置，高 TF 信号影响低 TF 的持仓判断 |
| Savitzky-Golay | Savitzky-Golay Filter | 基于局部多项式拟合的平滑滤波器，在保持信号形状方面优于简单移动平均 |
| 快照模式 | Snapshot Mode | 一次计算全部历史数据，之后仅通过索引截取来模拟回测推进，消除重算不稳定 |
| 迟滞 | Hysteresis | Schmitt 触发器的核心特性：状态转换的阈值取决于当前状态，使得状态翻转需要信号足够显著地穿过阈值 |
