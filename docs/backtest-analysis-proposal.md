# 回测分析方案

## 1. 行业标准 vs 本系统

### 1.1 量化回测分析的标准框架

行业主流平台（QuantConnect、Backtrader/QuantStats、VeighNa、Zipline/Pyfolio、Pineify）的回测分析可归纳为四个维度：

| 维度 | 核心指标 | 典型可视化 |
|------|---------|-----------|
| **收益** | 总收益率、年化收益率(CAGR)、超额收益(Alpha)、日均收益 | 净值曲线、月度热力图、收益分布直方图 |
| **风险** | 最大回撤、夏普比率、索提诺比率、波动率、VaR/CVaR | 回撤曲线(Underwater Plot)、滚动风险指标 |
| **交易** | 胜率、盈亏比、利润因子、平均持仓时间、换手率 | MFE/MAE散点图、交易明细表 |
| **信号** | IC均值/IR、IC衰减、信号频率、RRE、PFS | 因子收益分层、分位数组合曲线 |

参数稳健性方面，行业共识为：**Walk-Forward Analysis 是黄金标准**，辅以参数敏感性热力图、蒙特卡洛模拟和 Purged 交叉验证(CPCV)。核心理念：平台优于尖峰、OOS绩效是唯一真正重要的、一致性大于幅度。

### 1.2 本系统的特殊之处

本系统与标准量化回测系统有**本质差异**，不能简单套用行业模板：

**系统结构差异：**

| 特性 | 标准回测系统 | 本系统 |
|------|------------|--------|
| 处理对象 | 完整交易序列（入场→持仓→出场） | 多TF滤波+Schmitt触发器+BS标记的**信号管道** |
| 时间尺度 | 日线/分钟线，覆盖数月到数年 | 当前仅44 bar（5分钟线，~43分钟） |
| 核心机制 | 订单撮合+资金管理 | **非线性阈值效应**（Schmitt触发器级联放大） |
| 输出产物 | 净值曲线、交易记录 | CSV(55列管道指标) + events.jsonl(事件溯源差分) |
| 参数空间 | 策略参数（均线周期、止损比例等） | 信号参数(k_eps, ewma_span, sigma_min) |

**核心问题不在收益率，而在信号稳定性。** 系统已发现645x级联放大现象——filter尾部0.000342的微小变化经过梯度→EWMA→Schmitt阈值→pairs→trades→BS逐级放大，最终导致BS标记新增或消失。这是**非线性相变**，不是乘法放大：eps的微小变化恰好跨越了Schmitt触发器的阈值边界。

当前数据揭示的三个关键事实：
1. **跨视图sig一致性 = 0%**：日线做多时5分钟做空，多TF信号天然发散
2. **v0(日线)44 bar内翻转26次**，而v3(5分钟)仅翻转1次——信号频率跨TF差异巨大
3. **44 bar窗口内无完整交易周期**，无法计算胜率、盈亏比等交易指标

### 1.3 适用 vs 不适用的方法

| 行业方法 | 适用? | 理由 |
|---------|------|------|
| 净值曲线(Equity Curve) | 不适用 | 44 bar内无完整交易，且系统输出的是BS标记而非持仓，净值无意义 |
| 最大回撤(Max Drawdown) | 不适用 | 同上，无净值则无回撤 |
| 夏普比率(Sharpe Ratio) | 不适用 | 无收益率序列，无法计算 |
| 胜率/盈亏比/利润因子 | 不适用 | 44 bar窗口交易记录不足以支撑统计 |
| 月度收益热力图 | 不适用 | 窗口仅43分钟，无月度概念 |
| 蒙特卡洛模拟 | 不适用(当前) | 数据量不足(需至少数百笔交易)，待数据积累后可用 |
| Walk-Forward Analysis | 不适用(当前) | 需要数百bar以上的IS/OOS窗口分割，44 bar不够 |
| **信号稳定性分析(IC/IR/RRE)** | **部分适用** | IC体系依赖收益率序列，不直接适用；但RRE的时间一致性思想和PFS的扰动稳定性思想可借鉴 |
| **跨TF信号一致性分析** | **完全适用** | 直接对应"日线做多+5分钟做空"的核心困惑 |
| **参数敏感性热力图** | **完全适用** | 行业最佳实践，直接对应k_eps×ewma_span网格扫描 |
| **信号持续期分布分析** | **完全适用** | sig_dur可直接统计 |
| **阈值边界检测** | **完全适用** | 核心需求——\|a\|-eps的margin分析 |
| **滚动窗口指标** | 部分适用 | 需要更长数据，但方法论可迁移到bar级滚动统计 |
| **事件溯源差分分析** | **完全适用** | 本系统独有设计，events.jsonl即为此目的 |
| **级联追溯** | **完全适用** | 直接对应645x放大链路的逐级确认 |

**关键判断**：本系统是一个**信号管道诊断问题**，不是投资组合绩效评估问题。强行套用净值曲线/夏普比率等行业标配只会产出无意义的数字。分析方案应围绕"管道在什么条件下不稳定"展开。

## 2. 分析维度设计

按"用户想知道什么"组织，而非"系统能输出什么"。

### 维度一：BS 稳定性（P0 -- 核心问题）

**用户想知道：** BS标记在回测中是否会跳？在哪个bar跳？为什么跳？跳了之后会恢复吗？

#### 2.1.1 分析指标

| 指标 | 计算方法 | 解读 |
|------|---------|------|
| **BS翻转变动率** | `(bs_entry_count.diff() != 0).sum() / len(df)` | 越接近0越稳定。>0.1=每个bar都可能变 |
| **BS持久性** | bs_entry_count连续不变的最大bar数 | 稳定窗口长度。短窗口=BS频繁变动 |
| **eps边缘距离** | `\|a\| - eps` 在当前sig状态下 | 接近0=信号处于临界态，BS易跳 |
| **临界bar比例** | `sum(\|a\|_i - eps_i < 0.1 × eps_i) / N` | 临界bar占比越高，系统越不稳定 |
| **级联放大倍数** | 从事件溯源链计算 ΔBS / Δfilter_tail | 理论上限≈200。实测645x说明非线性跳变 |
| **BS变动事件密度** | (bs_added + bs_removed) / 总bar数 | Event Sourcing下的直接度量 |
| **BS恢复率** | (变动后1-3 bar内恢复原值的次数) / 总变动次数 | 区分暂时抖动 vs 结构性变化 |

#### 2.1.2 可视化设计

**图表A：BS演化甘特图**

```
每行 = 一个视图(v0~v3)
每列 = 一个bar(按时间排列)
颜色 = BS entry label(B=绿色, S=红色, 无=白色)
叠加标记 = BS变动事件(变动bar处用△标注)
```

目的：一眼看出BS在哪些bar发生变动，变动是局部的还是跨视图传播的。

**图表B：eps临界状态时序图**

```
双Y轴：
  上轴 = a(加速度)时序线 + eps带(±eps半透明填充)
  下轴 = sig状态(-1/0/+1颜色分区)
标注：|a| - eps < 阈值的bar用竖虚线高亮
```

目的：直观展示eps和a的位置关系，精确定位信号何时跨越阈值。

**图表C：级联放大瀑布图**

```
横轴 = 级联层级(filter → v → sigma_v → eps → sig → pairs → trades → BS)
纵轴 = 变化量(对数尺度)
每个变动事件一条折线，展示各级的变化幅度和放大倍数
```

目的：可视化645x放大链路的全貌，确认哪些层级是主要放大器。

**图表D：BS变动事件时间线**

```
横轴 = 时间(bar index)
标记点 = BS变动事件(红色=新增, 蓝色=移除, 大小=变动幅度)
下方叠加 = eps边缘距离线图
```

目的：将BS变动事件与eps临界状态在时间轴上对齐，验证因果关系。

#### 2.1.3 分析流程

```
1. 解析 events.jsonl → 提取所有 BS 变动事件(added/removed)
2. 对每个变动事件，追溯级联链路:
   a. BS变动 ← 哪个trade变动?
   b. trade变动 ← 哪个pair分裂/合并?
   c. pair变动 ← 哪个sig翻转?
   d. sig翻转 ← |a|-eps 是否接近0?
   e. 若 |a|-eps < 阈值 → 标记为"临界触发"
   f. 若 |a|-eps > 阈值 → 标记为"异常"(需进一步分析)
3. 统计:
   - 临界触发占比(预期 > 80%)
   - 各TF的独立变动 vs 联动变动比例
   - BS变动后恢复率
4. 输出诊断结论:
   - 系统是否处于临界边缘?
   - 变动是可预期的(eps边界正常翻转)还是意外的?
```

### 维度二：信号质量（P1）

**用户想知道：** Schmitt信号是否可靠？多TF信号为什么不一致？短持续期的信号是噪声吗？

#### 2.2.1 分析指标

| 指标 | 计算方法 | 解读 |
|------|---------|------|
| **sig翻转频率** | sig状态变化次数 / 总bar数 | 高频翻转=信号不稳定。v0实测26/44=59% |
| **sig持续期分布** | 统计sig_dur的分布(1,2,3,5,10+) | dur≤2的信号占比高=噪声多 |
| **状态转移矩阵** | 统计sig(-1→0→+1)的转移概率 | 是否存在偏好路径(如-1→0比0→+1更频繁) |
| **跨TF sig相关性** | 每对视图间sig一致的bar占比 | v0-v3实测0%，确认多TF发散程度 |
| **eps深度分组统计** | 将bar按\|a\|/eps分为边缘组(<1.2)/中间组(1.2~3)/深处组(>3) | 边缘组sig翻转率预期显著更高 |
| **sig_dur与后续价格关系** | dur≤2的信号出现后，接下来N个bar的价格方向 | 验证短dur信号是否为假信号 |

#### 2.2.2 可视化设计

**图表E：sig状态分布堆叠图**

```
横轴 = 时间(bar index)
纵轴 = 堆叠面积(蓝色=+1, 灰色=0, 红色=-1)
多面板 = v0/v1/v2/v3 各一个子图，垂直对齐
```

目的：跨视图直接对比sig状态，一眼看出多TF分歧的时间点和模式。

**图表F：跨TF热力图**

```
矩阵形式：行=v0~v3, 列=v0~v3
单元格颜色 = 两个视图间sig一致的bar数/总bar数
对角线=1.0(自相关)
下方三角 = 实际数据填充
```

目的：量化多TF间的一致程度，发现哪些TF对更相关(如v1和v2可能相关度高于v0和v3)。

**图表G：sig_dur分布直方图 + 累积曲线**

```
双面板：
  上 = dur直方图(分TF着色)
  下 = 累积占比曲线
标注 = dur=2的占比线(预期v0高、v3低)
```

目的：展示信号持续期分布，识别哪个TF的信号最"碎"。

**图表H：\|a\|-eps 散点图（带sig状态着色）**

```
横轴 = 时间
纵轴 = |a| - eps
颜色 = sig状态(+1绿/0灰/-1红)
水平参考线 = y=0(阈值边界) + y=±0.1×eps(临界区)
```

目的：展示信号安全边距的时序演化，边缘信号一目了然。

#### 2.2.3 分析流程

```
1. 计算跨TF sig相关性矩阵(4×4)
2. 统计每个TF的sig_dur分布
3. 按 |a|-eps 将bar分为边缘/中间/深处三组
4. 统计每组的 sig翻转率 = 该组中sig变化的bar数/该组总bar数
5. 预期: 边缘组翻转率 >> 深处组
6. 若 dur≤2 的信号占比 > 40% → 建议过滤短dur信号的策略
7. 分析多TF分歧模式:
   - 是否存在"上级TF领先、下级TF滞后"的规律?
   - 分歧时哪个TF的信号更"稳定"(sig_dur更长)?
```

### 维度三：参数稳健性（P2）

**用户想知道：** 当前参数(k_eps=0.15, ewma_span=60, sigma_min=0.05)是否最优？改变参数会怎样？是否存在"稳定区间"？

#### 2.3.1 分析指标

| 指标 | 计算方法 | 解读 |
|------|---------|------|
| **BS变动次数** | 每个参数组合下，events.jsonl中BS变动事件总数 | 越低越稳定 |
| **BS变动敏感度** | `Δ(BS变动次数) / Δ(参数)` | 在当前位置的偏导数，大=参数敏感 |
| **sig翻转次数** | 每个参数组合下sig状态变化总次数 | 衡量信号稳定性 |
| **稳定域面积** | BS变动次数不变的最大连续参数区域 | 大=稳健，小=处于悬崖边缘 |
| **eps均值** | 每个参数组合下eps的平均值 | 参数如何影响死区宽度 |

#### 2.3.2 可视化设计

**图表I：k_eps x ewma_span 热力图**

```
横轴 = k_eps [0.05, 0.10, 0.15, 0.20, 0.25, 0.30]  (6档)
纵轴 = ewma_span [20, 40, 60, 80, 120]               (5档)
颜色 = BS变动次数(蓝=少=稳定, 红=多=不稳定)
标注 @ = 当前参数位置(k_eps=0.15, ewma_span=60)
```

目的：一眼看出当前参数是否处于稳定域，以及向哪个方向调整会更稳定。

**图表J：参数-响应曲线**

```
4条曲线(每个TF一条):
  X轴 = k_eps (固定ewma_span=60)
  Y轴 = sig翻转次数
  标注 = 当前k_eps=0.15处的切线斜率(敏感度)
```

目的：展示系统对单个参数的敏感度，识别"悬崖"(曲线陡峭处)。

#### 2.3.3 分析流程

```
1. 定义参数网格:
   k_eps    ∈ [0.05, 0.10, 0.15, 0.20, 0.25, 0.30]
   ewma_span ∈ [20, 40, 60, 80, 120]
   sigma_min 固定为 0.05 (或添加到网格)
   总计 6×5 = 30 组参数组合

2. 对每组参数运行回测，采集 events.jsonl
3. 提取 BS变动事件总数 和 sig翻转次数
4. 绘制热力图 + 标注当前位置
5. 判断:
   - 当前位置是否在"平台"区域(周围BS变动次数相近)?
   - 是否存在某个方向BS变动次数显著降低?
   - 稳定域是否足够大(>3×3=9个组合BS不变)?
```

### 维度四：市场环境适应性（P3）

**用户想知道：** 不同市场条件下BS行为是否一致？高波动时BS更容易跳吗？

#### 2.4.1 分析指标

| 指标 | 计算方法 | 解读 |
|------|---------|------|
| **波动率-BS变动相关性** | 按ATR分位数分组，组内BS变动率 | 正相关=高波动→BS不稳定 |
| **趋势强度-BS变动相关性** | 按ADX分位数分组 | 趋势市 vs 震荡市的BS行为差异 |
| **成交量异常-BS变动关系** | 成交量>均值+2σ的bar上BS变动率 | 异常成交量是否触发BS跳变 |
| **价格跳空-BS变动关系** | 开盘价与前一bar收盘价差值大的bar | 跳空是否导致filter尾部变化→级联放大 |

#### 2.4.2 可视化设计

**图表K：波动率 vs BS变动率散点图**

```
横轴 = 滚动波动率(如5-bar ATR/close)
纵轴 = BS变动率(该bar及后N bar的BS变动事件密度)
每个点 = 一个bar
颜色 = TF(v0~v3)
趋势线 = LOWESS平滑
```

目的：检验"高波动→BS不稳定"的直觉假设。

**图表L：环境分组对照表**

```
表格形式：
  行 = 环境类型(高波动/低波动 × 趋势/震荡 = 四象限)
  列 = 指标(BS变动率, sig翻转率, eps均值, 临界bar比例)
  颜色编码 = 与全局均值的偏差(红=差于均值, 绿=好于均值)
```

目的：快速对比不同市场环境下的系统行为。

#### 2.4.3 分析流程

```
1. 计算每个bar的市场环境指标(ATR, ADX, 成交量Z-score)
2. 按分位数将bar分组(如低波动=ATR<33%分位, 高波动=ATR>67%分位)
3. 对每组统计BS变动率/sig翻转率/eps边缘距离
4. 做分组间差异显著性检验(若数据量够)
5. 注意: 44 bar数据量太小，分组后每组可能只有10-15 bar
   → 此维度在当前阶段以探索性分析为主，不做统计推断
```

### 3.2 多回测对比报告

用于跨ticker/跨参数对比：

```
┌─────────────────────────────────────────────────────┐
│ 多回测对比报告                                        │
├─────────────────────────────────────────────────────┤
│                                                       │
```

## 5. 与之前HTML工具的对比

如果之前存在基于行业模板的HTML回测报告工具，本次方案的改进点：

| 维度 | 之前(推测) | 本次方案 | 改进理由 |
|------|-----------|---------|---------|
| **分析焦点** | 堆砌行业指标（净值、夏普、回撤） | 聚焦核心问题（BS稳定性=信号管道诊断） | 行业指标在本系统无意义——无净值无交易序列 |
| **数据适配** | 假设有完整交易记录和收益率序列 | 基于实际数据形态设计（55列管道指标+events.jsonl） | 44 bar窗口、多TF、无完整交易=必须重新设计分析维度 |
| **可视化设计** | 净值曲线、回撤图、月度热力图等标准图表 | BS甘特图、eps临界图、级联瀑布图等定制诊断图表 | 标准图表无法回答"BS为什么跳"这种管道诊断问题 |
| **参数分析** | 以夏普比率为优化目标的参数扫描 | 以BS变动次数为目标的参数稳定性分析 | 目标函数从"收益最大化"变为"信号最稳定" |
| **报告结构** | KPI仪表盘 → 净值图 → 回撤图 → 热力图 | 诊断仪表盘 → BS演化图 → 级联追溯 → 诊断结论 | 从"绩效展示"变为"问题诊断" |
| **可操作性** | "夏普比率1.2"→无法指导参数调整 | "k_eps从0.15增至0.20可降低BS变动率40%"→直接可执行 | 诊断结论必须指向具体行动 |
| **理论框架** | 均值-方差框架（Markowitz） | 非线性阈值系统稳定性分析 | 本系统不是投资组合，是信号处理管道 |

**核心差异：** 之前的工具试图用"投资组合绩效评估"的框架套"信号管道诊断"的问题，导致产出无意义的数字和图表。本次方案从系统本质出发——非线性阈值系统的级联放大是核心机制，BS稳定性是核心问题——设计了一套完全适配的分析框架。
