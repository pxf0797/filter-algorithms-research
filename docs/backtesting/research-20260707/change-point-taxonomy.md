# 变化点全量分类与交易价值评估

> **分析日期**: 2026-07-07
> **输入报告**: T1 (filter-engine-analysis), T4 (root-cause-analysis)
> **分析目标**: 系统分类所有变化点类型，评估每类的稳定性和交易价值

---

## 背景：变化点的来源

本系统中的"变化点"并非直接来自原始价格，而是经过一条严格串行的处理链逐级产生：

```
价格序列 → 滤波(filtered) → 速度 v → 加速度 a → 波动率 sigma_v
    → 自适应阈值 eps → 施密特信号 sig → 配对段 pairs → 拟合预测 → PnL
```

任何上游环节的变化都会级联到下游。变化点的"稳定"程度取决于它在链中的位置和所用滤波器类型。核心不稳定源（引用自 T4）：

- **滤波器端点效应**: Butterworth 全局重算; Savitzky-Golay 尾端 ~10 点变化; SMA/EMA 仅尾端 1-2 点变化
- **EWMA sigma_v 递归放大**: 位置 K 的 v 变化 → sigma_v[K:] 全部变化 (span=60 时最多影响 60+ 个 bar)
- **Schmitt 状态机 Cascade**: 一个 bar 的 sig 翻转 → 后续所有 sig 从新状态重新递推
- **关键事实**: 已离开滤波边界效应区的历史 bar，其值已锁定不再变化；靠近窗口右边缘的 bar 是动态不稳定的

## Part 1: 五层变化点体系

### Layer A: 触发层（最早、最不稳定）

触发层位于处理链的最上游，直接基于 v、a、eps 的数值比较。这些点**最早感知市场状态变化**，但也因为距离滤波边界效应最近而**最不稳定**。

#### A1. a 穿越 +eps — 潜在做多触发

- **定义**: 加速度 a[i] 从下方突破自适应上阈值 +eps[i]
- **数据依赖**: a 依赖 v 依赖 filtered；eps 依赖 sigma_v (EWMA 全局递归)
- **稳定性**: 低。T4 量化：SMA 滤波下尾部 1-2 bar 的 a/eps 每帧变化；Butterworth 下全局变化。a 是二阶导数，对 filtered 的微小变化有放大效应
- **信号意义**: 价格不仅在涨(v>0)，而且涨速在加快(a>+eps)——趋势加速阶段

#### A2. a 穿越 -eps — 潜在做空触发

- **定义**: 加速度 a[i] 从上方跌破自适应下阈值 -eps[i]
- **数据依赖**: 同 A1，对称条件
- **稳定性**: 低，同 A1
- **信号意义**: 跌速在加快——趋势加速下跌

#### A3. v 穿越 0 — 趋势方向转折早期信号

- **定义**: 速度 v[i]（filtered 的一阶导数）从正变负或从负变正
- **数据依赖**: v = gradient(filtered)，依赖 filtered 的邻域值
- **稳定性**: 中等。v 是一阶导数，比 a 稳定一个量级。尾部 1-2 bar 的 v 因梯度边界退化而变化
- **信号意义**: 滤波价格的运行方向正在改变——这是最早的方向信号，但可能只是短暂回调而非趋势反转

#### A4. sigma_v 突变 — 市场状态变化

- **定义**: EWMA 波动率 sigma_v 出现显著放大或缩小
- **数据依赖**: sigma_v[i] 递归依赖 v[0..i] 全部历史（EWMA 指数衰减）
- **稳定性**: 低（在变化传播意义上）。T4 指出 sigma_v 是"放大器"——1 个 bar 的 v 变化 → 60+ 个 bar 的 sigma_v 变化。但 sigma_v 本身的值变化相对平滑（EWMA 低通特性）
- **信号意义**: 波动率突然放大 = 市场进入高不确定状态（可能趋势启动或恐慌）；波动率缩小 = 市场进入盘整

### Layer B: 信号层（Schmitt 输出）

信号层是 Schmitt 触发器状态机的输出，比触发层多了一层**滞回确认**，因而不容易因噪声翻转。但状态机的 Cascade 特性使其**对上游 eps/a/v 的变化有后向放大效应**。

#### B1. Sig: 0 → +1 — 做多信号产生

- **产生条件** (T1 1.4): a > +eps **且** v > 0，且当前状态为 0
- **方向确认**: 需要 v > 0 的额外条件（防止假突破）
- **稳定性**: 中高（远离边界时）。Schmitt 滞回提供了"死区"——信号一旦产生，需要 a < -eps 才会退出，而非简单的 a < +eps。但如果上游 eps 因滤波边界效应变化，sig 仍可能翻转
- **交易含义**: 趋势加速上涨得到确认，可考虑做多入场

#### B2. Sig: +1 → 0 — 做多信号消失（平多）

- **退出条件**: a < -eps（仅需加速度反向突破，**不需要 v 确认**）
- **设计意图**: 快速离场——加速度反向是趋势衰竭的前兆，不需要等速度也反转
- **稳定性**: 中等。退出条件比进入宽松（不对称设计），意味着 sig 更容易从 +1 退回 0，但也更容易被噪声触发退出
- **交易含义**: 多头动能衰竭，应考虑平多或减仓

#### B3. Sig: 0 → -1 — 做空信号产生

- **产生条件**: a < -eps **且** v < 0，且当前状态为 0
- **稳定性**: 同 B1，对称
- **交易含义**: 趋势加速下跌确认，可考虑做空入场

#### B4. Sig: -1 → 0 — 做空信号消失（平空）

- **退出条件**: a > +eps（仅需加速度反向突破，**不需要 v 确认**）
- **稳定性**: 同 B2，对称
- **交易含义**: 空头动能衰竭，应考虑平空

#### B5. Sig 持续时间变化 — 信号持久性异常

- **定义**: 当前 sig 非零段的持续时间相比历史均值显著偏长或偏短
- **稳定性**: 低（派生指标）。持续时间取决于 sig 的起止边界，而边界本身随窗口滑动而移动
- **交易含义**: 持续时间异常长 = 强趋势（顺势加仓）；异常短 = 假信号或趋势快速衰竭

### Layer C: 滤波层（价格形态）

滤波层直接基于 filtered 价格序列的几何特征，与 sig 信号机**正交**——不依赖 Schmitt 触发器，但同样受滤波边界效应影响。

#### C1. filtered 局部峰值 — 潜在趋势顶

- **定义**: filtered[i] 在局部窗口内为最大值
- **确认条件**: 需要看到右侧至少 1-2 bar 的价格回落才能确认峰值（天然滞后）
- **稳定性**: 中高（SMA/EMA 下，远离边界时）。峰值位置一旦离开边界效应区即锁定
- **交易含义**: 传统的阻力位，可与 sig 信号配合确认离场时机

#### C2. filtered 局部谷值 — 潜在趋势底

- **定义**: filtered[i] 在局部窗口内为最小值
- **稳定性**: 同 C1
- **交易含义**: 传统的支撑位

#### C3. filtered 与 noisy 交叉 — 滤波线穿过原始价格

- **定义**: filtered 序列与 noisy（原始收盘价）序列发生交叉
- **方向**: 上穿（金叉，价格突破滤波线向上）或下穿（死叉，价格跌破滤波线向下）
- **稳定性**: 中等。交叉位置随 filtered 边界效应而微调，但交叉"是否发生"相对稳定
- **交易含义**: 经典的趋势跟踪信号。金叉 = 短期价格强于滤波趋势，可能加速上行；死叉 = 反之

#### C4. filtered 斜率突变 — 滤波线的二阶导数突变

- **定义**: filtered 序列的二阶差分（或对 filtered 再取 gradient）出现显著变化
- **实质**: 与 a（加速度）高度相关但不完全相同——a = gradient(gradient(filtered))，而 filtered 斜率突变是对 filtered 直接取二阶差分
- **稳定性**: 低。二阶变化对 filtered 的微小扰动极为敏感
- **交易含义**: 趋势的加速/减速拐点——可用于判断趋势是否进入"冲刺"或"衰竭"阶段

---

### Layer D: 配对层（交易结构）

配对层来自 `_find_all_pairs(sig)` 的输出，将 sig 序列转化为可供交易的结构化片段。这是**离实际交易最近的层**，但也是上游变化的最终汇聚点。

#### D1. pair_start — 配对段开始（趋势确认）

- **定义**: 同方向非零 sig 段的第一个 bar index。例如 sig = [0,0,1,1,1,0] → pair_start = 2
- **合并逻辑** (T1 2.1 Step 2): 相邻同号非零段被合并，中间的 0 被视为"同方向延续"而非离场
- **交易含义**: 信号从观望(0)进入定向(+1/-1)且持续——比单个 sig 翻转更可靠的趋势确认
- **稳定性**: 中等。依赖 sig 序列的起止位置，但合并逻辑增加了一定的鲁棒性（中间短暂 0 不会破坏配对）

#### D2. pair_end — 配对段结束（趋势终结）

- **定义**: 相反信号的第一个 index（不是原信号的最后一个 index）。例如 sig=[1,1,1,0,-1,-1]，pair_end=4（空头信号出现的位置）
- **关键语义** (T1 2.2): pair_end = s2（下一个异号段的起点），而非 e1（当前段的终点）。意味着配对结束的判定是"对手出现"而非"自己消失"
- **交易含义**: 趋势被反向信号确认终结——是较强的离场信号
- **稳定性**: 低（靠近边界时）。pair_end 的确认需要看到反向 sig 出现，在右边界附近反向 sig 本身可能不稳定

#### D3. pred_up 翻转 — 预测方向改变

- **定义**: 对 pair 范围做抛物线拟合后，延伸 n_extend 个 bar，判断预测曲线是上翘(pred_up=True)还是下弯(pred_up=False)。翻转 = pred_up 从 True 变 False 或反之
- **数据依赖** (T1 3.3): pred_up = y_pred[-1] > y_pred[0]，其中 y_pred 是拟合多项式在 [pair_end, pair_end+n_extend] 上的值
- **交易含义**: 决定实际开仓方向。即使 sig=+1，如果 pred_up=False（预测曲线下弯），也不会开多仓（信号和预测矛盾）
- **稳定性**: 低。pair 范围变化 → 拟合数据点变化 → 参数(a,b,c)变化 → pred_up 可能翻转。T4 指出："方向翻转率取决于边界附近信号密度"

---

### Layer E: 跨周期层

跨周期层处理不同时间周期的变化点之间的关系。高周期的变化点对低周期有"方向性约束"作用。

#### E1. 高周期 Sig 翻转 — 对低周期的方向性冲击

- **定义**: 日线（或周线）的 sig 发生 0→±1 或 ±1→0 翻转
- **影响机制** (T1 5): 高周期 sig 通过 `_align_pnl_to_current_tf` 对齐到低周期时间轴，再通过 `_compute_holding_masks` 生成持仓遮罩，用于判断"同向性"
- **稳定性**: 中高。高周期本身 bar 数量少、每个 bar 信息量大，sig 翻转更慎重。但 T4 指出周线受级联合成中"不完整 K 线"影响
- **交易含义**: 周线做多 + 日线做多 = 同向共振，是最强信号；周线做多 + 日线做空 = 背离，需要谨慎

#### E2. 不同周期变化点的时间差 — 领先-滞后关系

- **定义**: 日线 sig 翻转后，经过多长时间（以低周期 bar 数计）60 分钟线 sig 才翻转
- **交易含义**: 如果日线翻转后 60 分钟线迅速跟随 → 趋势共识强；如果日线翻转后 60 分钟线迟迟不跟随 → 高周期信号可能为假
- **稳定性**: 低（派生指标）。两个周期的 sig 各自受滤波边界效应影响，时间差的变化是两个不稳定源的叠加

## Part 2: 稳定性-时效性矩阵

### 评分标准

| 维度 | 1分 | 2分 | 3分 | 4分 | 5分 |
|------|-----|-----|-----|-----|-----|
| **历史稳定性** | 每帧必变 (Butterworth级) | 高频变化 (>50%概率) | 中等 (10-50%) | 较稳定 (5-10%) | 几乎不变 (<5%) |
| **实时性(延迟)** | 滞后 >10 bar | 滞后 5-10 bar | 滞后 2-5 bar | 滞后 1-2 bar | 几乎实时 (0-1 bar) |

### 评分解释

**历史稳定性**（核心维度，权重最高）:
- Layer A 得 2-3 分：处于处理链上游，直接承受滤波边界效应的冲击。T4 量化：SMA 下尾部信号翻转概率 ~5-10%，Savitzky-Golay 下 ~30-50%，Butterworth 下 ~95%
- Layer B 得 3 分：Schmitt 滞回提供了缓冲，但状态机 Cascade 意味着上游 eps 变化仍会传播。远离边界区的历史 bar 的 sig 可视为锁定
- Layer C 得 2-4 分：filtered 极值最稳定（特别是 SMA/EMA 下）；斜率突变最不稳定（二阶变化）
- Layer D 得 2-3 分：pair 边界是 sig 的衍生，叠加了合并逻辑的不确定性
- Layer E 得 3-4 分：高周期天然更稳定，但跨周期时间差是两个不稳定源的叠加

**实时性**（延迟）:
- Layer A 得分最高（4-5）：触发层是最早的信号，几乎没有延迟
- Layer D 的 pair_end 得分最低（1）：需要等待反向信号出现才能确认趋势终结，滞后显著
- Layer E 的高周期 Sig 得分低（1）：周线/月线信号更新频率极低

**预测能力**:
- Layer B 的 Sig 0→±1 得分高（4）：滞回确认 + 方向条件（v>0 或 v<0）筛选，过滤了大量假突破
- Layer D 的 pair_start 得分高（4）：持续的非零 sig 段意味着趋势已确立
- Layer A 的 a穿越eps 得分低（2）：单独的加速度穿越阈值缺乏方向持续性

**抗噪能力**:
- Layer B 的 Sig 0→±1 得分高（4）：滞回机制天然抗噪，dead zone 防止了阈值附近的反复横跳
- Layer A 得分低（2）：没有滞回保护，噪声可直接触发
- Layer D 的 pair_start 得分高（4）：需要 sig 持续非零，单 bar 噪声不会创建配对

**综合分**: 等权平均，四舍五入到 0.25。评级：A >= 3.5, B >= 2.75, C < 2.75

```
   │          稳定性: ★★★☆☆  滞后: 2-5 bar

   ├── t₀+4:  🟢 pair_start                [Layer D: 配对层]
   │          配对段开始。sig 已连续多个 bar 为非零且无反向信号。
   │          合并逻辑将短暂 0 值视为同向延续，增强了连续性。
   │          抛物线拟合开始积累数据点。
   │          稳定性: ★★★☆☆  可靠性: 较 Sig 更可靠 (趋势已确保持续)
   │
   ├── t₀+5:  🔵 filtered 谷值确认          [Layer C: 滤波层]
   │          事后确认：t₀ 附近的 filtered 值确实是局部最低点。
   │          此时距离谷值可能已过了 3-5 bar，但确认可靠性高。
   │          稳定性: ★★★★☆  滞后: 3-5 bar
   │
   ├── t₀+N:  ✅ 离开滤波边界效应区           [锁定]
   │          当该 bar 距离窗口右边界足够远（超过滤波器的端点效应范围），
   │          其所有上游值(filtered/v/a/eps/sig)不再因新数据加入而变化。
   │          N 取决于滤波器: SMA/EMA 需 ~2-5 bar, Savitzky-Golay 需 ~10 bar,
   │          Butterworth 需窗口完全滑过（~120 bar 后）。
   │          此时该 bar 的所有变化点可以"锁定"——写入持久化存储。
   │
   ├── t₀+M:  🔴 高周期 Sig: 0 → +1         [Layer E: 跨周期层]
   │          (M >> N, 例如日线已涨了 5-10 天)
   │          更高时间周期（如日线→周线）的 sig 翻转。
   │          此时低周期的上涨已累积足够动量推动高周期信号。
   │          同向性确认——最强的共振信号。
   │          稳定性: ★★★★☆  滞后: 非常大 (以天/周计)
   │
   └── t₀+K:  📉 Sig: +1 → 0 (平多)        [Layer B: 信号层]
              (K 个 bar 后，上涨趋势结束)
              加速度跌破 -eps，做多信号消失。
              注意离场不需要 v 确认——设计为快速退出。
              随后 pair_end 确认、filtered 峰值确认依次发生。


═══════════════════════════════════════════════════════════════════════════════
                       变化点出现顺序的通用规律
═══════════════════════════════════════════════════════════════════════════════

  早 ─────────────────────────────── 时间 ──────────────────────────────→ 晚

  Layer A (触发)     Layer B (信号)    Layer C (滤波)    Layer D (配对)
  ┌──────────┐      ┌──────────┐     ┌──────────┐      ┌──────────┐
  │ v穿越0   │      │ Sig翻转  │     │ filt极值 │      │ pair边界 │
  │ a穿越eps │  →   │ 0→±1    │ →   │ 交叉确认 │  →   │ 起止确认 │  →  锁定
  │ sigma_v  │      │ ±1→0    │     │ 斜率突变 │      │ pred_up  │
  └──────────┘      └──────────┘     └──────────┘      └──────────┘
   最早/最不稳定      较稳定/可靠      天然滞后           最可靠/最滞后

  关键trade-off：越早的信号越不稳定，越晚的信号越可靠但越滞后。
  最优策略：用早期信号做预警（alert），用后期信号做确认（confirm）。
```

## Part 4: 一句话总结 — 最佳使用场景

### Layer A: 触发层

- **a 穿越 eps**: 适合**趋势启动的早期预警**（配合其他确认信号使用），不适合**单独作为入场依据**——单独的加速度穿越在盘整市中假信号率极高，T4 量化：SMA 下尾部信号翻转概率 ~5-10%，Butterworth 下几乎必变
- **v 穿越 0**: 适合**判断回调是否结束**（在已有趋势中寻找重新入场点），不适合**在无趋势市场中寻找反转**——v 穿越 0 在盘整市中频繁发生但无方向持续性
- **sigma_v 突变**: 适合**仓位管理和风险预警**（波动率放大时减小仓位、缩小止损），不适合**方向性交易决策**——sigma_v 不含方向信息，只含波动幅度信息

### Layer B: 信号层

- **Sig: 0 → ±1**: 适合**趋势跟踪策略的核心入场信号**（滞回确认 + 方向条件 = 假信号过滤），不适合**震荡市的逆势交易**——Sig 的设计本身就是趋势跟踪，在盘整市中会被反复触发和撤销
- **Sig: ±1 → 0**: 适合**趋势跟踪的离场信号**（加速度反向 = 动能衰竭，快速退出），不适合**追求"吃到最后一口"的离场优化**——不对称设计(不需要 v 确认)意味着退出偏早，会牺牲趋势末端的部分利润换取安全性
- **Sig 持续时间异常**: 适合**判断趋势强度并调整持仓周期预期**，不适合**精确的入场/离场择时**——持续时间是事后统计量，只有信号结束后才能准确计算

### Layer C: 滤波层

- **filtered 局部极值**: 适合**支撑/阻力位的客观标记**（SMA/EMA 下历史极值非常稳定，适合长期引用），不适合**实时交易触发**——峰值/谷值确认需要右侧数据，天生滞后 2-5 bar
- **filtered/noisy 交叉**: 适合**作为 Sig 信号的"二次确认"**（两者方向一致时增加信心），不适合**作为唯一入场信号**——交叉的滞后性 + 盘整市的反复穿插意味着单独使用时交易频率过高
- **filtered 斜率突变**: 适合**检测趋势的加速/衰竭拐点**（判断是否需要收紧止损或分批止盈），不适合**在低频策略中作为主信号**——二阶变化过于敏感，需要配合平滑参数使用

### Layer D: 配对层

- **pair_start**: 适合**确认趋势已确立后的顺势入场**（比 Sig 翻转更可靠——需要信号持续非零），不适合**追求"买在最低点"的左侧交易**——pair_start 确认时价格已从底部反弹了一段，必然错过最初的利润
- **pair_end**: 适合**确认趋势终结后的复盘分析**（历史 pair 边界非常清晰），不适合**实时离场决策**——pair_end 需要反向 sig 出现才确认，滞后严重；实时离场应使用 Sig ±1→0 或止损
- **pred_up 翻转**: 适合**在信号矛盾时提供"一票否决"**（sig=+1 但 pred_up=False → 不做多），不适合**作为独立的预测工具**——拟合仅使用 pair 范围内的数据点，外推 n_extend=10 的可靠性有限

### Layer E: 跨周期层

- **高周期 Sig 翻转**: 适合**判断"大方向"以约束低周期交易方向**（周线做多时，日线只做多不做空），不适合**精确择时**——高周期更新频率太低，等你看到周线 sig 翻转时，日线已经走了一大段
- **跨周期时间差**: 适合**评估趋势共识强度**（多周期快速共振 = 强趋势；迟迟不共振 = 犹豫市），不适合**机械式的交易规则**——时间差的分布高度依赖市场状态，不适合设定固定阈值
