# 研究简报

## 1. 核心问题
多周期股票滤波分析工具的回测模式下，不同周期在不同时刻的 Sig（施密特触发信号）和 PnL 结果会动态变化，导致基于这些信号做策略操作时可能存在误操作。需要深入理解回测机制、定位动态变化根因、并设计从简单到复杂的交易策略改进方案。

## 2. 拆解维度
- **回测数据流**：从 DB → parquet → filter → Schmitt trigger → PnL 的完整链路
- **动态变化根因**：为何滑动窗口前进时 Sig/PnL 会变化（滤波边界效应、Schmitt 状态依赖、预测曲线重算）
- **策略改进方向**：信号稳定性、多周期确认、延迟确认机制、从简单到复杂的渐进方案

## 3. 范围边界
- 聚焦于 filter_engine.py、data_loader.py、charts.py 和 streamlit_app.py 的核心逻辑
- 不涉及 UI/UX 改进、不涉及新增滤波算法
- 策略方案以"大方向正确"为优先，不追求即刻可交易的完备系统

## 4. 不确定项
- 用户对"误操作"的具体场景未完全明确（信号闪烁？假突破？不同周期信号冲突？）
- 策略复杂度期望边界未明确（是否要引入 ML？还是纯规则引擎？）
