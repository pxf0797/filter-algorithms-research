# 半边多空对交易策略（v3：C 周期完整离场状态门控）

> 起点即入场，C 的"提前离场"与"反向结束"等价对待，核心仍在离场

---

## 一、核心认知：永远在操作半边多空对

**一句话：** 不管是回测推进还是实时交易，你永远站在窗口最右边缘，当前正在走的那段多空对永远只有起点、没有终点——这就是"半边"，它不是特殊情况，它是唯一现实。

### 1.1 什么是多空对，什么是"半边"

**多空对（Pair）= 一段连续同向的趋势。** 它由三个要素定义：

| 要素 | 含义 | 来源 |
|------|------|------|
| 起点 | 趋势诞生的那一根 K 线（Sig 从 0 变为 ±1） | Schmitt 触发器状态转移 |
| 终点 | 趋势结束、反向趋势诞生的那一根 K 线 | 下一段反向段的起点 |
| 方向 | +1（多）或 -1（空） | 段内 Sig 的符号 |

起点和终点都有的，就是**完整多空对**——一段走完的历史，回看时涨到哪、跌到哪都已确定。当下正在走的这一段不一样：它有起点（趋势已诞生），却**没有终点**（谁也不知道它何时结束）。这种"有头无尾"的多空对，就是**半边多空对**。

```
完整多空对：  起点 ●━━━━━━━● 终点      （历史，已定型）
半边多空对：  起点 ●━━━━━━━▶ ???       （当下，还在走）
```

### 1.2 为什么说"永远"操作半边

**一句话：** 无论回测第几帧、还是实时此刻，最右边那个多空对永远是半边——因为"当下"这个位置，天然就是趋势还没走完的地方。

```
    过去 ◀─────────────────────────  现在
    │完整│完整│完整│完整│  半边 ▶ (你在这里)
     已定型 已定型 已定型 已定型   还在走
```

回测每前进一根 K 线，边缘右移一格，但"最右边那段是半边"这个事实从不改变。今天的半边明天可能走完、变成完整多空对被甩到左边，那时又会有**新的**半边出现在最右边。所以：**你操作的对象，永远、且只能是这个半边多空对。**

### 1.3 策略骨架（v3）

**一句话：** 半边的起点一出现就入场（靠 C 周期同向背书，不等锁定），入场之后唯一要做的事就是判断怎么离场——离场是全部难点。

```
        永远操作半边多空对
                │
       ┌────────┴────────┐
       ▼                 ▼
   起点出现即入场        怎么离场
   （C同向背书）        = 核心
                       （三种机制 + C状态梯度响应）
```

v3 承接 v2 的两个升级（起点即入场、看 C 多空对状态而非 C.Sig），只补一个洞：

**v3 相对 v2 改了一件事：补上 C "偏离提前离场"这个等价结束状态。** v2 认为 C 的多空对只有一种结束方式——Sig 反向（→ MISALIGN）。但 C 和 B 一样在跑三离场，它的当前半边也会**因偏离过大而提前离场平仓**。这种"提前结束"和"反向结束"对 B 完全等价：**C 背书消失。** v2 把它误当成"仍在场内的 WEAK_ALIGN"，v3 把它升级为独立的第 5 态 **C_ENDED**。

下面：第二章讲入场（沿用 v2），第三章讲 C 五态与 C_ENDED（v3 核心升级），第四、五章讲决策表与离场梯度。

## 二、入场：起点即判定（不等锁定）

**一句话：** B 半边起点一出现（Sig 0→±1）当帧判入场，唯一门槛是 C 多空对状态 = 强同向；入场条件与 v2 不变。

### 2.1 为什么不等锁定

等锁定 = 好几根 K 线过去 = 趋势已走一大段 = 进场太晚意义不大。趋势最值钱的就是起步那一段，等锁定往往错过它。v2/v3 的思路是：**不用时间换确定性，而用空间（C 周期背书）换确定性**——起点一诞生就判，让上级周期的同向趋势替我们过滤假信号。

### 2.2 入场时机与条件

```
入场 IF:
    B 当前半边起点当帧诞生 (pair_start_B == i)      # 时机：0 延迟
    AND C_pair_state(dir_B, i) == STRONG_ALIGN      # 背书：C 强同向（默认）
    [可配置 allow_weak：WEAK_ALIGN 时降级入场/减仓]
```

- **时机**从"锁定后"提前到"起点当帧"，零延迟吃到趋势起步段。
- **门槛**是"C 强同向"（STRONG_ALIGN）。这是入场的唯一钥匙：确定性不来自等待，而来自上级趋势的背书。

**v3 在此处的唯一影响：** 入场门槛依然是"仅 STRONG_ALIGN 才入"，但被拒绝入场的状态从 v2 的 3 种（WEAK/MISALIGN/NO_DIRECTION）扩为 4 种，新增了 **C_ENDED**（见第四章）。

### 2.3 不锁定的风险与双重兜底

不锁定引入了一个新风险：起点可能是边缘区的闪烁噪声，几根 bar 后就消失。这份风险由两层兜底消化：

| 兜底 | 时点 | 机制 |
|------|------|------|
| 兜底① C 强同向确认 | 入场时 | B 单边假信号与"C 已有同向活跃半边"同时出现的概率，远低于 B 单独假信号。C 背书把假起点概率大幅压低。 |
| 兜底② 入场依据消失快速离场 | 入场后 | 若起点在边缘窗口内蒸发，立刻小损离场（`entry_void`），把假起点的伤害限制在几根 bar 内。 |

## 三、同向判断：看 C 的多空对状态 ⭐v3 核心升级

### 3.1 为什么不看 C.Sig 而看多空对状态

**一句话：** Sig 是瞬时值，一根 K 线就翻；多空对状态反映 C 这一整段趋势的健康度。

C.Sig 会在 0 和 ±1 之间抖动，用它判同向会被单帧噪声反复误导。更致命的是它**看不见"C 趋势即将衰竭"这个阶段**——C 的 +1 半边已经降速（Sig 掉回 0）或冒出反向苗头（短暂 -1 但未确认），此时 C 这段趋势正在尾部，B 若此刻入场 = 在 C 趋势末端上车，是最危险的进场。Sig 无法表达"活跃但衰竭中"这个中间层，多空对状态可以。

C 周期不是被动提供一个方向，而是**自己也在操作半边多空对**——它同样有起点、有活跃半边、也跑自己的三离场。B 要判断的是 C 这个多空对**整体处于什么阶段**。

### 3.2 一个物理事实：C 趋势衰竭是渐进的

**一句话：** Schmitt 触发器永不 +1↔-1 直跳，必经 0；所以 C 转向必先降速→到 0→再反向，"C 正在走弱"是可观测的渐进过程，不是突变。

这是整个状态模型的物理地基。`_schmitt_trigger` 的状态机里，`+1→0` 的条件是加速度掉头（`a<-ε`），而建立 `-1` 还要再等 `a<-ε AND v<0`。这个天然的"先降速到 0、再反向"两段式，意味着：

```
C 的 +1 半边由盛转衰的真实路径：
   健康奔跑            降速             反向确认
   Sig=+1  ───────▶  Sig=0  ───────▶  Sig=-1(连续N根)
   STRONG_ALIGN      WEAK_ALIGN        MISALIGN
   （满速）          （尾部衰竭中）    （已翻向）
```

**关键结论：中间态不是硬造出来的，它是触发器里天然存在的物理阶段。** 既然 C 不可能从满速多头瞬间跳成满速空头，"C 正在衰竭"就一定有可观测的物理表现，我们只要把它量化出来即可。

### 3.3 关键升级：C 多空对有两种"结束"方式 ⭐新

**一句话：** C 和 B 一样跑三离场，它的当前半边有两种等价的"结束"——Sig 反向（正常结束）与偏离过大提前离场（提前结束），对 B 都是"背书消失"。

v2 只承认一种 C 结束：Sig 反向确认（dir_C 翻到 -d_B），归为 MISALIGN。但 C 既然自己也在操作半边、也跑同一套三离场，它的当前半边就会因**趋势偏离过大**而**提前平仓离场**——就像 B 的离场②一样。C 走不完整段趋势就被自己的偏离规则踢出场了。

| 结束方式 | 触发离场 | dir_C 是否翻转 | C 仓位 | v2 是否覆盖 |
|---------|---------|--------------|--------|-----------|
| **正常结束** | 离场①：Sig 反向 `reverse_run ≥ N_confirm` | ✅ 翻转到 -d_B | 已平仓 | ✅ → MISALIGN |
| **提前结束** | 离场②：偏离过大 `signed_dev > MAX_DEV_PCT_C` | ❌ 未翻（仍名义同向） | **已平仓** | ❌ **被 v2 漏掉** |

```
      C 半边预测轨道
      pred_val_C ╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌
                 ╱                         ← 若 price 一路贴着轨道跑
   price_C  ●━━━╱━━━━━━━━━━━━━━━━━━━━▶     = C 健康，Sig 反向才结束（MISALIGN）
                ╲
                 ╲╲  price 大幅偏离轨道
                   ╲╲                      ← 偏离 > MAX_DEV_PCT_C
                     ● C 触发离场②、提前平仓  = C_ENDED（dir_C 还没翻，但 C 已出场）
```

**核心洞察：两种结束对 B 完全等价——C 背书消失。** 区别只在结束后 C 站在哪里：

- **MISALIGN：** C **反手站到了 B 对面**（dir_C 翻成 -d_B），是"背书反转"——C 战略级否定 B。
- **C_ENDED：** C **退场观望**（dir_C 仍名义同向、但已平仓），是"背书撤销"——C 既不背书也不反对。

v2 只认第一种，把第二种（离场②已触发、C 已平仓）错塞进了"仍持仓的 WEAK_ALIGN"。这是自相矛盾的：离场②触发就意味着 C 已经平仓离场了，它不可能同时还是"仍在场内的弱同向"。v3 把这个缺口补上。

### 3.4 C 周期多空对的五种状态 ⭐升级（4→5 态）

**一句话：** 在 v2 四态之间插入 C_ENDED，专指"C 名义同向、但已因偏离过大提前离场平仓"。

| 状态 | 精确定义 | C 是否持仓 | 检测条件 | 对 B 入场意义 |
|------|---------|-----------|---------|-------------|
| **STRONG_ALIGN** | dir_C==d_B，健康奔跑 | ✅ 持仓 | 无预警且 `signed_dev ≤ WARN_DEV_PCT_C` | ✅ 入场（满仓） |
| **WEAK_ALIGN** | dir_C==d_B，露出衰竭前兆但离场②未触发 | ✅ **仍持仓** | `0<reverse_run<N_confirm` **或** `WARN_DEV_PCT_C ≤ signed_dev ≤ MAX_DEV_PCT_C` **或** [软]Sig→0 | ⚠️ 降级/减仓/不入 |
| **C_ENDED** ⭐新 | dir_C==d_B（名义同向）但 C 离场②已触发、**已平仓**（多空对提前结束） | ❌ **已平仓** | `signed_dev > MAX_DEV_PCT_C`（已超阈） | ❌ 不入场（背书已撤销） |
| **MISALIGN** | dir_C == -d_B，C 反向结束、已反手 | ❌ 已平仓、已反手 | `reverse_run ≥ N_confirm`（dir_C 已翻） | ❌ 不入场（逆 C 大势） |
| **NO_DIRECTION** | dir_C == 0，C 无活跃非零半边 | ❌ 空仓观望 | 无当前非零合并段 | ❌ 不入场（无背书） |

**只有 STRONG_ALIGN 打开入场。** C_ENDED、MISALIGN、NO_DIRECTION 明确不入；WEAK_ALIGN 是可配灰区。新增的 C_ENDED 恰好**插在 WEAK_ALIGN（未离场）和 MISALIGN（反向离场）之间**，补上"同向离场"这个缺口——C 结束了、但没反手。

### 3.5 关键边界：WEAK_ALIGN（仍持仓预警）vs C_ENDED（已平仓）⭐新重点

**一句话：** 两态都满足 dir_C==d_B（名义同向、Sig 未翻），唯一分界线是 `signed_dev` 有没有越过 C 离场②的阈值 `MAX_DEV_PCT_C`——没越过 = C 还在场内挣扎（WEAK），越过 = C 已触发离场②出场了（C_ENDED）。

这是 v3 最关键的一刀。请看偏离轴上的一条阈值线，两侧物理互斥、绝不重叠：

```
signed_dev（C 当前半边"不利方向"偏离预测轨道的百分比）
       │
  0 ───┼──────────────┬──────────────────────┬───────────────▶ 偏离增大
       │              │                      │
       │  STRONG 区   │   WEAK 预警带         │   C_ENDED 区
       │  健康奔跑     │   接近但未触发离场②    │   离场②已触发、C 已平仓
       │  C 持仓       │   C 仍持仓（挣扎中）   │   C 已出场（多空对提前结束）
       │              │                      │
       └──────────────┴──────────────────────┴───────────────
                 WARN_DEV_PCT_C          MAX_DEV_PCT_C
                 （预警下界）            （离场②触发线 = 唯一分界）
       └── dev ≤ WARN ──┘└─ WARN ≤ dev ≤ MAX ─┘└─ dev > MAX ──┘
```

**一条线两侧，语义天差地别：**

| 维度 | WEAK_ALIGN | C_ENDED ⭐ |
|------|-----------|-----------|
| dir_C | == d_B（同向） | == d_B（名义同向） |
| C 仓位 | **仍持仓** | **已平仓**（离场②触发） |
| 偏离量 | `WARN_DEV_PCT_C ≤ dev ≤ MAX_DEV_PCT_C`（未超阈） | `dev > MAX_DEV_PCT_C`（已超阈） |
| C 多空对 | 未结束（尾部衰竭中） | **已提前结束** |
| 语义 | "C 可能要走弱了" | "C 这段趋势已经断了" |
| 对 B | 尾部风险高，谨慎 | 背书已消失，等同结束 |

**为什么边界严丝合缝、不重叠？** 因为 `MAX_DEV_PCT_C` 是 C 离场②的**触发线**，是一个物理开关：

- `dev ≤ MAX_DEV_PCT_C`：C 离场②**未触发、C 仍持仓** → 顶多是 WEAK 预警。此时 `WARN_DEV_PCT_C` 只是在 MAX 之下再划出一条预警下界（如 `WARN = 0.7×MAX`），让 STRONG 和 WEAK 之间有过渡带。
- `dev > MAX_DEV_PCT_C`：C 离场②**已触发、C 已平仓** → 必然是 C_ENDED。

v2 的错误正是把 `dev > MAX`（离场已触发）也塞进 WEAK（仍持仓），逻辑自相矛盾。v3 用 `MAX_DEV_PCT_C` 这条线把它切开：**未超阈 = WEAK 预警（C 还在场内挣扎）；已超阈 = C_ENDED 离场（C 已经出场了）。**

**WEAK 的两条出口各占一维阈值，互不干涉：**

```
                       偏离维越过 MAX_DEV_PCT_C
        ┌────────────────────────────────────▶  C_ENDED（提前结束，C 未反手）
   WEAK_ALIGN
   （唯一中间态）
        └────────────────────────────────────▶  MISALIGN（反向结束，C 已反手）
                       反转维越过 N_confirm
```

WEAK 是"未结束"的唯一中间态，它有两条终局出口：偏离方向越过 `MAX_DEV_PCT_C` 走向 **C_ENDED**，反转方向越过 `N_confirm` 走向 **MISALIGN**。两个终局各占一维阈值，物理上互斥。

### 3.6 C 状态判定流程（含 C_ENDED 分支）

**一句话：** C_ENDED 是终局态，必须先于 WEAK 检查——因为一旦离场②触发，C 就已经出场，不能再当"仍持仓的预警"。

```
                    ┌─────────────────────┐
                    │  取 dir_C（当前半边） │
                    └──────────┬──────────┘
                               ▼
                     dir_C == 0 ? ──是──▶ NO_DIRECTION
                               │否
                               ▼
                  dir_C == -d_B ? ──是──▶ MISALIGN（反向结束，已反手）
                               │否 (dir_C == d_B，名义同向)
                               ▼
                  signed_dev > MAX_DEV_PCT_C ?
                               │
                    ┌──是──────┴──────否──┐
                    ▼                     ▼
             C_ENDED ⭐            中间态检测（仍持仓）：
          （离场②已触发、          A 反转预警 0<reverse_run<N_confirm
            C 已平仓、提前结束）    B 破位预警 WARN ≤ dev ≤ MAX（未超阈）
                                   C 降速预警 sig_C==0（软，可关）
                                        │
                              任一为真 ? ──是──▶ WEAK_ALIGN（尾部衰竭中）
                                        │否
                                        ▼
                                    STRONG_ALIGN（健康奔跑）
```

关键顺序：**先判 `signed_dev > MAX_DEV_PCT_C`（C_ENDED），再判 WEAK 预警。** 这确保"已离场"永远优先于"仍持仓预警"，两态不会撞车。

## 四、入场决策表（v3，5 态）

**一句话：** B 半边方向（当帧起点）× C 多空对状态（5 态）→ 入场/降级/不入场；相对 v2 新增 C_ENDED 行。

| # | B 起点当帧 | C 多空对状态 | 决策 | 原因 |
|---|-----------|-------------|------|------|
| 1 | 是 | STRONG_ALIGN | ✅ 入场（满仓） | C 同向健康奔跑，最可靠 |
| 2 | 是 | WEAK_ALIGN | ⚠️ 降级：`allow_weak` 开→半仓+紧离场；关→不入 | C 同向但衰竭中，尾部进场高风险 |
| 3 | 是 | **C_ENDED** ⭐新 | ❌ 不入场 | **C 多空对已提前离场，背书已撤销**（等同结束，无背书可依） |
| 4 | 是 | MISALIGN | ❌ 不入场 | C 已反向结束、反手做空，逆大势 |
| 5 | 是 | NO_DIRECTION | ❌ 不入场（默认保守） | C 无背书，B 单边假信号裸奔 |
| 6 | 否（非起点帧） | 任意 | — 不判入场 | 仅起点当帧判入场 |

**与 v2 决策表的差异：** 新增第 3 行 C_ENDED → 不入场。它和 MISALIGN 一样都拒绝入场，但**语义不同**——C_ENDED 是"背书消失"（C 退场观望），MISALIGN 是"背书反转"（C 反手对立）。都不入场，因为入场的前提是"C 有活跃同向半边在背书"，而 C_ENDED 下 C 的同向半边已经提前结束了，哪怕 dir_C 还名义同向，也没有活跃仓位在背书。

## 五、离场：策略的核心（三种机制 + C 状态梯度响应）

**一句话：** 三离场机制不变，v3 把离场③（上级反向）升级为"按 C 生命周期的梯度响应"——越接近结束，B 越保守，但 MISALIGN 和 C_ENDED 强度不同。

### 5.1 三离场机制（保留 v2）

| 机制 | 触发 | 说明 |
|------|------|------|
| 离场① 进入下一多空对 | B 反向段 `reverse_run ≥ N_confirm` | 本级趋势正常反转，止盈离场 |
| 离场② 趋势偏离过大 | B 不利偏离 `> MAX_DEV_PCT_B` | 只看不利方向，破位即走 |
| 离场③ 上级反向（C 状态） | C 状态梯度响应（见 5.2） | v3 升级为梯度，非一刀切 |
| （保留）entry_void | 边缘窗口内 B 起点蒸发 | 不锁定的假起点兜底，快速小损 |
| （保留）预测保护期止损 | 入场初期击穿轨道 | 防错方向 |

### 5.2 离场③升级：C 状态梯度响应 ⭐

**问题：** v2 离场③只有 C=MISALIGN 才触发 B 强退。C_ENDED（C 提前离场、背书消失）是否也该触发？

**分析：** C_ENDED 意味着 C 的背书撤销了，B 靠 C 背书才入场的，背书没了持仓依据被削弱。但 C_ENDED **C 并未反手对立**（dir_C 仍名义同向），B 自己的本级趋势可能仍然有效。因此不宜像 MISALIGN 那样"立即全额强退"，而应"收紧防线、择机减仓"——强度介于 WEAK（轻收紧）和 MISALIGN（强退）之间。

**按 C 生命周期给梯度化响应（越接近结束，B 越保守）：**

| C 状态 | B 持仓响应 | 强度 | 逻辑 |
|--------|-----------|------|------|
| STRONG_ALIGN | 继续持有 | — | C 健康背书 |
| WEAK_ALIGN | 只收紧其余阈值（如 `MAX_DEV_PCT_B` 减半 / 提前止盈），不减仓 | 轻 | C 仍持仓，只是衰竭预警 |
| **C_ENDED** ⭐ | **收紧 + 减仓**：`MAX_DEV_PCT_B` 减半、拉紧止盈；可选减半仓落袋，剩余交给本级①②兜底 | 中 | 背书撤销但 C 未反手，让本级趋势自行验证 |
| MISALIGN | **立即全额强退**（离场③，最高优先级，战略否定） | 强 | C 反手站到对面，战略级否定 |

**升级后离场优先级（if-elif）：**

```
优1   C 状态 == MISALIGN            → 🚪 立即全额离场（离场③，战略否定）
优1.5 C 状态 == C_ENDED  ⭐新       → ⚠️ 收紧 B 阈值 + 减仓（背书撤销，非强退）
优2   边缘窗口内 B 起点蒸发          → 🚪 entry_void 快速小损离场
优3   B 不利偏离 > MAX_DEV_PCT_B     → 🚪 离场②（趋势偏离）
优4   B 反向段 ≥ N_confirm          → 🚪 离场①（进入下一多空对）
(保留) 预测保护期击穿轨道            → 🚪 止损
否则                                → 继续持有
```

**要点：MISALIGN 强退、C_ENDED 收紧减仓**——两者都源于"C 多空对结束"，但 MISALIGN 是 C 反手站到对面（危险，全退），C_ENDED 是 C 退场观望（背书没了但不对立，减仓+收紧让本级趋势自行验证）。这样既补上了 C_ENDED 的响应，又不因为"C 只是退场没反手"就把 B 正常持仓一刀切掉。

## 六、完整决策流程

**一句话：** 每帧，无仓就查"起点当帧 + C 五态门控"决定是否入场，有仓就按优先级跑离场网（离场③含 C_ENDED 梯度）决定走、减、或留。

```
┌──────────────────────────────────────────────────┐
│ 每帧 i：算各周期 Sig，识别 B 当前半边，              │
│         对 C 也算多空对状态 c_pair_state（5 态）    │
└───────────────────────┬──────────────────────────┘
                        ▼
               ┌────────────────┐
               │  当前是否持仓？  │
               └───┬────────┬───┘
              无仓 │        │ 有仓
                   ▼        ▼
   ┌────────────────────┐  ┌──────────────────────────────────┐
   │   入场判定（v3）     │  │  离场判定（按优先级 if-elif）        │
   ├────────────────────┤  ├──────────────────────────────────┤
   │ B 起点当帧诞生？     │  │ 优1  C==MISALIGN？→全额强退（③）    │
   │   ├ 否 → 不判       │  │ 优1.5 C==C_ENDED？→收紧+减仓 ⭐新   │
   │   └ 是 ↓           │  │ 优2  边缘窗口内起点蒸发？→entry_void │
   │ C 多空对状态（5态）？ │  │ 优3  不利偏离>MAX_DEV_B？→离场（②） │
   │   ├ STRONG→✅入场   │  │ 优4  反向段≥N_confirm？→离场（①）   │
   │   ├ WEAK →⚠️降级/不 │  │ （保护期止损：初期击穿→离场）        │
   │   ├ C_ENDED→❌不入⭐│  │ （WEAK：不强退，只收紧阈值）         │
   │   ├ MISALIGN→❌不入 │  │ 否则 → 继续持有                    │
   │   └ NO_DIR →❌不入  │  └──────────────────────────────────┘
   └────────────────────┘
                   │
                   ▼
           记录交易 / 更新 PnL
```

**要点：** 入场分支比 v2 多一条 C_ENDED → 不入场；有仓分支在离场网顶部把离场③拆成 MISALIGN（强退）和 C_ENDED（收紧减仓）两支。单持仓模型，同帧不同时开多仓。

## 七、实战走查（bar 级，含 C 提前离场场景）

以下 Sig 来自 Schmitt 触发器（+1 多 / 0 观望 / -1 空）。

### 场景 1：起点即入场，C 强同向 ✅（保留 v2）

```
B (60分钟)：新多头半边诞生，起点当帧（pair_start == i），未等锁定
C (日线)：  dir_C = +1，无反转/破位预警，signed_dev ≤ WARN → STRONG_ALIGN

判定：起点当帧 ✓ + C STRONG_ALIGN ✓ → ✅ 入场（做多）
解读：v3 标准入场。零延迟吃到趋势起步段，C 健康奔跑背书压低假信号概率。
```

### 场景 2：C 弱同向（偏离接近但未超阈），降级不入 ⚠️（保留 v2）

```
B (60分钟)：新多头半边起点当帧
C (日线)：  dir_C = +1（仍同向、仍持仓），signed_dev = 3.2%
           WARN_DEV_PCT_C(2.8%) ≤ 3.2% ≤ MAX_DEV_PCT_C(4%) → 破位预警
           → C 状态 = WEAK_ALIGN

判定：allow_weak 关（默认）→ ❌ 不入场
解读：C 偏离接近离场线但还没触发，C 仍持仓、尾部挣扎中。此刻入场高风险，宁可错过。
```

### 场景 X：B 想入场但 C 刚因偏离提前离场（C_ENDED）→ 不入场 ⭐新

```
B (60分钟)：新多头半边起点当帧，dir_B = +1
C (日线)：  dir_C = +1（名义还同向，Sig 未翻）
           但 signed_dev = 4.6% > MAX_DEV_PCT_C(4%)
           → C 离场②已触发、C 已平仓 → C 状态 = C_ENDED

判定：C == C_ENDED → ❌ 不入场
解读：这是 v3 补的洞。dir_C 表面还是 +1，v2 会把它当 WEAK 灰区（甚至误判可入）。
      但 C 的多空对其实已因偏离过大提前结束、C 已空仓——根本没有活跃仓位在背书。
      入场的前提是"C 有活跃同向半边背书"，C_ENDED 下这个前提已经不成立。
      C_ENDED 与 MISALIGN 都拒绝入场，但语义不同：这里 C 是退场观望，不是反手对立。
```

### 场景 Y：B 持仓中 C 转 C_ENDED → 收紧减仓（非强退）⭐新

```
持仓：多头，已持有 6 bar，入场时 C 是 STRONG_ALIGN
C (日线)：本帧 C 的 signed_dev 突破 4% > MAX_DEV_PCT_C
         → C 离场②触发、C 平仓 → C 状态 = C_ENDED（dir_C 仍名义 +1，未反手）

判定：优1.5 C == C_ENDED → ⚠️ 收紧 B 阈值 + 减仓
     （MAX_DEV_PCT_B 减半、拉紧止盈、可选减半仓落袋）
解读：C 背书撤销了，但 C 没反手做空——它只是退场观望。所以不像 MISALIGN 那样全额强退，
      而是收紧防线、减仓落袋，把剩余仓位交给本级①②兜底，让 B 自己的趋势继续验证。
      对比场景 Z：若 C 走到 MISALIGN（反手），才会全额强退。
```

### 场景 Z：C 转 MISALIGN，全额强退 ③（最高优先级，保留 v2）

```
持仓：多头，B.Sig 仍 = +1（本级还看多）
C (日线)：dir_C 的反向段已连续 ≥ N_confirm，dir_C 翻成 -1
         → C 状态 = MISALIGN（反向确认、C 已反手做空）

判定：优1 C == MISALIGN → 🚪 立即全额离场（压过本级 +1，压过 C_ENDED）
解读：为 B 背书的日线大势不仅撤了、还反手站到对面，战略级否定，最高优先级全退。
      这与场景 Y 的分野正是 v3 梯度的核心：反手=强退，退场=减仓。
```

## 八、与现有系统集成

**一句话：** "C 提前离场"复用 B 离场②的同一套 `_signed_deviation` 计算，v2 其实已算过这个值，v3 只是把它按两条阈值线重新分流，改动集中在 `_c_pair_state()`，`WARN_DEV_PCT_C = MAX_DEV_PCT_C` 即复现 v2、回测零回归。

### 8.1 "C 提前离场"如何算

对 C 复用 B 的离场②（趋势偏离）逻辑即可，无需新算法：

```
1. C 周期已跑 _schmitt_trigger 得 sig_C、price_C（v2 已有）
2. 对 C 当前半边跑 _fit_physics_parabola 得预测轨道 fit_C（v2 已有，供破位预警）
3. 逐帧算 signed_dev（C 当前价 vs fit_C，仅取不利方向）—— 与 B 离场② 同一函数
4. signed_dev > MAX_DEV_PCT_C  → 判定 C_ENDED（C 离场②已触发、已平仓）
   WARN_DEV_PCT_C ≤ dev ≤ MAX  → 判定 WEAK 破位预警（未离场）
```

**关键事实：v2 其实已经算了这个 `signed_dev`**（在破位预警检测器里），只是把 `dev > MAX` 错误地归进了 WEAK。**v3 的代码改动因此极小**——不是新增计算，而是把同一个 `signed_dev` 按两条阈值线重新分流。

### 8.2 改动范围（增量 + 默认可复现 v2，回测零回归）

| 改动 | 位置 | 说明 |
|------|------|------|
| **改（主）** | `_c_pair_state(...)` | 加 `C_ENDED` 枚举；把 `signed_dev > MAX_DEV_PCT_C` 从 WEAK 剥离为 C_ENDED；WEAK 偏离维改为 `WARN ≤ dev ≤ MAX` 预警带 |
| **改** | 入场支路 | 决策表加 C_ENDED → 不入场（与 MISALIGN 同为拒绝，语义分开） |
| **改** | 离场支路 | 离场③拆两支：MISALIGN → 全额强退；C_ENDED → 收紧 `MAX_DEV_PCT_B` + 减仓（新优1.5） |
| **新增超参** | `WARN_DEV_PCT_C`（WEAK 预警下界，默认 `0.7×MAX`）、`c_ended_reduce_frac`（C_ENDED 减仓比例，默认 0.5）；`allow_weak_entry` 沿用 |
| **不改** | `_fit_physics_parabola` / `_schmitt_trigger` / `_signed_deviation` | 完全复用，C_ENDED 不引入任何新数学 |

### 8.3 向后兼容：零回归验证

令 `WARN_DEV_PCT_C = MAX_DEV_PCT_C` 且关闭 C_ENDED 分支时，WEAK 预警带塌缩、C_ENDED 永不触发，`dev > MAX_DEV_PCT_C` 的样本回落归入 WEAK（与 v2 一致——v2 正是把 `dev > MAX` 判为 WEAK 破位预警），系统逐字节复现 v2 行为——**回测基线零回归是第一道验证。** 随后逐步下调 `WARN_DEV_PCT_C`、打开 C_ENDED，对比"v3 vs v2 vs 基线"的胜率 / 交易次数 / 最大回撤 / Sharpe，量化补上 C_ENDED 的边际贡献。

> 实现要点：C_ENDED 分支的开关须是"把 `dev > MAX` 重新路由回 WEAK"，而非"直接短路成 STRONG"——否则关闭时 `dev > MAX` 会误落到 STRONG，反而偏离 v2。

## 九、优势与下一步

### 优势

- **C 的提前离场不再被误当弱同向。** v2 把"离场②已触发、C 已平仓"错塞进"仍持仓的 WEAK_ALIGN"，逻辑自相矛盾；v3 用一条阈值线 `MAX_DEV_PCT_C` 把"仍持仓预警"与"已平仓离场"切开，判定物理自洽。
- **两种结束等价对待，更贴合 C 实际操作。** C 和 B 一样跑三离场，本就会因偏离过大走不完整段就平仓。v3 承认"Sig 反向"和"偏离提前离场"是两种等价结束，对 B 都是背书消失，不再漏掉一半现实。
- **梯度响应更细腻。** 离场③从"MISALIGN 一刀切"升级为"STRONG 持有 / WEAK 轻收紧 / C_ENDED 收紧减仓 / MISALIGN 全额强退"四级梯度，区分"C 反手（危险）"与"C 退场（观望）"，既补上响应又不误伤本级正常持仓。
- **改动极小、可复现 v2。** 复用 v2 已算的 `signed_dev`，改动集中在 `_c_pair_state()`；`WARN_DEV_PCT_C = MAX_DEV_PCT_C` 即复现 v2，回测零回归先行验证。

### 一处待定（可配置）

C_ENDED 默认响应是"收紧 + 减仓"而非全额强退，理由是 C 未反手对立、本级趋势可能仍有效。但这是一个**策略选择**而非硬事实——保守派可能希望 C_ENDED 也直接全退（等同 MISALIGN）。因此 `c_ended_reduce_frac`（减仓比例，0=不减、1=全退）设为可配超参，留给回测拍板。

### 下一步（MVP）

```
1. C 五态模型      —— 在 v2 四态间插入 C_ENDED，_c_pair_state() 按两阈值线重分流
2. 入场门控升级    —— 决策表加 C_ENDED → 不入场（与 MISALIGN 语义分开）
3. 离场③梯度化    —— MISALIGN 全额强退 / C_ENDED 收紧减仓 / WEAK 轻收紧 / STRONG 持有
4. 零回归验证      —— WARN_DEV_PCT_C = MAX_DEV_PCT_C 复现 v2，再逐层下调打开
```

参数调优聚焦：`WARN_DEV_PCT_C`（WEAK/C_ENDED 预警带宽度）、`MAX_DEV_PCT_C`（C 离场②触发线 = 核心分界）、`c_ended_reduce_frac`（C_ENDED 减仓强度）、`allow_weak_entry`（灰区开关）。先验证关掉全部开关时回测零回归，再逐层打开，量化 C_ENDED 的边际贡献。
