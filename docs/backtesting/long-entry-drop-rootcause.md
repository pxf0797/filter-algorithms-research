# 根因分析：做多入场被静默丢弃（3690 60min 复现）

> 用户报告："做多的时候 PnL 并没有正常做多"（3690_HK 60分钟）。
> 用真实数据跑真实管线确认：**入场被 `pair_end - pair_start >= 3` 门槛静默丢弃**。
> 复现脚本：`tools/trace_long_veto.py`（跑真实 DB 数据，非静态推理）。

## 1. 现象（真实成交，3690 60min，最新 60 根）

信号判定应做多的点（`sig[pair_end]==+1`）：**[16, 37, 51]**
实际做多入场：**仅 [51]** → **[16, 37] 两个做多被丢**。

```
逐 pair 入场判定:
(  5, 14) gap= 9 sig=-1 做空  有预测 → 做空
( 14, 16) gap= 2 sig=+1 做多  无预测 → ★丢弃(跳过做多)   ← 大涨段[16..30]的做多入场
( 16, 35) gap=19 sig=-1 做空  有预测 → 做空
( 35, 37) gap= 2 sig=+1 做多  无预测 → ★丢弃(跳过做多)
( 37, 45) gap= 8 sig=-1 做空  有预测 → 做空
( 45, 51) gap= 6 sig=+1 做多  有预测 → 做多  ✓(唯一幸存的做多)
( 51, 56) gap= 5 sig=-1 做空  有预测 → 做空
```

## 2. 根因（逻辑链）

1. `streamlit_app.py::_compute_prediction_pairs`：
   ```python
   for pair_start, pair_end in all_pairs:
       if pair_end - pair_start >= 3:          # ← 门槛：拟合抛物线至少需要 3 根
           fit_result = fit_func(t, filtered, pair_start, pair_end)
           ... pred_pairs.append(...)
   ```
   `pair_end - pair_start`= 从**第一段起点**到**反向段起点**的跨度（含中间的 0）。**快速反转**（反转前那段很短，只隔 1~2 根）→ 跨度 < 3 → **不生成预测**。

2. `filter_engine.py::_compute_strategy_pnl`：
   ```python
   for pair_start, pair_end in all_pairs:
       if pair_end not in pred_map:            # ← 无预测 → 整个 pair 跳过
           continue
   ```
   于是该 pair 的**入场（多/空都一样）被静默跳过**，不记录任何交易。

3. **为什么本例总是砍到做多**：本段行情是"上涨 + 快速回踩"——每个强上涨段（[16..30]、[37..38]）前面只有 **1 根下跌 blip**（段1/段3），所以"做多入场 pair"的跨度恰好=2<3 被砍；而做空入场 pair 的第一段是较长的上涨段（跨度 9/19/8），predikce 存在，做空全部保留。**在带快速回踩的上涨行情里，做多会被系统性丢弃** → 正是用户看到的"该做多没做多"。

## 3. 影响

- 不是随机 bug，是**结构性**：任何"反转前的段 < 3 根间隔"的入场都被丢。
- 方向不对称是**数据决定**的：上涨快速回踩 → 砍做多；下跌快速反弹 → 砍做空。
- `>=3` 是为了抛物线拟合（3 点定二次），但它**顺带把入场也一起否决了**——入场本不该依赖"能否拟合抛物线"。

## 4. 修复方案（待定，属策略决策）

| 方案 | 做法 | 取舍 |
|---|---|---|
| **A. 入场与预测解耦** | 无预测时仍按 `sig` 方向入场；`pred_up` 方向确认降级为"有预测才用"，止损从"预测价"回退到"相对入场价固定%" | 最贴合"该入场就入场"；快速反转不再漏单；但失去 pred_up 假信号过滤 |
| **B. 短跨度用线性拟合兜底** | `gap<3`（2 点）时用一次线性拟合给 `pred_up`，保留方向确认 | 保留确认逻辑；实现小；1 点(gap<2)仍需兜底 |
| **C. 拟合窗口向前借点** | `gap<3` 时把拟合起点前移，凑够 ≥3 根 | 保留抛物线；但改变拟合语义(掺入更早数据) |

**建议**：先做 **A**（入场不再被"能否拟合"绑架，是最直接的正确性修复），把 `pred_up`/预测价止损降级为"有则用、无则回退固定%止损"。是否保留 pred_up 假信号过滤由回测拍板。
