检测到您是直接打开 HTML 文件（file:// 协议），无法加载 Parquet 文件。

请使用以下命令启动本地服务器：

python tools/view_backtest.py --serve

或者用嵌入模式直接查看：python tools/view_backtest.py <parquet 文件路径>

或者用命令行嵌入数据后打开：

# 直接指定 parquet 文件 python tools/view_backtest.py <parquet 文件路径> # 自动找最新的回测结果 python tools/view_backtest.py --latest ./test_backtest_output # 同时加载 metadata.json python tools/view_backtest.py -m metadata.json result.parquet

回测结果可视化

1 概览仪表盘
2 信号对比（4 视图独立子图，共享 x 轴）

4 个子图垂直堆叠，共享 x 轴，各自独立 y 轴固定 [-1, +1]。绿(+1)/红(-1)/灰(0) 背景着色，阶梯信号线。

3 滤波价格叠加 + EPS 阈值带（v2 日线参考）

4 条滤波价格线叠加（颜色+线宽分层），半透明带=v2(日线) ±eps 阈值参考。

4 PnL 曲线（4 视图 x 做多+做空）

实线=做多 PnL，虚线=做空 PnL。标注为各曲线终值。

5 持仓状态热力图（4 视图 x long_pos + short_pos）

行=视图，列=时间（采样 100 点）。绿色=做多持仓，红色=做空持仓，灰色=空仓。

6 交易事件 & BS 标记统计
7 完整数据表（前 50 行，横向滚动）
