数据存储前后对比 — EventRecorder 摘要 vs Parquet 全量

数据项 Parquet 列名 现在存储
(EventRecorder 摘要)		 方案后存储
(Parquet 全量)		 提升 分析场景
收盘价序列 close / open, high, low 仅尾部 3~5 个值 全量 OHLCV 数组 (120+ bar × 8 view) ✅ 改进 K 线图回放、价格形态识别
滤波值 v0_filtered / filtered2 仅最后 1 个值 全量数组 (每 bar 一个 float32) ✅ 改进 滤波器效果验证、参数调优
施密特触发器中间状态 schmitt_eps, schmitt_v, schmitt_a 仅尾部 3~5 个值 全量数组 (eps / v / a / sigma_v) ✅ 改进 信号翻转过程回溯、阈值敏感性分析
信号序列 schmitt_sig 仅尾部 3~5 个值 全量数组 (+1/0/-1 每 bar) ✅ 改进 信号一致性分析、多周期矛盾检测
PnL 曲线 v0_pnl_long, v0_pnl_short 不存储 全量累积收益数组 (每 bar float32) 🆕 新增 资金曲线回放、回撤分析、Sharpe 计算
交易明细 trades.parquet (14 字段) 仅统计 (数量 / 胜率) 逐笔完整明细 (entry/exit bar/price/pnl 等) 🆕 新增 逐笔审查、亏损归因、持仓时长分布
持仓掩码 long_mask, short_mask 不存储 布尔数组 (每 bar 是否持仓) 🆕 新增 持仓状态时序、仓位管理分析
预测抛物线数据 pair_id (关联 prediction_pairs) 不存储 每 pair 起止 bar / 参数记录 🆕 新增 预测准确率评估、pair 盈亏统计
高周期对齐 PnL higher_pnl 不存储 全量数组 (每 bar float32) 🆕 新增 多周期 PnL 对齐分析
Schema 版本 metadata.json 无 schema_version 字段 + Parquet 内嵌版本号 🆕 新增 版本迁移、兼容性检查
时间轴 timestamp (datetime64[ns]) 不存储 每 bar 精确时间戳 🆕 新增 按时间范围过滤、跨 session 对齐
