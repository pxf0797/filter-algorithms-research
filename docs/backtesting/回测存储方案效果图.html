粗周期数据自然重复（正确行为，非 bug）
min_tf 周期变化 & 其他周期值变更点

日线的 -1 从 bar 0 到 bar 8 始终不变（每个交易日 = 78 个 5 分钟 bar）→ 存储中连续 78 行重复同一日线信号值。 这正是统一时间轴的核心优势：每行精确反映该时刻所有周期的对齐状态。

4 存储方案前后对比
维度现在（EventRecorder / JSONL）方案后（统一时间轴 Parquet）
时间轴 无统一轴，JSONL 条目时间分散 min_tf 统一行索引，所有周期对齐
信号 仅尾部 5 值摘要 完整信号序列，每 bar 一条
PnL 不存储 每 bar 累计 PnL 值
持仓 不存储 每 bar 布尔/枚举值
交易 仅最终统计数字 每 bar 事件标注（BS 标记）
分析方式 人工翻 JSONL 文件 DuckDB SQL 一键查询
人眼观察 无直接观察手段 CSV 直接 Excel 打开
5 设计要点
  • ✅ 统一时间轴 = min_tf bar 为行，所有周期对齐
  • ✅ 粗周期数据自然重复 = 正确行为，不是 bug
  • ✅ Parquet 列式存储 = DuckDB 秒级查询跨 Session 数据
  • ✅ CSV 同步输出 = Excel 直接打开观察
